1. 使役形：让……做 / 使……做

使役形 = 让某人做某事 / 使某种情况发生

使役形表示上级、父母、老师、组织等让别人做某事，也可以表示某件事使人产生某种感情。

陳さんは 息子を アメリカに 留学させます。
陈先生让儿子去美国留学。
先生は 学生に 宿題を させました。
老师让学生做了作业。
母は 子供を 早く 寝させました。
妈妈让孩子早点睡了。
使役句有“让、叫、使、允许”的意思。根据上下文，可能是命令，也可能是许可。

2. 使役形变化规则

类型基本形使役形规则

一类动词読む読ませるむ→ませる
一类动词話す話させるす→させる
一类动词待つ待たせるつ→たせる
一类动词買う買わせるう→わせる
二类动词食べる食べさせる去る＋させる
二类动词見る見させる去る＋させる
三类动词来る来させる（こさせる）特殊

一类动词「う」结尾要变「わ」：買う→買わせる、言う→言わせる。

3. 自动词使役：AはBをVさせます

使役者 + は + 被使役者 + を + 自动词使役形

原动词是不带直接宾语的自动词时，被使役者多用「を」。

部長は 李さんを 大阪へ 出張させました。
部长让小李去大阪出差了。
母は 子供を 公園で 遊ばせました。
妈妈让孩子在公园玩。
先生は 学生を 立たせました。
老师让学生站起来。
自动词本身没有「を」宾语，所以被使役者常用「を」标记。

4. 他动词使役：AはBにNをVさせます

使役者 + は + 被使役者 + に + 宾语 + を + 他动词使役形

原动词本来就有「を」宾语时，为避免两个「を」，被使役者常用「に」。

先生は 学生に 本を 読ませました。
老师让学生读书了。
母は 子供に 野菜を 食べさせました。
妈妈让孩子吃了蔬菜。
部長は 李さんに レポートを 書かせました。
部长让小李写了报告。
他动词本身需要「Nを」，所以被使役者用「に」：学生に本を読ませる。

5. 使役：强制 vs 许可

使役形既可以表示“强制别人做”，也可以表示“允许别人做”。要根据上下文判断。

用法例句中文
强制、命令先生は学生に宿題をさせました。老师让学生做作业。
许可、放任母は子供を公園で遊ばせました。妈妈让孩子在公园玩。
培养、安排父は娘を留学させました。父亲让女儿去留学。
情感触发その話はみんなを笑わせました。那件事把大家逗笑了。
中文的“让”也有强制和允许两种意思，日语使役形也一样。

6. Vさせてください：请让我……

动词使役て形 + ください

表示请求对方允许自己做某事。中文常译为“请让我……”。

少し 休ませてください。
请让我休息一下。
この 仕事を わたしに やらせてください。
请让我做这项工作。
今日は 早く 帰らせてください。
今天请让我早点回去。
一度 考えさせてください。
请让我考虑一下。
这是非常常用的请求许可表达，比直接说「します」更礼貌。

7. Vやすいです：容易……，好……

动词ます形去ます + やすいです

表示某动作容易做，或者某物容易被做某动作。

この ペンは とても 書きやすいです。
这支笔很好写。
この 辞書は 使いやすいです。
这本词典很好用。
この 靴は 歩きやすいです。
这双鞋很好走路。
「やすい」像一类形容词一样变化：書きやすい、書きやすくない、書きやすかった。

8. Vにくいです：难……，不好……

动词ます形去ます + にくいです

表示某动作难做，或者某物不容易被做某动作。

この 字は 読みにくいです。
这个字很难读。
この 道は 歩きにくいです。
这条路不好走。
この 説明は 分かりにくいです。
这个说明很难懂。
「にくい」也按一类形容词变化：分かりにくい、分かりにくくない。
