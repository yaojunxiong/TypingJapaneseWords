一、快速开始

打开学习首页

访问 docs/minna-index.html，进入统一课程入口。

使用 Google 登录

点击 G 用 Google 登录。登录后，系统可以保存你的学习进度，并参与排行榜。

点击“继续学习”

系统会根据你的进度自动跳到当前建议学习的课程。

完成本课 Mastery

完成词汇、语法、例句、综合测试，并清空错题。

回首页刷新进度

完成后点击回首页，或在首页点击 刷新我的进度，下一课会自动解锁。

登录用户

保存云端进度可同步不同设备可参与匿名排行榜

推荐使用 Google 登录学习。

未登录用户

可浏览入口进度可能不稳定不能可靠参与排行榜

如果只是临时体验，可以不登录。

区域用途操作方法

三、什么叫完成一课？

系统采用 Mastery 掌握标准，不只是“看完一遍”。

标准

词汇 100%语法 ≥80%例句 ≥80%综合测试 ≥80%错题清零

注意

如果完成后首页没有马上变化，请点击 刷新我的进度，或者重新打开首页。

四、如何学习一课

核心词汇

先熟悉本课单词和固定表达。建议先看日语，再选中文意思。

语法训练

通过选择题理解本课句型，例如 〜たら、〜ても、〜と思います 等。

核心例句

系统会拆分句子结构，帮助理解日语语序。

综合测试

混合考查词汇、语法、句子理解和场景表达。

错题复习

答错后请重新练习，直到错题清零。

五、排行榜说明

排行榜采用安全匿名方式。

项目说明
排名规则先按完成关卡数降序，再按总分降序，再按最近打卡时间排序。
显示名称显示“学习者 xxxxxx”这样的匿名名。
不显示内容不显示完整 Google 邮箱、user_id、user_key、原始 progress JSON。
管理员查询管理员可以在 Supabase 后台用 SQL 反查匿名名对应邮箱。

六、常见问题

1. 为什么下一课没解锁？

请确认上一课已经达到 Mastery 标准，并点击首页的“刷新我的进度”。

2. 为什么排行榜没有我？

需要使用 Google 登录，并至少完成一课或产生云端学习记录。

3. 为什么排行榜读取失败？

请确认 Supabase 已执行 supabase/minna_public_leaderboard.sql，并且 view 已授权读取。

4. 换设备后进度还在吗？

只要使用同一个 Google 账号登录，云端进度可以继续读取。

七、推荐学习方法

每天1课或半课先词汇再语法错题必须清零例句大声读完成后回首页刷新

小学生或初学者建议每次学习 15–25 分钟，完成一小段后休息，再继续。
