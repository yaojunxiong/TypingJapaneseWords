1. 今～時～分です：现在几点几分

今 + 数字 + 時 + 数字 + 分 + です

询问和回答时间时，用「今、何時ですか」和「～時～分です」。

今 何時ですか。
现在几点？
今 7時です。
现在7点。
今 8時30分です。
现在8点30分。
「時」读作「じ」；「分」有音变，如1分いっぷん、3分さんぷん、6分ろっぷん、10分じゅっぷん。

2. 动词ます形：现在、将来、习惯动作

名词 + は + 动词ます

「ます」是礼貌动词形式，可以表示现在的习惯，也可以表示将来的动作。

森さんは 7時に 起きます。
森先生7点起床。
わたしは 毎日 勉強します。
我每天学习。
明日 働きます。
明天工作。
日语的「ます」不只表示“正在做”，更多时候表示习惯或将来。

3. 动词ません：不做……

动词ます → 动词ません

现在或将来的否定用「ません」。

田中さんは 今日 働きません。
田中先生今天不工作。
わたしは 明日 休みません。
我明天不休息。
森さんは 日曜日 勉強しません。
森先生星期天不学习。
「ません」本身就是礼貌否定，不要再加「ない」。

4. 动词ました / ませんでした：过去肯定与过去否定

ました = 做了；ませんでした = 没做

意思形式例子
工作働きます今日働きます
不工作働きません今日働きません
工作了働きました昨日働きました
没工作働きませんでした昨日働きませんでした
昨日 9時に 寝ました。
昨天9点睡了。
昨日 勉強しませんでした。
昨天没学习。

5. 时间に动词：在某个时间做某事

具体时间 + に + 动词

动作发生在具体时间点时，时间后面常用「に」。

森さんは 7時に 起きます。
森先生7点起床。
学校は 8時半に 始まります。
学校8点半开始。
会議は 3時に 終わります。
会议3点结束。
具体时间点如「7時」「月曜日」「1月1日」常可用に；「今日」「昨日」「明日」「毎日」一般不用に。

6. から・まで：从……到……

时间 + から + 时间 + まで

「から」表示起点，“从……”；「まで」表示终点，“到……”。

会社は 9時から 5時までです。
公司从9点到5点。
わたしは 月曜日から 金曜日まで 働きます。
我从星期一到星期五工作。
授業は 8時半から 12時までです。
课从8点半到12点。
「から」「まで」可以一起用，也可以单独用：9時からです、5時までです。

7. いつ：什么时候

いつ + 动词ますか

询问动作发生时间时，用「いつ」。

試験は いつですか。
考试是什么时候？
来週の 月曜日です。
是下周一。
森さんは いつ 休みますか。
森先生什么时候休息？
日曜日 休みます。
星期天休息。
「いつ」问时间，不问地点；问地点用「どこ」。

10. 中国学习者容易错的地方

错误正确说明
森さんは7時起きます。森さんは7時に起きます。具体时间点后用に
昨日働きます。昨日働きました。昨天是过去，要用ました
昨日働きません。昨日働きませんでした。过去否定用ませんでした
今日に勉強します。今日勉強します。今日、昨日、明日一般不加に
9時まで5時からです。9時から5時までです。顺序是から→まで
何時にですか。何時ですか。/ 何時に起きますか。问“几点”本身不用に；问动作时间可用に

第5课一句话记忆

第5课就是学“几点做什么、从几点到几点、过去做没做”。

今7時です现在7点
森さんは7時に起きます森先生7点起床
昨日勉強しました昨天学习了
昨日働きませんでした昨天没工作
9時から5時まで働きます从9点工作到5点
