1. ～とき：……的时候

普通形 + とき

「とき」表示“时候”。前面可以接动词、い形容词、な形容词、名词，用来说明某件事发生的时间场景。

日本へ 来たとき、空港で 友達に 会いました。
来日本的时候，在机场见到了朋友。
暇なとき、音楽を 聞きます。
有空的时候，听音乐。
子どものとき、よく 川で 泳ぎました。
小时候，经常在河里游泳。
「とき」前面不是礼貌形。不要说「行きますとき」，要说「行くとき」。

2. 动词辞书形＋とき：做……的时候 / 做……之前

动词辞书形 + とき

动词辞书形接「とき」时，常表示后面的动作发生时，前面的动作还没完成，或者正要做。

寝るとき、電気を 消します。
睡觉的时候，把灯关掉。
出かけるとき、鍵を かけます。
出门的时候，锁门。
日本へ 行くとき、カメラを 買いました。
去日本的时候，买了相机。
図書館で 本を 借りるとき、カードが 要ります。
在图书馆借书时，需要卡。
「行くとき」多表示“去之前/去的时候”；动作“去”还没有完全结束。

3. 动词た形＋とき：做了……的时候 / 做完……之后

动词た形 + とき

动词た形接「とき」时，常表示前面的动作已经完成之后，再发生后面的事情。

うちへ 帰ったとき、「ただいま」と 言います。
回到家时，说“我回来了”。
日本へ 来たとき、桜を 見ました。
来到日本的时候，看到了樱花。
仕事が 終わったとき、友達に 電話しました。
工作结束的时候，给朋友打了电话。
駅に 着いたとき、雨が 降っていました。
到车站的时候，正在下雨。
「来るとき」= 来之前/来的途中；「来たとき」= 来到之后/到达时。た形强调动作已完成。

4. 辞书形とき vs た形とき

表达中文感觉
日本へ行くとき、カメラを買いました。去日本的时候买了相机。去之前或去的途中买
日本へ行ったとき、カメラを買いました。去了日本的时候买了相机。到日本以后买
寝るとき、薬を飲みます。睡觉时吃药。睡前吃
寝たとき、電気が消えていました。睡下时灯已经关了。睡这个动作已发生
判断方法：前面的动作“完成了吗？”没完成用辞书形，完成后用た形。

5. 动词ない形＋とき：不……的时候

动词ない形 + とき

表示“不做某事的时候”。

時間が ないとき、朝ご飯を 食べません。
没有时间的时候，不吃早饭。
日本語が わからないとき、先生に 聞きます。
不懂日语的时候，问老师。
使わないとき、電気を 消してください。
不用的时候，请关灯。
「ないとき」本身就是普通形接とき。不要说「ありませんとき」。

6. い形容词＋とき：……的时候

い形容词 + とき

い形容词直接接「とき」。

暑いとき、冷たい水を 飲みます。
热的时候，喝冰水。
忙しいとき、テレビを 見ません。
忙的时候，不看电视。
眠いとき、コーヒーを 飲みます。
困的时候，喝咖啡。
若いとき、よく 旅行しました。
年轻的时候，经常旅行。
い形容词接名词不加「の」也不加「な」：暑いとき、忙しいとき。

7. な形容词＋な＋とき

な形容词 + な + とき

な形容词修饰「とき」时，要加「な」。因为「とき」本质上是名词。

暇なとき、映画を 見ます。
有空的时候，看电影。
元気なとき、よく スポーツを します。
精神好的时候，经常运动。
静かなとき、勉強しやすいです。
安静的时候，容易学习。
不要说「暇とき」。な形容词修饰名词时要加な：暇なとき。

8. 名词＋の＋とき

名词 + の + とき

名词修饰「とき」时，要用「の」。

子どものとき、よく 外で 遊びました。
小时候，经常在外面玩。
学生のとき、アルバイトを しました。
学生时代，做过兼职。
病気のとき、会社を 休みます。
生病的时候，请假不上班。
地震のとき、エレベーターを 使わないでください。
地震的时候，请不要使用电梯。
名词接とき要用の：学生のとき、病気のとき。

9. 动词辞书形＋と：一……就…… / 如果……就……

动词辞书形 + と + 结果

「～と」表示做某动作后，自然出现某结果。常用于机器操作、道路说明、自然规律、必然结果。

このボタンを 押すと、切符が 出ます。
一按这个按钮，票就出来。
この道を まっすぐ 行くと、駅が あります。
沿着这条路一直走，就有车站。
右へ 曲がると、郵便局が あります。
向右转，就有邮局。
春に なると、桜が 咲きます。
到了春天，樱花就开。
「と」后面一般不用请求、命令、意志句。比如“如果有时间，请来”不适合用「と」，后面课程会学其他条件表达。

10. ～と 的常见使用场景

场景例句中文
机器操作ここを押すと、ドアが開きます。按这里，门就开。
路线说明信号を右へ曲がると、銀行があります。在红绿灯右转，就有银行。
自然规律冬になると、寒くなります。到冬天就会变冷。
发现结果窓を開けると、海が見えます。一打开窗，就能看到海。
「と」有“只要A发生，B就自然发生”的感觉。
