第13课核心语法

Nが欲しいですVます形たいです目的に行きます何かどこか

语法中文意思重点
名词が欲しいです想要……想要的东西用が
动词ます形去ます＋たいです想做……表达第一人称愿望，常用于自己
名词を/が Vたいです想……某物を和が都可见，初级常用を
地点へ 动词ます形に 行きます去某地做……に表示移动目的
何か / どこか什么东西 / 某个地方不确定的对象，不加を/へ也可

1. N が欲しいです：想要……

名词 + が + 欲しいです

「欲しい」表示“想要”。想要的对象用助词「が」。

わたしは 新しいパソコンが 欲しいです。
我想要一台新电脑。
車が 欲しいです。
想要车。
今、時間が 欲しいです。
现在想要时间。
誕生日に 何が 欲しいですか。
生日时你想要什么？
「欲しい」是い形容词，所以否定是「欲しくないです」，过去是「欲しかったです」。

2. 欲しいです 的变化

「欲しい」按照い形容词变化。

形式日语中文
现在肯定欲しいです想要
现在否定欲しくないです不想要
过去肯定欲しかったです以前想要 / 当时想要
过去否定欲しくなかったです以前不想要 / 当时不想要
子どもの時、自転車が 欲しかったです。
小时候想要自行车。
今は 車が 欲しくないです。
现在不想要车。

3. Vます形＋たいです：想做……

动词ます形去ます + たいです

「～たいです」表示说话人想做某事。把动词的「ます」去掉，再加「たいです」。

ます形去ます～たいです中文
食べます食べ食べたいです想吃
飲みます飲み飲みたいです想喝
見ます見見たいです想看
行きます行き行きたいです想去
買います買い買いたいです想买
しますししたいです想做
水を 飲みたいです。
想喝水。
映画を 見たいです。
想看电影。
京都へ 行きたいです。
想去京都。
日本語を 勉強したいです。
想学习日语。
「たい」像い形容词一样变化：食べたくないです、食べたかったです。

4. ～たいです 的变化

「～たい」后面按照い形容词变化。

形式日语中文
现在肯定食べたいです想吃
现在否定食べたくないです不想吃
过去肯定食べたかったです以前想吃 / 当时想吃
过去否定食べたくなかったです以前不想吃 / 当时不想吃
今日は 何も 食べたくないです。
今天什么都不想吃。
昨日は 早く帰りたかったです。
昨天想早点回家。
「～たいです」多用于自己或询问对方。直接说第三者「田中さんは行きたいです」不太自然，后面会学更合适的表达。

5. N を / が Vたいです

名词 + を/が + 动词たいです

在「～たいです」句里，动作对象可以用「を」，也可以用「が」。初级课本中常见「を」；「が」更强调愿望对象。

表达中文感觉
寿司を食べたいです想吃寿司动作对象
寿司が食べたいです想吃寿司更强调“寿司”这个想要对象
映画を見たいです想看电影自然常用
映画が見たいです想看的就是电影强调对象
初级阶段先记「NをVたいです」最稳；看到「NがVたいです」也要能理解。

6. 地点へ目的に行きます：去某地做……

地点 + へ + 动词ます形去ます / 名词 + に + 行きます

「に」可以表示移动目的。中文是“去……做……”。

デパートへ 買い物に 行きます。
去百货商店买东西。
京都へ 花見に 行きます。
去京都赏花。
レストランへ 晩ご飯を 食べに 行きます。
去餐厅吃晚饭。
図書館へ 本を 借りに 行きます。
去图书馆借书。
这里的「に」不是时间点，而是“目的”。结构是：去哪里 + 做什么 + に行きます。

7. 行きます・来ます・帰ります 都可以接目的

目的句不只可以接「行きます」，也可以接「来ます」「帰ります」。

动词例句中文
行きます映画を見に行きます。去看电影。
来ます友達が遊びに来ます。朋友来玩。
帰ります昼ご飯を食べに帰ります。回去吃午饭。
日本へ 日本語を 勉強しに 来ました。
来日本学习日语。
うちへ 荷物を 取りに 帰ります。
回家拿行李。

8. 何か：某个东西 / 什么东西

何か + 动词

「何か」表示不确定的“什么东西、某个东西”。在句中常常不再加「を」。

何か 食べたいです。
想吃点什么。
何か 飲みませんか。
要不要喝点什么？
コンビニで 何か 買います。
在便利店买点什么。
「何を食べますか」= 吃什么？明确提问；「何か食べたいです」= 想吃点什么，不确定具体是什么。

9. どこか：某个地方 / 哪里

どこか + 动词

「どこか」表示不确定的“某个地方、哪里”。常用于想去某处但还没确定。

どこかへ 行きたいです。
想去个什么地方。
日曜日、どこか 行きませんか。
星期天要不要去哪里玩？
休みに どこかへ 行きましたか。
假期去了什么地方吗？
「どこへ行きますか」= 去哪里？明确问地点；「どこかへ行きたいです」= 想去某个地方。
