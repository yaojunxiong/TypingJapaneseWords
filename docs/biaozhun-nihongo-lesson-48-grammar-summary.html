1. 谦让语：降低自己，抬高对方

谦让语 = 谦虚地说自己或自己一方的动作

谦让语常用于对客人、老师、上司说话时，表示“我来做……”，通过降低自己的动作来尊重对方。

お荷物は 私が お持ちします。
您的行李我来拿。
後ほど、こちらから ご連絡します。
稍后由我们联系您。
明日、先生の 研究室へ 伺います。
明天我去老师的研究室拜访。
尊敬语用于“对方做”；谦让语用于“我/我方做”。

2. おVします：我为您……

お + 动词ます形去ます + します

用于谦虚地表达自己为对方做某事。

この 荷物を お持ちします。
我来拿这件行李。
駅まで お送りします。
我送您到车站。
後で お電話します。
稍后我给您打电话。
資料を お届けします。
我把资料送过去。
「お～します」常用于自己的动作对对方有帮助或影响的场景。

3. ごNします：汉语词サ变动词的谦让表达

ご + サ变名词 + します

「連絡します」「案内します」「説明します」等汉语词サ变动词，常用「ご～します」。

後ほど ご連絡します。
稍后我联系您。
会議室まで ご案内します。
我带您到会议室。
使い方を ご説明します。
我来说明使用方法。
和语动词多用「お」：お持ちします；汉语词サ变多用「ご」：ご連絡します。

4. いたします：します 的郑重谦让语

します → いたします

「いたします」比「します」更郑重，常用于商务、服务、正式邮件。

私が ご案内いたします。
由我来为您带路。
明日、こちらから ご連絡いたします。
明天由我们联系您。
資料を お送りいたします。
我把资料发给您。
商务邮件里常见：確認いたします、送付いたします、対応いたします。

5. 特殊谦让语

高频动词有专门的谦让语，需要单独记。

普通表达谦让语中文

来ます参ります来
聞きます伺います听，询问

这些特殊谦让语很常用，特别是「伺います」「拝見します」「いただきます」「申します」。

6. 伺います：去拜访 / 听 / 问

伺います = 行きます・聞きます・訪ねます 的谦让语

明日 3時に 先生の 研究室へ 伺います。
明天3点我去老师研究室拜访。
お名前を 伺っても よろしいですか。
可以请问您的姓名吗？
詳しい 話を 伺いたいです。
我想听一下详细情况。
「伺う」既可以表示“去拜访”，也可以表示“询问、听”。

7. いただきます：吃喝 / 收到 / 请对方做

いただきます = 食べます・飲みます・もらいます 的谦让语

お土産を いただきました。
我收到了礼物。
先生に 資料を 送っていただきました。
老师给我发了资料。
こちらに お名前を 書いていただけますか。
可以请您在这里写下姓名吗？
「～ていただけますか」是非常礼貌的请求：“能请您……吗？”

8. ございます：あります / です 的郑重表达

「ございます」常用于服务、商务、正式说明。

こちらは 会議の 資料でございます。
这是会议资料。
エレベーターは 右側に ございます。
电梯在右侧。
ご質問は ございますか。
您有问题吗？
あります → ございます；です → でございます。服务业常用。

9. 尊敬语 vs 谦让语

对象用法例句
对方/老师/客人做尊敬语先生がいらっしゃいます。
自己/我方做谦让语私が伺います。
对方吃召し上がります何を召し上がりますか。
自己吃/接受いただきますお茶をいただきます。
对方看ご覧になります先生がご覧になります。
自己看拝見します資料を拝見します。
记忆：尊敬语抬高对方；谦让语降低自己。

13. 中国学习者容易错的地方

错误正确说明
