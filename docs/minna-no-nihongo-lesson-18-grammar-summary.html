辞书形～ことができます趣味は～ことです～前に能力・可能

语法中文意思重点
动词辞书形动词原形字典里查到的形式，也是普通形之一
动词辞书形＋ことができます会……；能……表示能力或可能性
名词ができます会……；能……常接运动、语言、乐器等名词
趣味は 动词辞书形＋ことです兴趣是……把动词变成名词性内容
动词辞书形＋前に在……之前动作发生前先做另一件事

1. 辞书形：动词原形

辞书形 = 字典里的动词形式

第18课开始学习动词的「辞書形」。辞书形就是字典里查动词时看到的形式，也是后面很多语法的基础。

例：食べます → 食べる，行きます → 行く，します → する。中文可以先理解为“动词原形”。

2. 一类动词辞书形变化

一类动词把ます形前的假名从「い段」变成「う段」。

ます形辞书形中文
書きます書く写
聞きます聞く听；问
急ぎます急ぐ赶紧
飲みます飲む喝
遊びます遊ぶ玩
帰ります帰る回去
待ちます待つ等
話します話す说
買います買う买
一类动词常见变化：き→く、ぎ→ぐ、み→む、び→ぶ、り→る、ち→つ、し→す、い→う。

3. 二类・三类动词辞书形变化

二类动词去掉「ます」，加「る」。三类动词要单独记。

类别ます形辞书形中文
二类食べます食べる吃
二类見ます見る看
二类起きます起きる起床
二类寝ます寝る睡觉
三类しますする做
三类来ます来る来
「来る」读作「くる」。

4. ～ことができます：会……；能……

动词辞书形 + ことができます

表示能力或可能性。中文可以翻译成“会……”“能……”“可以……”。

わたしは 日本語を 話すことができます。
我会说日语。
ミラーさんは 漢字を 読むことができます。
米勒先生会读汉字。
ここで 切符を 買うことができます。
可以在这里买票。
この図書館で DVDを 借りることができます。
在这个图书馆可以借DVD。
「こと」把前面的动词短语名词化，整个「話すこと」相当于“说这件事”。

5. ～ことができません：不会……；不能……

动词辞书形 + ことができません

否定形式表示“不会……”“不能……”。

わたしは 泳ぐことができません。
我不会游泳。
ここで たばこを 吸うことができません。
这里不能抽烟。
子どもは この薬を 飲むことができません。
小孩子不能吃这个药。
能力上的“不会”和规则上的“不能”都可以用「～ことができません」，要看上下文。

6. 名词ができます：会……；能……

名词 + が + できます

如果对象是运动、语言、乐器、技能类名词，可以直接用「Nができます」。

表达中文
日本語ができます会日语
英語ができます会英语
テニスができます会打网球
スキーができます会滑雪
ピアノができます会弹钢琴
ミラーさんは 日本語が できます。
米勒先生会日语。
わたしは テニスが できます。
我会打网球。
「日本語を話すことができます」更具体：会说日语。「日本語ができます」更概括：会日语。

7. 趣味は～ことです：兴趣是……

趣味 + は + 动词辞书形 + こと + です

说明兴趣爱好时，可以用「动词辞书形＋こと」把动作名词化。

わたしの趣味は 音楽を 聞くことです。
我的兴趣是听音乐。
趣味は 写真を 撮ることです。
兴趣是拍照。
わたしの趣味は 旅行することです。
我的兴趣是旅行。
母の趣味は 料理を 作ることです。
妈妈的兴趣是做饭。
如果兴趣本来就是名词，也可以直接说：趣味は音楽です。趣味はサッカーです。

8. ～前に：在……之前

动词辞书形 + 前に

表示在某个动作发生之前，先做另一件事。前面的动作用辞书形。

寝る前に、歯を磨きます。
睡觉前刷牙。
日本へ来る前に、日本語を勉強しました。
来日本之前学了日语。
食事する前に、手を洗います。
吃饭前洗手。
旅行する前に、ホテルを予約します。
旅行前预订酒店。
「～てから」= 做完之后；「～前に」= 做之前。一个看后，一个看前。

9. 名词の前に：在……之前

名词 + の + 前に

如果前面是名词，要加「の」。

会議の前に、資料をコピーします。
会议前复印资料。
食事の前に、手を洗います。
饭前洗手。
試験の前に、よく勉強しました。
考试前好好学习了。
动词：寝る前に；名词：会議の前に。名词后面的「の」不能省。
