1. 今、何時ですか：现在几点？

今 + 何時 + ですか

「今」表示“现在”，“何時」表示“几点”。询问当前时间时用「今、何時ですか」。

今、何時ですか。
现在几点？
2時10分です。
2点10分。
午前9時です。
上午9点。
午後6時半です。
下午6点半。
「半（はん）」= 半。6時半 = 6点半。分钟的「分」读音会变化，要特别记。

数字 + 時 / 数字 + 分

日语时间用「時（じ）」表示点，用「分（ふん / ぷん）」表示分。

3. N は ～から ～までです：从……到……

名词 + は + 时间 + から + 时间 + まで + です

「から」表示起点，“从……”。「まで」表示终点，“到……”。一起用表示时间范围。

銀行は 9時から 3時までです。
银行从9点到3点。
会社は 月曜日から 金曜日までです。
公司从星期一到星期五上班。
昼休みは 12時から 1時までです。
午休从12点到1点。
デパートは 10時から 8時までです。
百货商店从10点到8点营业。
「から」「まで」可以一起用，也可以单独用：9時からです = 从9点开始；5時までです = 到5点为止。

4. 何時から何時までですか：从几点到几点？

何時から + 何時まで + ですか

询问营业时间、上课时间、工作时间等，用这个句型。

銀行は 何時から 何時までですか。
银行从几点到几点？
9時から 3時までです。
从9点到3点。
昼休みは 何時から 何時までですか。
午休从几点到几点？
12時から 1時までです。
从12点到1点。

5. 动词ます形：现在/未来的礼貌表达

动词ます形

第4课开始正式学习动词的礼貌形。现在和未来的肯定都用「～ます」。

形式中文例子
～ます做 / 将做働きます
～ません不做 / 将不做働きません
～ました做了働きました
～ませんでした没做働きませんでした
わたしは 毎日 働きます。
我每天工作。
わたしは 明日 働きます。
我明天工作。
日语中「働きます」既可以表示现在习惯，也可以表示未来，要看时间词判断。

6. ます・ません・ました・ませんでした

动词礼貌形最重要的是四个基本形式。

时间肯定否定
现在/未来働きます
工作 / 将工作		働きません
不工作 / 将不工作
过去働きました
工作了		働きませんでした
没工作
昨日 勉強しました。
昨天学习了。
昨日 勉強しませんでした。
昨天没有学习。
明日 働きません。
明天不工作。
看到「昨日」等过去时间，就用「ました / ませんでした」。看到「明日」等未来时间，就用「ます / ません」。

7. 何曜日ですか：星期几？

「曜日」表示星期。询问星期几时用「何曜日ですか」。

8. ～に：在几点做某事

时间 + に + 动词

具体时间点后常加助词「に」，表示“在……时间做某事”。

わたしは 6時に 起きます。
我6点起床。
毎晩 11時に 寝ます。
每天晚上11点睡觉。
会議は 3時に 終わります。
会议3点结束。
「今日、昨日、明日、毎朝」这类不是具体钟点的时间词，通常不加「に」。
