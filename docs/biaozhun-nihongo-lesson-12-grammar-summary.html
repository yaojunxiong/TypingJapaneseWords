第12课核心句型

N1はN2より～ですN1よりN2のほうが～ですN1はN2ほど～くないですどちらが～ですかNの中で一番どのNが一番

句型中文意思重点
N1は N2より 形容词ですN1比N2更……より表示比较基准
N1より N2のほうが 形容词です比起N1，N2更……のほうが强调被比较后更突出的一方
N1は N2ほど 形容词否定N1不如N2……ほど后面接否定
N1とN2と どちらが 形容词ですかN1和N2哪个更……？二选一比较
范围で Nが 一番 形容词です在……中，N最……一番表示最高级
どのNが 一番 形容词ですか哪个N最……？三者以上比较

1. N1はN2より～です：N1比N2更……

N1 + は + N2 + より + 形容词 + です

「より」表示比较的基准。这个句型用来说明N1在某方面比N2程度更高。

李さんは 森さんより 若いです。
小李比森先生年轻。
中国は 日本より 広いです。
中国比日本大。
この かばんは あの かばんより 高いです。
这个包比那个包贵。
今日は 昨日より 暑いです。
今天比昨天热。
「より」后面的对象是“被比较的基准”，不是更强的一方。更强的一方在「は」前。

2. N1よりN2のほうが～です：比起N1，N2更……

N1 + より + N2 + のほうが + 形容词 + です

这个句型和「N2はN1より～です」意思接近，但语气上更突出「N2のほう」。

森さんより 李さんのほうが 若いです。
比起森先生，小李更年轻。
日本より 中国のほうが 広いです。
比起日本，中国更大。
コーヒーより 紅茶のほうが 好きです。
比起咖啡，我更喜欢红茶。
「AよりBのほうが～」的重点是B更……。中文可以理解为“比A，B更……”。

3. N1はN2ほど～くないです：N1不如N2……

N1 + は + N2 + ほど + 形容词否定

「ほど」表示程度基准，后面必须接否定。整体意思是“N1没有N2那么……”。

東京は 北京ほど 寒くないです。
东京没有北京那么冷。
この 店は あの 店ほど 有名ではありません。
这家店没有那家店那么有名。
わたしは 李さんほど 日本語が 上手ではありません。
我的日语没有小李那么好。
「ほど」后面不能接肯定。不要说「東京は北京ほど寒いです」。要用否定：寒くないです。

4. N1とN2とどちらが～ですか：哪个更……？

N1 + と + N2 + と + どちらが + 形容词 + ですか

两者之间比较时，用「どちら」。回答时常用「Nのほうが～です」。

日本語と 英語と どちらが 難しいですか。
日语和英语哪个更难？
日本語のほうが 難しいです。
日语更难。
コーヒーと 紅茶と どちらが 好きですか。
咖啡和红茶你更喜欢哪个？
紅茶のほうが 好きです。
我更喜欢红茶。
「どちら」用于二选一；更口语可以说「どっち」。正式学习先用「どちら」。

5. Nの中でNが一番～です：在……中最……

范围 + の中で + N + が + 一番 + 形容词 + です

三者以上比较，表达“最……”时，用「一番」。

スポーツの中で サッカーが 一番 おもしろいです。
在运动中，足球最有意思。
日本料理の中で すしが 一番 好きです。
在日本菜里，我最喜欢寿司。
季節の中で 春が 一番 好きです。
四季之中，我最喜欢春天。
「の中で」表示比较范围。范围清楚时，也可以省略。

6. どのNが一番～ですか：哪个N最……？

どの + 名词 + が + 一番 + 形容词 + ですか

在三者以上的同类名词中询问“哪个最……”，用「どのN」。

日本料理の中で どの 料理が 一番 好きですか。
在日本菜中，你最喜欢哪道菜？
すしが 一番 好きです。
我最喜欢寿司。
この中で どの かばんが 一番 高いですか。
这里面哪个包最贵？
この 黒い かばんが 一番 高いです。
这个黑色的包最贵。
「どれ」可以单独用；「どの」后面必须接名词：どの料理、どのかばん。

7. 比较句里的形容词

比较句既可以用一类形容词，也可以用二类形容词，还可以用「好き」「上手」等表达。

类型例句中文
一类形容词今日は昨日より暑いです。今天比昨天热。
二类形容词この店はあの店より有名です。这家店比那家店有名。
好きコーヒーより紅茶のほうが好きです。比起咖啡，更喜欢红茶。
上手李さんは森さんより日本語が上手です。小李比森先生日语好。
二类形容词在比较句句末仍然直接接「です」：有名です、静かです、好きです。

第12课一句话记忆

第12课就是学“比……更……、不如……、哪个更……、哪个最……”。

李さんは森さんより若いです小李比森先生年轻
森さんより李さんのほうが若いです比起森先生，小李更年轻
東京は北京ほど寒くないです东京不如北京冷
日本語と英語とどちらが難しいですか日语和英语哪个难
サッカーが一番おもしろいです足球最有意思
どの料理が一番好きですか最喜欢哪道菜
