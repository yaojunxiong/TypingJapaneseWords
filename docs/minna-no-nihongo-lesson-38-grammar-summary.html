第38课核心语法

VのはVのがVのを动词名词化知っています

语法中文意思重点
动词辞书形＋のは做……这件事把动作变成主题
动词辞书形＋のが做……这件事作好き、上手、下手等的对象
动词辞书形＋のを做……这件事作宾语，常接忘れます、知っています
知っています / 知りません知道 / 不知道否定回答通常用知りません

1. 动词辞书形＋の：把动作变成名词

动词辞书形 + の

第38课的核心是用「の」把一个动作句变成名词成分。中文可以理解为“做……这件事”。

比如「日本語を勉強します」是一个动作句；「日本語を勉強するの」就变成“学日语这件事”。
原来的动作句名词化中文
日本語を勉強します日本語を勉強するの学日语这件事
料理を作ります料理を作るの做饭这件事
本を読みます本を読むの读书这件事
漢字を覚えます漢字を覚えるの记汉字这件事

2. Vのは＋形容词です：做……这件事很……

动词辞书形 + のは + 形容词です

「のは」把动作当作句子的主题。中文可以理解为“做……这件事……”。

日本語を勉強するのは楽しいです。
学日语很开心。
漢字を覚えるのは難しいです。
记汉字很难。
毎日運動するのは体にいいです。
每天运动对身体好。
朝早く起きるのは大変です。
早上早起很辛苦。
「のは」后面常接评价：楽しい、難しい、大変、体にいい、便利等。

3. Vのが好きです / 上手です：喜欢做…… / 擅长做……

动词辞书形 + のが + 好き・嫌い・上手・下手

当表达喜欢、讨厌、擅长、不擅长某个动作时，用「のが」。

私は料理を作るのが好きです。
我喜欢做饭。
弟は絵を描くのが上手です。
弟弟擅长画画。
私は人の前で話すのが苦手です。
我不擅长在人前讲话。
子どもは野菜を食べるのが嫌いです。
孩子讨厌吃蔬菜。
常用搭配中文
Vのが好きです喜欢做……
Vのが嫌いです讨厌做……
Vのが上手です擅长做……
Vのが下手です不擅长做……
Vのが苦手です不擅长 / 不喜欢做……

4. Vのを忘れました：忘记做……

动词辞书形 + のを + 忘れました

「のを」让动作变成宾语，后面常接「忘れます」「知っています」「覚えています」等动词。

電気を消すのを忘れました。
忘了关灯。
窓を閉めるのを忘れました。
忘了关窗户。
薬を飲むのを忘れてしまいました。
不小心忘了吃药。
宿題を出すのを忘れました。
忘了交作业。
这里不要说「電気を消すを忘れました」，必须用「のを」。

5. Vのを知っていますか：知道……这件事吗？

动词普通形 + のを + 知っていますか

表示知道某件事情。这里「の」把前面的句子变成“这件事”。

田中さんが結婚したのを知っていますか。
你知道田中结婚这件事吗？
来月、新しい駅ができるのを知っていますか。
你知道下个月会建成新车站这件事吗？
ミラーさんが会社を辞めたのを知っていますか。
你知道米勒辞职这件事吗？
如果后面是「見ました」「聞きました」等，也常用「のを」。例如：子どもが走っているのを見ました。= 看见孩子正在跑。

6. 知っています / 知りません

「知っています」表示“知道”。但是否定回答时，日语通常说「知りません」，不是「知っていません」。

问题回答中文
山田さんを知っていますか。はい、知っています。认识 / 知道
山田さんを知っていますか。いいえ、知りません。不认识 / 不知道
このニュースを知っていますか。いいえ、知りません。不知道这个新闻
「知りません」是自然回答；「知っていません」通常不作为普通的“不知道”回答。

7. のは・のが・のを 的区别

表达作用例句
Vのは做主题日本語を勉強するのは楽しいです。
Vのが做喜欢/擅长等的对象料理を作るのが好きです。
Vのを做宾语電気を消すのを忘れました。
简单记：は是主题，が常跟喜欢/擅长，を后面接忘记、知道、看见等动词。
