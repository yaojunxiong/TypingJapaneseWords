第44课核心语法

～すぎます～やすいです～にくいです～くします～にします

语法中文意思重点
～すぎます太……；过于……表示程度超过合适范围，常带负面感觉
～やすいです容易……；好……表示做某动作很容易
～にくいです难以……；不好……表示做某动作很困难
い形容词くします把……弄得……人为改变性质或状态
な形容词/名词にします把……变成……；决定要……表示改变状态，或点餐/选择

1. ～すぎます：太……；过于……

动词ます形去ます / い形容词去い / な形容词词干 + すぎます

「～すぎます」表示程度超过了合适的范围。中文可以理解成“太……了”“……过头了”。

这个表达常带“有点不好、过量、不合适”的感觉。
词类接法例子
动词ます形去ます＋すぎます食べすぎます
い形容词去い＋すぎます高すぎます
な形容词词干＋すぎます静かすぎます
昨日、お酒を飲みすぎました。
昨天酒喝太多了。
この服は高すぎます。
这件衣服太贵了。
この部屋は静かすぎて、少し寂しいです。
这个房间太安静了，有点寂寞。
ゲームをしすぎて、目が疲れました。
游戏玩太多了，眼睛累了。

2. ～すぎる 的名词形式：～すぎ

「～すぎます」可以变成名词形式「～すぎ」。常用于提醒、评价。

食べすぎは体に悪いです。
吃太多对身体不好。
働きすぎに気をつけてください。
请注意不要工作过度。
飲みすぎで、頭が痛いです。
因为喝太多，头疼。

3. ～やすいです：容易……；好……

动词ます形去ます + やすいです

表示某个动作容易做。中文常译为“容易……”“好……”。

动词やすい形中文
使います使いやすいです好用
飲みます飲みやすいです好喝 / 容易喝
読みます読みやすいです好读
わかりますわかりやすいです容易懂
このパソコンは使いやすいです。
这台电脑很好用。
先生の説明はわかりやすいです。
老师的说明很容易懂。
この本は字が大きくて、読みやすいです。
这本书字大，很好读。
「～やすい」像い形容词一样变化：使いやすい、使いやすくない、使いやすかった。

4. ～にくいです：难以……；不好……

动词ます形去ます + にくいです

表示某个动作难做。中文可以理解为“难以……”“不好……”。

动词にくい形中文
使います使いにくいです不好用
飲みます飲みにくいです不好喝 / 难喝下去
読みます読みにくいです难读
覚えます覚えにくいです难记
この漢字は覚えにくいです。
这个汉字很难记。
このペンは書きにくいです。
这支笔不好写。
この道は夜、歩きにくいです。
这条路晚上不好走。
「～にくい」也像い形容词一样变化：読みにくい、読みにくくない、読みにくかった。

5. ～やすい vs ～にくい

表达中文例句
読みやすい好读この本は読みやすいです。
読みにくい难读この字は読みにくいです。
使いやすい好用このスマホは使いやすいです。
使いにくい不好用このアプリは使いにくいです。
快速记：やすい = easy to do；にくい = difficult to do。

6. い形容词くします：把……弄得……

い形容词去い + くします

表示人为地把某个东西变成某种状态。中文是“把……弄得……”。

音を小さくしてください。
请把声音调小。
部屋を明るくします。
把房间弄亮。
髪を短くしました。
把头发剪短了。
説明をもっとわかりやすくしてください。
请把说明变得更容易懂。
「大きい→大きくします」「安い→安くします」「短い→短くします」。

7. な形容词 / 名词にします：把……变成……；决定要……

な形容词词干 / 名词 + にします

可以表示人为改变状态，也可以表示点餐、购物、选择时“决定要……”。

改变状态

部屋をきれいにします。
把房间打扫干净。
町を静かにしたいです。
想把城市变得安静。

选择、决定

コーヒーにします。
我要咖啡。
昼ご飯はカレーにします。
午饭决定吃咖喱。
会議は月曜日にします。
会议定在星期一。
点餐时「～にします」非常常用，比直接说「ください」更像“我决定选这个”。
