1. 尊敬語：抬高对方的说法

第49课学习的是 尊敬語。尊敬语用来表达对对方、客人、老师、上司、长辈等人的尊敬。

重点：尊敬语不是把自己说得更礼貌，而是把“对方的动作、状态、东西”抬高。自己的动作不用尊敬语。
普通说法尊敬语感觉中文
先生が来ます。先生がいらっしゃいます。老师来。
社長が言いました。社長がおっしゃいました。社长说了。
お客様が食べます。お客様が召し上がります。客人吃。

2. 受身形也可以表示尊敬

动词受身形 = 尊敬表达

第37课学过受身形“被……”。第49课里，同样的形式也可以表示尊敬。意思不是“被”，而是礼貌地说对方做某事。

普通形受身形尊敬中文
行きます行かれます去
帰ります帰られます回去
読みます読まれます读
書きます書かれます写
来ます来られます来
しますされます做
部長はもう帰られました。
部长已经回去了。
先生はこの本を読まれました。
老师读了这本书。
社長は明日大阪へ行かれます。
社长明天去大阪。
受身形尊敬比较容易造句，但有时可能和“被动”混淆，要看上下文判断。

3. お＋ます形＋になります：更郑重的尊敬语

お + 动词ます形去ます + になります

这是非常常用的尊敬语形式，比单纯用受身形更郑重。

先生はもうお帰りになりました。
老师已经回去了。
社長は新聞をお読みになります。
社长读报纸。
お客様は何時ごろお着きになりますか。
客人大约几点到达？
先生は毎朝散歩をお楽しみになります。
老师每天早上享受散步。
这个形式一般用于ます形去ます后有两个音节以上的动词。像「見ます」「寝ます」这种一个音节动词通常不用「お見になります」「お寝になります」。

4. 特别尊敬语：必须单独记

有些常用动词不用普通变化，而有专门的尊敬语。

5. 特别尊敬语的ます形变化

有几个尊敬语的ます形很特别，要注意。

辞书形ます形不是
いらっしゃるいらっしゃいますいらっしゃります
おっしゃるおっしゃいますおっしゃります
くださるくださいますくださります
なさるなさいますなさります
这几个虽然辞书形以「る」结尾，但ます形不是「ります」，而是「います」。

6. お＋ます形＋ください：请您……

お + 动词ます形去ます + ください

这是对对方的礼貌请求。中文可以理解为“请您……”。常用于店员、工作人员、正式通知。

こちらで少々お待ちください。
请在这里稍等。
この紙にお名前をお書きください。
请在这张纸上写您的名字。
どうぞお入りください。
请进。
この資料をお読みください。
请阅读这份资料。
比「待ってください」「書いてください」更郑重、更适合服务场景。

7. お / ご 的用法

尊敬语里经常给名词或动词加「お」「ご」。大致规律是：和语多用「お」，汉语词多用「ご」。

おご
お名前ご住所
お電話ご家族
お仕事ご意見
お帰りになりますご利用になります
お待ちくださいご確認ください
实际用法有固定搭配，遇到常用表达最好直接记整句。

8. 尊敬语不能用于自己的动作

尊敬语是抬高别人，所以不要用于自己的动作。

不自然自然中文
私はいらっしゃいます。私は参ります。/ 行きます。我去 / 我来。
私は召し上がります。私はいただきます。/ 食べます。我吃。
私はおっしゃいます。私は申します。/ 言います。我说。
第49课是尊敬语，抬高别人；第50课会学习謙譲語，把自己放低。
