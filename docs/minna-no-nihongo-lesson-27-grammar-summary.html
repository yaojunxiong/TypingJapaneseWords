《みんなの日本語 初級Ⅱ》第27课语法总结

手机网页阅读版｜可能形｜見えます・聞こえます｜しか～ません

第27课核心语法

可能形見えます聞こえますできますしか～ません

语法中文意思重点
可能形能……；会……；可以……表示能力或可能性
～が見えます看得见……自然进入视野，不是主动看
～が聞こえます听得见……声音自然传到耳朵，不是主动听
～ができます建成；做好；出现；交到朋友不是“能力”的できます，而是“产生/完成”
～しか～ません只……；仅仅……后面一定接否定

1. 可能形：表示“能……”

A は B が 可能形

可能形表示“有能力做某事”或“某事可以被做”。中文可以理解为“能……、会……、可以……”。

一类动词变化

把ます形前面的假名从 い段 改成 え段，再加ます。

ます形可能形中文
書きます書けます能写
読みます読めます能读
行きます行けます能去
話します話せます能说
買います買えます能买

二类动词变化

去掉ます，加 られます。

ます形可能形中文
食べます食べられます能吃
見ます見られます能看
起きます起きられます能起床
借ります借りられます能借

三类动词变化

ます形可能形中文
しますできます能做
来ます来られます能来
注意：普通动词常用「を」，变成可能形以后，很多时候用「が」。
日本語を話します。
说日语。
日本語が話せます。
会说日语。
私は日本語が少し話せます。
我会说一点日语。
このATMは夜も使えます。
这个ATM晚上也能使用。

2. ～が見えます：看得见……

名词 + が見えます

「見えます」表示东西自然进入眼睛，是“看得见”。重点不是“我主动去看”，而是“视野里能看到”。

表达中文区别
見ます看主动看
見えます看得见自然看见
窓から海が見えます。
从窗户看得见海。
ここから富士山が見えます。
从这里看得见富士山。
人が多くて、前が見えません。
人太多，看不见前面。

3. ～が聞こえます：听得见……

名词 + が聞こえます

「聞こえます」表示声音自然传到耳朵里，是“听得见”。不是主动听音乐、听说明。

表达中文区别
聞きます听；问主动听/询问
聞こえます听得见声音自然传来
鳥の声が聞こえます。
听得见鸟叫声。
隣の部屋から音楽が聞こえます。
从隔壁房间听得见音乐声。
電話の声がよく聞こえません。
电话里的声音听不太清楚。

4. ～ができます：建成 / 做好 / 出现

第27课的「できます」除了“能做”，还可以表示“产生、完成、建成、交到朋友”。

日语中文感觉
駅ができます车站建成新东西出现
スーパーができます超市建成新设施出现
友達ができます交到朋友关系产生
用事ができます有事了事情出现
料理ができます饭做好了完成
駅の前に大きいスーパーができました。
车站前建了一家大超市。
日本で友達ができました。
我在日本交到了朋友。
急に用事ができました。
突然有事了。

5. ～しか～ません：只……

名词 / 数量词 + しか + 否定形

「しか」表示“只有……”。它的特点是：后面必须用否定，但中文翻译成肯定的“只有”。

表达后面形式语感
だけ肯定、否定都可以客观说“只”
しか必须接否定常带“不多、不够”的感觉
私は日本語が少ししか話せません。
我只会说一点日语。
財布に1000円しかありません。
钱包里只有1000日元。
この店は日曜日しか休みません。
这家店只有星期天休息。
对比：日本語が少し話せます = 我会说一点日语。日本語が少ししか話せません = 我只会说一点日语，语气更像“不太够”。
