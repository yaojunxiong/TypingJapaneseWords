句型中文意思重点

二类形容词で、二类形容词です又……又……二类形容词后接で
名词で、名词です是……，也是……名词连接用で
Vています处于某种状态不只是“正在做”

1. 一类形容词くて：又……又……

一类形容词去い + くて + 形容词/句子

想把两个一类形容词连接起来时，把前一个形容词的「い」变成「くて」。

ホテルの 部屋は 広くて 明るいです。
酒店的房间又宽敞又明亮。
この りんごは 大きくて 甘いです。
这个苹果又大又甜。
この 料理は 安くて おいしいです。
这道菜又便宜又好吃。
变化方法：広い → 広くて；明るい → 明るくて；おいしい → おいしくて。

2. 二类形容词で：又……又……

二类形容词 + で + 形容词/句子

二类形容词连接时，不用「くて」，而是在后面接「で」。

この ホテルは きれいで 静かです。
这家酒店又干净又安静。
小野さんは 親切で 元気です。
小野女士又亲切又有精神。
この 町は 便利で にぎやかです。
这个城市又方便又热闹。
二类形容词句末：きれいです。连接：きれいで。修饰名词：きれいな部屋。

3. 名词で：是……，也是……

名词 + で + 名词/句子

名词句连接时，也用「で」。可以表示同一个人或事物具有两个身份、两个属性。

森さんは 旅行会社の 社員で、営業部の 部長です。
森先生是旅行社的职员，也是营业部部长。
これは 日本製で、とても 丈夫です。
这是日本制造，而且很结实。
父は 医者で、母は 教師です。
父亲是医生，母亲是老师。
「名词で」可以连接后句，但前后主语不同也可以：父は医者で、母は教師です。

4. Vています：表示结果状态

动词て形 + います

第15课学过「ています」表示正在进行。第16课要注意：有些动词加「ています」表示“动作完成后留下的状态”。

森さんは 車を 持っています。
森先生有车。
李さんは 東京に 住んでいます。
小李住在东京。
わたしは 結婚しています。
我已经结婚了。
田中さんは 眼鏡を かけています。
田中先生戴着眼镜。
「持っています」不是“正在拿着”的唯一意思，常表示“拥有”。「住んでいます」表示居住状态。

5. まだVていません：还没有……

まだ + 动词て形 + いません

表示某事还没有完成时，用「まだ～ていません」。

李さんは まだ 来ていません。
小李还没有来。
宿題は まだ 終わっていません。
作业还没有完成。
朝ご飯は まだ 食べていません。
早饭还没有吃。
第8课的「まだです」是简短回答；完整表达可以用「まだVていません」。

6. 句子が、句子：但是……

句子 + が + 句子

「が」放在两个句子之间，可以表示轻微转折，中文常翻译为“但是”。

この 部屋は 広いですが、少し 暗いです。
这个房间很宽敞，但是有点暗。
日本語は 難しいですが、おもしろいです。
日语很难，但是很有意思。
この 店は 有名ですが、高いです。
这家店很有名，但是很贵。
这里的「が」比「でも」更常用于一个句子内部连接。

7. 形容词连接总结

类型连接方法例子
一类形容词い → くて広い → 広くて
二类形容词直接加できれい → きれいで
名词直接加で社員 → 社員で
いいよくてこの部屋はよくて安いです
「いい」特殊：いい → よくて，不是「いくて」。

11. 中国学习者容易错的地方

错误正确说明
広いて明るいです。広くて明るいです。一类形容词い变くて
きれいくて静かです。きれいで静かです。きれい是二类形容词
社員て部長です。社員で部長です。名词连接用で
森さんは車を持ちます。森さんは車を持っています。表示拥有常用持っています
李さんは東京に住みます。李さんは東京に住んでいます。表示居住状态用住んでいます
まだ来ませんでした。まだ来ていません。“还没有来”常用まだ来ていません

第16课一句话记忆

第16课就是学“把形容词、名词连接起来”，以及「ています」表示状态。

広くて明るいです又宽敞又明亮
きれいで静かです又干净又安静
社員で部長です是职员，也是部长
車を持っています有车
東京に住んでいます住在东京
