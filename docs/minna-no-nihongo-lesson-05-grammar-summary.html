语法中文意思重点
名词へ 行きます去……へ表示移动方向，读作え
名词へ 来ます来……表示来到某地
名词へ 帰ります回……表示回家、回国、回公司等
交通工具で 行きます乘……去で表示交通手段
人と 行きます和……一起去と表示共同动作对象

1. 場所へ行きます：去某地

地点名词 + へ + 行きます

「へ」表示移动的方向，写作「へ」，作为助词时读作 え。第5课开始学习移动动词：行きます、来ます、帰ります。

わたしは 京都へ 行きます。
我去京都。
サントスさんは 会社へ 行きます。
桑托斯先生去公司。
学生は 学校へ 行きます。
学生去学校。
「へ」强调方向，“朝……去”。实际会话中也常用「に」，但第5课重点先掌握「へ」。

2. 行きます・来ます・帰ります

这三个动词都表示移动，但方向不同。

动词假名中文例句
行きますいきます去東京へ行きます。
来ますきます来日本へ来ました。
帰りますかえります回去；回家；回国うちへ帰ります。
ミラーさんは アメリカから 来ました。
米勒先生从美国来了。
わたしは うちへ 帰ります。
我回家。
来週、国へ 帰ります。
下周回国。

3. どこへ行きますか：去哪里？

どこ + へ + 行きますか

询问移动目的地时，用「どこへ」。

どこへ 行きますか。
去哪里？
大阪へ 行きます。
去大阪。
日曜日 どこへ 行きましたか。
星期天去了哪里？
どこも 行きませんでした。
哪里也没去。
「どこも行きません」= 哪里也不去；「どこも行きませんでした」= 哪里也没去。

4. 交通工具で行きます：乘……去

交通工具 + で + 行きます / 来ます / 帰ります

助词「で」表示手段、方法。第5课中常用于交通工具。

交通工具假名中文
電車でんしゃ电车
地下鉄ちかてつ地铁
新幹線しんかんせん新干线
バスバス公交车
タクシータクシー出租车
自転車じてんしゃ自行车
飛行機ひこうき飞机
船ふね船
わたしは 電車で 会社へ 行きます。
我乘电车去公司。
ミラーさんは 新幹線で 京都へ 行きました。
米勒先生坐新干线去了京都。
山田さんは タクシーで うちへ 帰りました。
山田先生坐出租车回家了。
如果是走路，不用「足で」，而说「歩いて」。例如：歩いて行きます = 走路去。

5. 何で行きますか：坐什么去？

何 + で + 行きますか

询问交通手段时，用「何で」。这里的「何」通常读作「なん」。

何で 京都へ 行きますか。
坐什么去京都？
新幹線で 行きます。
坐新干线去。
何で 会社へ 行きますか。
坐什么去公司？
地下鉄で 行きます。
坐地铁去。
「何で」也可能表示“为什么”，但第5课在交通语境中就是“用什么交通工具”。

6. 人と行きます：和……一起去

人 + と + 行きます / 来ます / 帰ります

助词「と」表示共同动作的对象，中文是“和……一起”。

わたしは 友達と 京都へ 行きます。
我和朋友去京都。
家族と 日本へ 来ました。
我和家人来到了日本。
山田さんは だれと 帰りましたか。
山田先生和谁回去了？
一人で 帰りました。
一个人回去了。
「一人で」= 一个人。这里不用「一人と」。

7. いつ行きますか：什么时候去？

いつ + 行きますか

「いつ」表示“什么时候”。用来询问日期、时间、时期。

いつ 日本へ 来ましたか。
什么时候来日本的？
3月25日に 来ました。
3月25日来的。
いつ 京都へ 行きますか。
什么时候去京都？
来週 行きます。
下周去。
「いつ」后不加「に」。不能说「いつに行きますか」。具体日期、具体时间常加「に」：3月25日に、7時に。

8. 时间词 + に：在某日/某时

具体时间 + に + 动词

具体日期、具体钟点后常加「に」。

加に通常不加に
7時に今日
月曜日に昨日
3月25日に明日
誕生日に来週
7時に 起きます。
7点起床。
月曜日に 大阪へ 行きます。
星期一去大阪。
来週 京都へ 行きます。
下周去京都。
「来週に」不是绝对错误，但初级阶段先记：今日、明日、昨日、来週、先週等相对时间通常不加に。

9. 誕生日はいつですか：生日是什么时候？

誕生日 + は + いつ + ですか

第5课还会练习日期和生日。

誕生日は いつですか。
生日是什么时候？
6月13日です。
6月13日。
ミラーさんの 誕生日は いつですか。
米勒先生的生日是什么时候？
9月1日です。
9月1日。
日期读法有很多特殊读音，如1日ついたち、2日ふつか、3日みっか、4日よっか、20日はつか，需要单独记。
