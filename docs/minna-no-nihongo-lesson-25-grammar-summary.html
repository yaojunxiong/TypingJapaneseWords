1. ～たら：如果……的话

普通形过去 + ら

「～たら」表示条件，中文常翻译成“如果……的话”。它看起来像过去形，但在这里不一定表示过去。

雨が 降ったら、出かけません。
如果下雨，就不出门。
時間が あったら、映画を 見ます。
如果有时间，就看电影。
安かったら、買います。
如果便宜，就买。
暇だったら、手伝ってください。
如果有空，请帮忙。

2. たら 的接续

类型接法例子
动词た形＋ら行ったら、飲んだら、食べたら
い形容词去い＋かったら高かったら、寒かったら、よかったら
な形容词词干＋だったら便利だったら、暇だったら
名词名词＋だったら雨だったら、日曜日だったら
特别注意：いい → よかったら。常用于邀请：よかったら、一緒に行きませんか。

3. ～たら：……之后

「たら」也可以表示“……之后”。前项动作完成后，做后项动作。

仕事が 終わったら、飲みに 行きます。
工作结束后，去喝一杯。
駅に 着いたら、電話してください。
到车站后，请给我打电话。
昼ご飯を 食べたら、出かけます。
吃完午饭后，出门。

4. ～ても：即使……也……

动词て形＋も / い形くても / な形・名词でも

「～ても」表示逆接条件，后面的结果和一般预想相反。

雨が 降っても、出かけます。
即使下雨，也出门。
高くても、買います。
即使贵，也买。
忙しくても、毎日 日本語を 勉強します。
即使忙，也每天学习日语。
日曜日でも、仕事を します。
即使是星期天，也工作。

5. もし～たら / いくら～ても

もし 强调假设；いくら 强调“无论程度多高”。

もし お金が たくさん あったら、世界を 旅行したいです。
如果有很多钱，我想环游世界。
もし 明日 雨だったら、うちに います。
如果明天下雨，我待在家。
いくら 勉強しても、漢字を 覚えることが できません。
无论怎么学习，也记不住汉字。
いくら 安くても、要りません。
无论多便宜，也不需要。
