第32课核心句型

Vる/VないつもりですVることにしますVることになりました小句そうですによると予定です

句型中文意思重点
Vる/Vない つもりです打算做/不做……个人意向、主观计划
Vることにします决定做……自己做出的决定
Vることになりました决定为……；规定为……外部决定、组织安排、自然结果
小句简体＋そうです听说……传闻，不是样态
名词＋によると据……说/根据……说明信息来源
Vる/Nの 予定です预定……客观日程、安排

1. Vる/Vないつもりです：打算做/不做

动词基本形 + つもりです / 动词ない形 + つもりです

表示说话人比较明确的个人计划或打算。

今度の 日曜日に 遊園地へ 行くつもりです。
这个星期天打算去游乐园。
来年、日本へ 留学するつもりです。
明年打算去日本留学。
今日は お酒を 飲まないつもりです。
今天打算不喝酒。
「つもりです」偏主观意向：“我心里是这样打算的”。

2. Vることにします：决定做……

动词基本形/ない形 + ことにします

表示说话人自己决定做或不做某事。

明日から 毎日 運動することにします。
我决定从明天开始每天运动。
今年の 夏休みは 旅行しないことにしました。
今年暑假决定不去旅行了。
健康のために、タバコを やめることにしました。
为了健康，我决定戒烟了。
「ことにしました」常表示“已经决定了”。它比「つもりです」更强调决定这个动作。

3. Vることになりました：决定为……；规定为……

动词基本形/ない形 + ことになりました

表示某件事被决定下来，常常不是说话人一个人决定，而是公司、学校、规则、情况发展后的结果。

来月から 給料が 上がることになりました。
从下个月起工资决定要涨了。
来週、大阪へ 出張することになりました。
下周决定去大阪出差。
この 教室では 食事しないことになっています。
这个教室规定不能吃东西。
「ことになりました」偏“事情被定下来了”；「ことにしました」偏“我决定了”。

4. ことにします vs ことになります

表达核心意思例句
ことにします自己决定毎日運動することにします。
ことにしました自己已经决定旅行しないことにしました。
ことになりました被安排/被决定大阪へ出張することになりました。
ことになっています规定、惯例ここでは禁煙することになっています。
记忆：にします＝我来决定；になります＝事情变成这样的安排。

5. 小句＋そうです：听说……

小句简体 + そうです

表示从别人、新闻、通知等听来的信息。中文是“听说……”。

馬さんの 息子さんは 今年 小学校に 入学するそうです。
听说小马的儿子今年上小学。
天気予報によると、明日は 雨が 降るそうです。
据天气预报说，明天会下雨。
李さんは 来月 中国へ 帰るそうです。
听说小李下个月回中国。
这里的「そうです」是“传闻”。它和第33课以后常见的“看起来……”的「そうです」用法不同。

6. によると：据……说 / 根据……

信息来源 + によると + 小句そうです

说明消息来源时，用「によると」。常和「そうです」一起使用。

ニュースによると、今年の 冬は 寒いそうです。
据新闻说，今年冬天会很冷。
先生の 話によると、試験は 来週だそうです。
据老师说，考试是下周。
新聞によると、駅前に 新しい デパートが できるそうです。
据报纸说，车站前会建新的百货商店。
「によると」后面常接传闻、判断、说明，不直接接命令或请求。

7. 予定です：预定……

动词基本形 + 予定です / 名词 + の + 予定です

表示客观日程或安排，常用于会议、出差、旅行、航班等。

午後、会議を 開く予定です。
下午预定开会。
来週は 出張の 予定です。
下周有出差的安排。
飛行機は 6時に 到着する予定です。
飞机预定6点到达。
名词接「予定」时用「の」：出張の予定、会議の予定。

8. つもり・予定・ことにします 对比

表达感觉例句
行くつもりです我打算去日曜日に行くつもりです。
行く予定です日程上预定去日曜日に行く予定です。
行くことにしました我决定去日曜日に行くことにしました。
行くことになりました被安排/决定要去日曜日に行くことになりました。
个人心意＝つもり；客观安排＝予定；自己决定＝ことにします；外部决定＝ことになります。

9. そうです的接续

前接例子中文
动词简体入学するそうです听说入学
一类形容词寒いそうです听说冷
二类形容词静かだそうです听说安静
名词休みだそうです听说是休息日
否定行かないそうです听说不去
过去行ったそうです听说去了
传闻「そうです」前面用简体。名词和二类形容词现在肯定要保留「だ」。

第32课一句话记忆

第32课就是学“我打算、我决定、事情被决定、听说”。注意「ことにします」和「ことになります」视角不同。

遊園地へ行くつもりです打算去游乐园
運動することにします决定运动
出張することになりました被安排出差
入学するそうです听说要入学
天気予報によると、雨だそうです据天气预报说明天有雨
来週は出張の予定です下周预定出差
