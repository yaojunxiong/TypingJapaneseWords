第8课核心句型

NでVます语言でVます人に物をあげます人に/から物をもらいますもうVましたまだです

句型中文意思重点
名词で 动词ます用……做……で表示工具、手段、材料、语言
言語で 手紙を書きます用某种语言写信日本語で、中国語で、英語で
人に 物を あげます给某人某物主语把东西给别人
人に/から 物を もらいます从某人那里得到某物主语是接受方
もう 动词ました已经做了……常用于确认完成
まだです还没有回答“もう～ましたか”

1. NでVます：用……做……

工具/手段 + で + 动词ます

助词「で」可以表示动作使用的工具、手段或方式。中文常翻译为“用……”。

李さんは 日本語で 手紙を 書きます。
小李用日语写信。
わたしは ペンで 名前を 書きます。
我用钢笔写名字。
森さんは 電話で 友達と 話します。
森先生用电话和朋友说话。
小野さんは はさみで 紙を 切ります。
小野女士用剪刀剪纸。
第7课「場所で」表示动作地点；第8课「工具で」表示工具手段。都是で，但意思要看前面的名词。

2. 语言でVます：用某种语言做事

日本語で / 中国語で / 英語で + 动词

语言也可以看作一种“手段”，所以用「で」。

日本語で 手紙を 書きます。
用日语写信。
中国語で 話します。
用中文说话。
英語で メールを 書きました。
用英语写了邮件。
これは 日本語で 何ですか。
这个用日语怎么说？
「日本語を話します」= 说日语；「日本語で話します」= 用日语说。两种都能见到，但本课重点是「语言で」。

3. 人に物をあげます：给某人某物

人 + に + 物 + を + あげます

「あげます」表示主语把东西给别人。接受者用「に」，给的东西用「を」。

わたしは 小野さんに お土産を あげました。
我给了小野女士礼物。
李さんは 森さんに チョコレートを あげました。
小李给了森先生巧克力。
母に 花を あげます。
给妈妈花。
不要用「あげます」说“别人给我”。别人给我在后面会学「くれます」。本课先掌握“我/主语给别人”。

4. 人に/から物をもらいます：从某人那里得到某物

人 + に/から + 物 + を + もらいます

「もらいます」表示主语从别人那里得到东西。给的人可以用「に」，也可以用「から」。

わたしは 小野さんに 辞書を もらいました。
我从小野女士那里得到了词典。
李さんは 友達から 写真を もらいました。
小李从朋友那里得到了照片。
森さんは 会社から 記念品を もらいました。
森先生从公司得到了纪念品。
如果来源是机构、组织，用「から」更自然：会社から、学校から。

5. あげます vs もらいます

动词主语方向例句
あげます给的人主语 → 别人わたしは友達に本をあげました。
もらいます得到的人别人 → 主语わたしは友達に本をもらいました。
看主语是谁：主语给出去，用「あげます」；主语收到，用「もらいます」。

6. もうVました：已经做了……

もう + 动词ました

「もう」表示“已经”。常用于确认某件事是否完成。

もう 昼ご飯を 食べました。
已经吃午饭了。
李さんは もう 手紙を 書きました。
小李已经写信了。
宿題は もう 終わりました。
作业已经结束了。
「もう」后面常接过去形「ました」，表示动作已经完成。

7. もうVましたか / まだです

もう + 动词ましたか 用来问“已经……了吗？”

もう 昼ご飯を 食べましたか。
已经吃午饭了吗？
はい、もう 食べました。
是的，已经吃了。
もう レポートを 書きましたか。
报告已经写了吗？
いいえ、まだです。
不，还没有。
「まだです」是省略回答，完整意思接近「まだ書いていません」。初级阶段先记固定回答即可。
