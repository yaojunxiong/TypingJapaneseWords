第8课核心语法

い形容词な形容词～はどうですかとても・あまりそして・が

语法中文意思重点
N は い形容词ですN很……い形容词直接接です
N は な形容词ですN很……な形容词作谓语时不加な
い形容词 + 名词……的名词直接修饰名词：新しい車
な形容词 + な + 名词……的名词修饰名词时加な：きれいな人
あまり～くないです / じゃありません不太……あまり后接否定

1. 形容词分两类：い形容词・な形容词

第8课开始学习形容词。日语形容词主要分为两类：い形容词 和 な形容词。

类别特点例子
い形容词基本以い结尾大きい、小さい、新しい、古い、暑い、寒い
な形容词修饰名词时加なきれい、静か、にぎやか、有名、便利、元気
注意：「きれい」虽然以い结尾，但它是な形容词，不是い形容词。

2. N は い形容词です：N很……

名词 + は + い形容词 + です

い形容词作谓语时，直接接「です」。

東京は 大きいです。
东京很大。
この本は 新しいです。
这本书是新的。
今日は 暑いです。
今天很热。
この料理は おいしいです。
这道菜很好吃。
い形容词本身有“是……的”感觉，礼貌句末加です即可。

3. N は な形容词です：N很……

名词 + は + な形容词 + です

な形容词作谓语时，后面直接接「です」，不加「な」。

奈良は 静かです。
奈良很安静。
この町は にぎやかです。
这个城市很热闹。
富士山は 有名です。
富士山很有名。
この部屋は きれいです。
这个房间很干净 / 漂亮。
不要说「静かなです」。作谓语时是「静かです」，修饰名词时才是「静かな町」。

4. 形容词修饰名词

形容词可以放在名词前面，表示“……的名词”。

类别接法例子中文
い形容词い形容词 + 名词新しい車新的车
い形容词い形容词 + 名词大きい町大的城市
な形容词な形容词 + な + 名词静かな町安静的城市
な形容词な形容词 + な + 名词きれいな人漂亮的人
これは 新しいカメラです。
这是新的相机。
奈良は 静かな町です。
奈良是安静的城市。
大阪は にぎやかな町です。
大阪是热闹的城市。
记忆：な形容词修饰名词时，需要“な”来连接。

5. ～はどうですか：……怎么样？

名词 + は + どう + ですか

询问对某事物的评价、印象时，用「どうですか」。

日本の生活は どうですか。
日本的生活怎么样？
楽しいです。
很开心 / 很愉快。
日本語の勉強は どうですか。
日语学习怎么样？
難しいですが、おもしろいです。
虽然难，但是很有意思。
「どう」不是问地点，也不是问东西，而是问“状态、评价、感觉”。

6. とても・あまり：很 / 不太

第8课常用副词：「とても」表示“很”，「あまり」表示“不太”，但「あまり」后面要接否定。

副词中文后面接例句
とても很，非常肯定とても暑いです。
あまり不太否定あまり暑くないです。
この映画は とてもおもしろいです。
这部电影非常有意思。
この映画は あまりおもしろくないです。
这部电影不太有意思。
この町は とても静かです。
这个城市非常安静。
この町は あまり静かじゃありません。
这个城市不太安静。
あまり + 肯定 不自然。要说「あまり～ないです / じゃありません」。

7. い形容词否定：～くないです

い形容词去い + くないです

い形容词变否定时，把最后的「い」变成「くないです」。

肯定否定中文
暑いです暑くないです不热
寒いです寒くないです不冷
新しいです新しくないです不新
おもしろいですおもしろくないです没意思
いいですよくないです不好
特别注意：「いい」的否定不是「いくない」，而是「よくないです」。

8. な形容词否定：～じゃありません

な形容词 + じゃありません

な形容词变否定时，和名词句类似，用「じゃありません」。

肯定否定中文
静かです静かじゃありません不安静
便利です便利じゃありません不方便
有名です有名じゃありません不有名
きれいですきれいじゃありません不干净 / 不漂亮
この部屋は あまりきれいじゃありません。
这个房间不太干净。
この店は あまり有名じゃありません。
这家店不太有名。

9. そして・が：而且 / 但是

第8课会用连接词把两个评价连起来。

连接词中文关系
そして而且；然后顺接，补充同方向评价
が但是转折，前后评价不同方向
この部屋は 広いです。そして、きれいです。
这个房间很宽敞。而且很干净。
日本語は 難しいですが、おもしろいです。
日语虽然难，但是很有意思。
この店は 安いですが、あまりおいしくないです。
这家店便宜，但是不太好吃。
句子中的「が」可表示“但是”，语气比中文的“但是”更柔和。

11. 中国学习者容易错的地方

错误正确说明
静かなです。静かです。な形容词作谓语不加な
きれい人です。きれいな人です。な形容词修饰名词要加な
新しいな車です。新しい車です。い形容词修饰名词不加な
暑いじゃありません。暑くないです。い形容词否定用くない
便利くないです。便利じゃありません。な形容词否定用じゃありません
いいくないです。よくないです。いい的否定是よくない
あまりおもしろいです。あまりおもしろくないです。あまり后接否定
