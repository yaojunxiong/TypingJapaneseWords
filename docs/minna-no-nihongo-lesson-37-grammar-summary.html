1. 受身形：被……

动词被动形

受身形表示“被……”。日语里被动句常从“受影响的人/物”的角度来表达。

一类动词变化

把ない形的「ない」换成 れる。

辞书形ない形被动形中文
書く書かない書かれる被写
読む読まない読まれる被读
呼ぶ呼ばない呼ばれる被叫
踏む踏まない踏まれる被踩
取る取らない取られる被拿走

二类动词变化

去掉「る」，加 られる。

辞书形被动形中文
食べる食べられる被吃
見る見られる被看
ほめるほめられる被表扬

三类动词变化

辞书形被动形中文
するされる被做
来る来られる被来访 / 来
二类动词的被动形和可能形形式一样，如「見られる」。要根据句子意思判断是“能看”还是“被看”。

2. AはBに～られます：A被B……

A は B に 被动形

这是最基本的被动句。B是动作发出者，A是被动作影响的人或物。

私は先生にほめられました。
我被老师表扬了。
私は母にしかられました。
我被妈妈批评了。
弟は犬にかまれました。
弟弟被狗咬了。
动作发出者用「に」。例如：先生にほめられました = 被老师表扬。

3. 受害被动：被……弄得困扰

日语里很常用被动形表达“某件事让我受到了影响/困扰”。中文不一定直接翻译成“被”，但日语会用被动。

電車で足を踏まれました。
在电车上脚被踩了。
雨に降られました。
被雨淋了 / 遇上下雨了，很困扰。
友達に来られて、勉強できませんでした。
朋友来了，害得我没法学习。
受害被动常有“不方便、困扰、倒霉”的感觉。比如「雨に降られました」不是雨主动攻击我，而是“我被下雨这件事影响了”。

4. 所有物被动：我的东西被……

私は 人に 所有物を 被动形

当自己的东西被别人拿走、弄坏、踩到时，日语常以“我”为主语。

私は弟にカメラを壊されました。
我的相机被弟弟弄坏了。
私は誰かに財布を取られました。
我的钱包被人拿走了。
私は子どもに服を汚されました。
我的衣服被孩子弄脏了。
中文常说“我的相机被弄坏了”，日语常说“我被弟弟弄坏了相机”：私は弟にカメラを壊されました。

5. 物/作品が～られます：客观说明

介绍建筑、作品、发明、发现时，常用被动形。这个用法不一定有“受害”感觉，只是客观说明“被建造/被制作/被发现”。

このお寺は500年前に建てられました。
这座寺庙是500年前建造的。
この絵は有名な画家によって描かれました。
这幅画是由有名的画家画的。
この歌は多くの人に歌われています。
这首歌被很多人唱。
客观说明中，动作发出者可以用「に」或「によって」。介绍作品创作者时常用「によって」。

6. 被动句和主动句对比

主动句被动句
先生が私をほめました。
老师表扬了我。		私は先生にほめられました。
我被老师表扬了。
犬が弟をかみました。
狗咬了弟弟。		弟は犬にかまれました。
弟弟被狗咬了。
誰かが財布を取りました。
有人拿走了钱包。		私は誰かに財布を取られました。
我的钱包被人拿走了。
主动句重点是“谁做了动作”；被动句重点是“谁受到了影响”。
