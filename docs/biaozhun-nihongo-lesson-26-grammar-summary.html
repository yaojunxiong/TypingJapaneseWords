第26课核心句型

小句＋のは形です小句＋のをVでしょうかもしれませんもしかしたらそれで

句型中文意思重点
小句（简体）＋のは＋形容词です做……这件事很……「の」把小句名词化
小句（简体）＋のを＋动词看见/听见/知道……这件事名词化后作宾语
小句＋でしょう……吧 / 大概……推测、确认
小句＋かもしれません也许…… / 可能……可能性比でしょう更不确定
もしかしたら说不定，也许常和かもしれません一起用
それで因此，所以说明前因后果

1. 小句＋のは＋形容词です：做……很……

动词简体小句 + の + は + 形容词です

「の」可以把前面的动词小句变成名词，相当于“做……这件事”。

自転車に 2人で 乗るのは 危ないです。
两个人骑一辆自行车很危险。
日本語で 手紙を 書くのは 難しいです。
用日语写信很难。
毎朝 早く 起きるのは 大変です。
每天早起很辛苦。
みんなで 食事するのは 楽しいです。
大家一起吃饭很开心。
这里的「の」不是“的”，而是把“乗る、書く、起きる”等动作变成“这件事”。

2. 小句＋のが＋形容词です：喜欢/擅长/不擅长做……

动词简体小句 + の + が + 好きです/上手です/下手です

表示喜欢、擅长、不擅长某个动作时，常用「のが」。

わたしは 音楽を 聞くのが 好きです。
我喜欢听音乐。
李さんは 絵を かくのが 上手です。
小李擅长画画。
森さんは 人前で 話すのが 苦手です。
森先生不擅长在人前讲话。
第11课学过「Nが好きです」，这里把动词小句变成名词后，也能接「が好きです」。

3. 小句＋のを＋动词：把“这件事”作为宾语

动词简体小句 + の + を + 見ます/聞きます/知っています/忘れます

当“看见、听见、知道、忘记”的对象是一件事时，可以用「のを」。

李さんが 車から 降りるのを 見ました。
我看见小李从车上下来了。
小野さんが 歌うのを 聞きました。
我听见小野女士唱歌了。
森さんが 結婚したのを 知っていますか。
你知道森先生结婚了吗？
電気を 消すのを 忘れました。
忘记关灯了。
「見る/聞く」看到或听到的是一个动作发生，所以用「のを」。

4. のは / のが / のを 的区别

形式用法例句
のは把动作整体作主题早く起きるのは大変です。
のが作喜欢、擅长等的对象泳ぐのが好きです。
のを作看见、听见、知道、忘记等的宾语来るのを見ました。
先把“动词小句＋の”看成一个大名词，再根据句子需要接は、が、を。

5. でしょう：大概……吧

简体小句 + でしょう

「でしょう」表示推测，中文常译为“大概……吧”。也可以用来向对方确认。

明日は 雨でしょう。
明天大概会下雨吧。
李さんは もう 会社を 出たでしょう。
小李大概已经离开公司了吧。
この 辺は 静かでしょう。
这一带很安静吧。
口语中常说「でしょ」。正式学习和书面语先掌握「でしょう」。

6. かもしれません：也许…… / 可能……

简体小句 + かもしれません

表示可能性不高或不确定的推测时，用「～かもしれません」。

森さんは 今日 会社を 休むかもしれません。
森先生今天可能不上班。
午後から 雨が 降るかもしれません。
下午可能会下雨。
この 道は 込んでいるかもしれません。
这条路可能很堵。
もしかしたら、今日は 来られないかもしれません。
说不定今天可能来不了。
「かもしれません」比「でしょう」更不确定，中文有“也许、说不定”的感觉。

7. 名词/二类形容词＋かもしれません

名词和二类形容词现在肯定接「かもしれません」时，通常不加「だ」。

类型例句中文
名词あの人は 先生かもしれません。那个人可能是老师。
二类形容词この 問題は 簡単かもしれません。这个问题可能简单。
一类形容词明日は 暑いかもしれません。明天可能热。
动词李さんは 来ないかもしれません。小李可能不来。
「だと思います」要加だ，但「かもしれません」前名词/二类形容词通常不加だ。

8. それで：因此，所以

前句。+ それで + 后句。

「それで」用于说明前面的情况导致后面的结果。

昨日は 熱が ありました。それで、会社を 休みました。
昨天发烧了。因此没去上班。
電車が 遅れました。それで、会議に 遅刻しました。
电车晚点了。所以会议迟到了。
「それで」重点是因果关系，不是单纯的时间顺序。

第26课一句话记忆

第26课就是学“把动作变成一件事”，再说这件事很危险、喜欢、看见、听见；同时学习“可能、大概”的推测。

自転車に2人で乗るのは危ないです两个人骑一辆自行车很危险
音楽を聞くのが好きです喜欢听音乐
降りるのを見ました看见下车
明日は雨でしょう明天大概会下雨吧
休むかもしれません可能休息
先生かもしれません可能是老师
