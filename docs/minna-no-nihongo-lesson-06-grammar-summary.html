第6课核心语法

名词を动词場所で动词一緒に～ませんか～ましょう

语法中文意思重点
名词を 动词做某事；吃/喝/看……を提示动作对象，读作お
場所で 动词在某地做动作で表示动作发生的场所
一緒に～ませんか一起……好吗？礼貌邀请别人
～ましょう一起……吧积极提议或回应邀请
何をしますか做什么？询问动作内容

1. 名词を动词：吃/喝/看/做……

名词 + を + 他动词

助词「を」提示动作的对象，写作「を」，读作 お。第6课开始大量使用“对某个东西做动作”的句子。

ご飯を 食べます。
吃饭。
水を 飲みます。
喝水。
映画を 見ます。
看电影。
日本語を 勉強します。
学习日语。
「を」前面是被动作影响的对象：食べる对象是ご飯，飲む对象是水，見る对象是映画。

2. 何をしますか：做什么？

何 + を + しますか

询问对方做什么时，用「何をしますか」。这里「何」常读作「なに」。

日曜日、何を しますか。
星期天做什么？
映画を 見ます。
看电影。
昨日、何を しましたか。
昨天做了什么？
友達と サッカーを しました。
和朋友踢了足球。
「します」可以单独表示“做”，也可以和名词组成动词：勉強します、買い物します、散歩します。

3. 場所で动词：在某地做动作

地点 + で + 动词

助词「で」表示动作发生的场所。中文是“在……做……”。

駅で 新聞を 買います。
在车站买报纸。
レストランで 昼ご飯を 食べます。
在餐厅吃午饭。
うちで テレビを 見ます。
在家看电视。
学校で 日本語を 勉強します。
在学校学习日语。
第5课的「交通工具で」表示手段；第6课的「場所で」表示动作地点。意思不同，但都是助词「で」。

4. どこで～ますか：在哪里做？

どこ + で + 动词ますか

询问动作发生的地点时，用「どこで」。

どこで 昼ご飯を 食べますか。
在哪里吃午饭？
食堂で 食べます。
在食堂吃。
どこで その本を 買いましたか。
在哪里买了那本书？
本屋で 買いました。
在书店买的。
问“东西在哪里”用「どこ」：トイレはどこですか。问“在哪里做动作”用「どこで」：どこで食べますか。

5. 一緒に～ませんか：一起……好吗？

一緒に + 动词ませんか

「～ませんか」用来礼貌地邀请别人。中文可以理解成“一起……好吗？”“要不要……？”

一緒に 京都へ 行きませんか。
一起去京都好吗？
一緒に 昼ご飯を 食べませんか。
一起吃午饭好吗？
今晩、一緒に 映画を 見ませんか。
今晚一起看电影好吗？
虽然形式是否定「ません」，但在邀请句里不是“不做吗”的责问，而是柔和邀请。

6. ～ましょう：一起……吧

动词ます形去ます + ましょう

「～ましょう」用于提议“一起做吧”，也常用于接受邀请时回答。

ちょっと 休みましょう。
休息一下吧。
一緒に 行きましょう。
一起去吧。
昼ご飯を 食べましょう。
吃午饭吧。

邀请与回答

一緒に お茶を 飲みませんか。
一起喝茶好吗？
ええ、飲みましょう。
好啊，喝吧。
「～ませんか」偏邀请；「～ましょう」偏提议或接受邀请。

7. ちょっと：委婉拒绝

别人邀请你时，如果不方便，日本人常用「ちょっと……」委婉拒绝。

一緒に 映画を 見ませんか。
一起看电影好吗？
すみません。ちょっと……。
不好意思，有点……
今晩、飲みに 行きませんか。
今晚去喝一杯好吗？
すみません。今日は ちょっと……。
不好意思，今天有点不方便……
「ちょっと」后面不说完，在日语里也能表达“有点不方便”的意思，比直接说“不去”更柔和。

8. よく・時々・あまり・全然

第6课会遇到频率、副词表达。

副词中文后面常接例句
よく经常；很好地肯定よく映画を見ます。
時々有时肯定時々テニスをします。
あまり不太否定あまりテレビを見ません。
全然完全不否定全然勉強しません。
「あまり」「全然」后面通常接否定形式：あまり～ません、全然～ません。
