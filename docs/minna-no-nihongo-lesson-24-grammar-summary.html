第24课核心语法

くれますあげますもらいますVてあげますVてもらいますVてくれます

语法中文意思重点
人が わたしに Nをくれます别人给我……东西朝“我/我方”移动
人に Nをあげます我/某人给别人……东西从主语给出去
人に/から Nをもらいます从别人那里得到……主语是接受方
Vてあげます为别人做……我/主语帮别人做
Vてもらいます请别人为我做……；得到别人帮忙我/主语受益
Vてくれます别人为我做……别人主动帮我/我方做

1. くれます：别人给我 / 我方

人 + が + わたしに + 名词 + を + くれます

「くれます」表示别人把东西给“我”或“我方的人”。重点是东西朝我这边来。

佐藤さんは わたしに 花を くれました。
佐藤给了我花。
友達は わたしに 写真を くれました。
朋友给了我照片。
先生は 弟に 本を くれました。
老师给了我弟弟一本书。
“我方”包括我、我的家人、我的团队等。别人给我方东西时，用「くれます」很自然。

2. あげます・もらいます・くれます 对比

句型方向例句中文
あげます我/主语 → 别人わたしは友達に本をあげました。我给了朋友书。
もらいます别人 → 我/主语わたしは友達に本をもらいました。我从朋友那里得到了书。
くれます别人 → 我/我方友達はわたしに本をくれました。朋友给了我书。
「もらいます」主语是收到的人；「くれます」主语是给的人，但受益方向朝向我方。

3. Vてあげます：为别人做……

人 + に + 动词て形 + あげます

表示“我/主语为别人做某事”。动作方向是从主语给别人带来帮助。

わたしは 友達に 日本語を 教えてあげました。
我教了朋友日语。
母に 荷物を 持ってあげました。
我帮妈妈拿了行李。
弟に 宿題を 手伝ってあげます。
我帮弟弟做作业。
「～てあげます」有“我帮你做”的恩惠感。对上级或不熟的人直接说，可能显得自己施恩，需谨慎。

4. Vてもらいます：请别人为我做 / 得到别人帮忙

人 + に + 动词て形 + もらいます

表示“我请别人做某事”或“我得到别人帮忙做某事”。主语是受益的人。

わたしは 先生に 漢字を 教えてもらいました。
我请老师教了我汉字。/ 我得到了老师教汉字的帮助。
友達に 写真を 撮ってもらいました。
请朋友帮我拍了照片。
駅員に 道を 教えてもらいました。
请车站工作人员给我指了路。
「てもらいます」的重点是“我受到了帮助”。帮忙的人用「に」。

5. Vてくれます：别人为我做……

人 + が + わたしに/わたしのために + 动词て形 + くれます

表示别人为我或我方做某事，带有感谢、受益的感觉。主语是帮忙的人。

友達が わたしに 写真を 撮ってくれました。
朋友帮我拍了照片。
母が お弁当を 作ってくれました。
妈妈给我做了便当。
田中さんが 駅まで 送ってくれました。
田中先生送我到了车站。
兄が 宿題を 手伝ってくれました。
哥哥帮我做了作业。
「てくれます」常带有“对方帮了我，真感谢”的感觉。

6. Vてもらいます vs Vてくれます

表达主语中文感觉
わたしは友達に写真を撮ってもらいました。我我请朋友帮我拍了照片 / 我得到了朋友帮忙
友達が写真を撮ってくれました。朋友朋友帮我拍了照片，带感谢感
わたしは先生に日本語を教えてもらいました。我我请老师教了我日语
先生が日本語を教えてくれました。老师老师教了我日语，帮了我
看主语：主语是受益者，用「てもらいます」；主语是帮忙者，用「てくれます」。

7. Vてあげます vs Vてくれます

表达方向中文
わたしは友達を手伝ってあげました。我 → 朋友我帮了朋友。
友達がわたしを手伝ってくれました。朋友 → 我朋友帮了我。
母に料理を作ってあげました。我 → 妈妈我给妈妈做了饭。
母が料理を作ってくれました。妈妈 → 我妈妈给我做了饭。
「あげます」方向离开我方；「くれます」方向来到我方。

8. 句中助词整理

动词常见对象例句
教えます人に 内容を先生に日本語を教えてもらいました。
貸します人に 物を友達に本を貸してあげました。
借ります人に/から 物を友達に辞書を貸してもらいました。
送ります人を 地点まで田中さんが駅まで送ってくれました。
手伝います人を兄がわたしを手伝ってくれました。
有些动词的对象用「を」，有些接受对象用「に」。不要只按中文“给/帮”来套。

9. 请求别人帮忙的自然说法

第24课的语法也常用于实际请求。

すみません。写真を 撮ってくださいませんか。
不好意思，可以请您帮我拍张照片吗？
ちょっと 手伝ってくれませんか。
可以帮我一下吗？
駅まで 送ってもらえませんか。
可以请你送我到车站吗？
「～てくれませんか」「～てもらえませんか」都是常用请求。对不熟的人，用更礼貌的「～てくださいませんか」更安全。
