～ながら～ています～し、～しそれにそれで

语法中文意思重点

～ています经常……；从事……；习惯性地……表示长期习惯、职业、反复活动

1. ～ながら：一边……一边……

动词ます形去ます + ながら

「ながら」表示两个动作同时进行。中文可以理解为“一边A，一边B”。

重点：句子后面的动作通常是主要动作，前面的「ながら」动作是同时进行的附带动作。
ます形去ます接ながら
聞きます聞き聞きながら
食べます食べ食べながら
見ます見見ながら
歩きます歩き歩きながら
話します話し話しながら
音楽を聞きながら、勉強します。
一边听音乐，一边学习。
テレビを見ながら、ご飯を食べます。
一边看电视，一边吃饭。
歩きながら、電話をしないでください。
请不要一边走路一边打电话。
「音楽を聞きながら、勉強します」的重点是“学习”。“听音乐”只是同时做的事情。

2. ～ています：经常……；从事……

动词て形 + います

以前学过「～ています」表示“正在……”。第28课还学习它表示长期习惯、职业、反复做的事情。

用法中文例句
正在进行正在……今、本を読んでいます。
习惯经常……毎朝ジョギングをしています。
职业/长期状态从事……；在……工作父は銀行で働いています。
毎朝ジョギングをしています。
我每天早上跑步。
週に一回、日本語を習っています。
我每周一次学习日语。
父は銀行で働いています。
我爸爸在银行工作。
判断方法：如果句子里有「毎朝」「毎週」「いつも」「週に一回」等词，很多时候不是“正在”，而是“习惯性地做”。

3. ～し、～し、～：又……又……

普通形 + し、普通形 + し、～

用来列举多个理由或特点。中文可以理解成“又……又……”“而且……”。

词类接法例子
动词普通形 + し使えるし、便利だし
い形容词普通形 + し安いし、おいしいし
な形容词词干 + だし静かだし、きれいだし
名词名词 + だし日曜日だし、休みだし
この店は安いし、おいしいし、よく来ます。
这家店又便宜又好吃，所以我经常来。
地下鉄は速いし、便利だし、地下鉄で行きましょう。
地铁又快又方便，我们坐地铁去吧。
このアパートは駅から近いし、静かだし、とてもいいです。
这套公寓离车站近，而且安静，非常好。
「～し」常常暗示“还有别的理由没有全部说完”。所以比单纯说两个理由更自然。

4. それに：而且；再加上

句子。 + それに、 + 补充信息。

「それに」用来继续补充同方向的信息。前面说好，后面继续说好；前面说不好，后面继续说不好。

この店は安いです。それに、おいしいです。
这家店很便宜。而且很好吃。
今日は寒いです。それに、雨も降っています。
今天很冷。而且还在下雨。
この部屋は広いです。それに、駅から近いです。
这个房间很宽敞，而且离车站近。

5. それで：所以；因此

原因。 + それで、 + 结果。

「それで」表示因为前面的原因，所以发生后面的结果。

電車が止まりました。それで、遅れました。
电车停了。所以我迟到了。
昨日は熱がありました。それで、会社を休みました。
昨天发烧了。所以我请假没去公司。
道が混んでいました。それで、約束の時間に間に合いませんでした。
路上很堵。所以没赶上约定时间。
区别：「それに」是补充信息；「それで」是原因 → 结果。

表达中文重点

～ています经常……；从事……习惯、职业、长期活动
