1. 动词ない形：否定的基本形

第19课的重点是「ない形」。它是许多否定、禁止、义务表达的基础。

动词类型ます形ない形变化要点
一类动词書きます書かないき→か＋ない
一类动词飲みます飲まないみ→ま＋ない
一类动词買います買わないい→わ＋ない
二类动词食べます食べない去ます＋ない
二类动词見ます見ない去ます＋ない
三类动词来ます来ない（こない）特殊
三类动词しますしない特殊
一类动词的「買います」要特别注意：買わない，不是「買あない」。

2. Vないでください：请不要做……

动词ない形 + でください

请求对方不要做某事时，用「～ないでください」。

部屋の かぎを 忘れないでください。
请不要忘记房间钥匙。
ここで タバコを 吸わないでください。
请不要在这里吸烟。
写真を 撮らないでください。
请不要拍照。
無理を しないでください。
请不要勉强。
第15课「Vてください」= 请做；第19课「Vないでください」= 请不要做。

3. Vなければなりません：必须做……

动词ない形去ない + なければなりません

表示义务、必须、不得不做某事时，用「～なければなりません」。

李さんは 今日 早く 帰らなければなりません。
小李今天必须早点回去。
明日 試験ですから、勉強しなければなりません。
因为明天考试，所以必须学习。
薬を 飲まなければなりません。
必须吃药。
变化：帰らない → 帰らなければなりません；飲まない → 飲まなければなりません。

4. Vなくてもいいです：不做也可以

动词ない形去ない + なくてもいいです

表示没有必要做某事，中文是“不做也可以”。

明日は 休みですから、早く 起きなくてもいいです。
明天休息，所以不用早起。
この 書類は 出さなくてもいいです。
这个文件不交也可以。
靴を 脱がなくてもいいです。
不用脱鞋也可以。
「なければなりません」= 必须做；「なくてもいいです」= 不做也可以。

5. なければなりません vs なくてもいいです

表达意思例句
行かなければなりません必须去会社へ行かなければなりません。
行かなくてもいいです不去也可以今日は会社へ行かなくてもいいです。
食べなければなりません必须吃薬を飲む前に食べなければなりません。
食べなくてもいいです不吃也可以朝ご飯は食べなくてもいいです。
两者都从「ない形」变来，但意思完全相反，一个是义务，一个是许可不用做。

6. まだVていません：还没有做

まだ + 动词て形 + いません

表示动作到现在还没有完成。第16课已经见过，第19课继续强化使用。

李さんは まだ 来ていません。
小李还没有来。
宿題は まだ 終わっていません。
作业还没有完成。
朝ご飯は まだ 食べていません。
早饭还没吃。
回答「もう～ましたか」时，可以说「いいえ、まだです」，也可以完整说「まだ～ていません」。

7. 名词が：铺垫、转折、委婉开场

名词/句子 + が、……

「が」可以表示“但是”，也常用来做委婉的铺垫。

すみませんが、写真を 撮らないでください。
不好意思，请不要拍照。
失礼ですが、お名前は 何ですか。
不好意思，请问您叫什么名字？
この 料理は おいしいですが、少し 辛いです。
这道菜很好吃，但是有点辣。
请求别人时加「すみませんが」会更自然、更礼貌。
