第7课核心句型

NをVます場所でVますNかN何をしますか何もVませんください

句型中文意思重点
名词を 动词ます做/吃/喝/看某物を提示动作对象，读作「お」
場所で 动词ます在某地做某事で提示动作发生地点
名词か 名词A或者B表示选择
何をしますか做什么？询问动作内容
何も 动词ません什么也不做疑问词+も+否定
名词をください请给我……购物、点餐常用

1. NをVます：动作的对象

名词 + を + 动词ます

助词「を」提示动作的对象。比如吃什么、喝什么、看什么、买什么。它写作「を」，作助词时读作「お」。

李さんは 毎日 コーヒーを 飲みます。
小李每天喝咖啡。
わたしは パンを 食べます。
我吃面包。
森さんは 新聞を 読みます。
森先生读报纸。
小野さんは テレビを 見ます。
小野女士看电视。
「を」不表示地点，而是动作直接作用的对象。读音要记成「お」。

2. 何をVますか：做什么？

何 + を + 动词ますか

询问动作对象时，用「何を」。这里「何」常读作「なに」。

朝ご飯に 何を 食べますか。
早饭吃什么？
パンと 卵を 食べます。
吃面包和鸡蛋。
日曜日、何を しますか。
星期天做什么？
映画を 見ます。
看电影。
「何をしますか」是非常常用的句型，意思是“做什么”。

3. 場所でVます：在某地做某事

地点 + で + 动词ます

助词「で」表示动作发生的场所。和第4课的存在地点「に」要区分。

李さんは 図書館で 勉強します。
小李在图书馆学习。
わたしは 家で テレビを 見ます。
我在家看电视。
食堂で 昼ご飯を 食べます。
在食堂吃午饭。
コンビニで お弁当を 買いました。
在便利店买了便当。
存在用「に」：部屋に机があります。动作发生地用「で」：部屋で本を読みます。

4. NかN：A或者B

名词 + か + 名词

「か」放在两个名词之间时，表示选择，中文是“或者”。

朝ご飯は パンか お粥を 食べます。
早饭吃面包或者粥。
日曜日は 映画か 音楽を 楽しみます。
星期天看电影或者听音乐。
コーヒーか 紅茶を ください。
请给我咖啡或者红茶。
句末「か」表示疑问；名词之间的「か」表示“或者”。

5. 何もVません：什么也不……

疑问词 + も + 否定

「何も～ません」表示“什么也不……”。必须和否定形式一起用。

昨日、何も 食べませんでした。
昨天什么也没吃。
日曜日、何も しません。
星期天什么也不做。
今朝、何も 飲みませんでした。
今天早上什么也没喝。
不要说「何も食べます」。疑问词+も通常要配否定：何も食べません。

6. Nをください：请给我……

名词 + を + ください

购物、点餐、请求拿东西时，可以用「～をください」。

すみません、コーヒーを ください。
不好意思，请给我咖啡。
この 本を ください。
请给我这本书。
お弁当を 2つ ください。
请给我两个便当。
「ください」比直接说“给我”礼貌，但在正式服务场合也常搭配「お願いします」。
