第31课核心语法

意向形～と思っています～つもりです～予定ですまだ～ていません

语法中文意思重点
意向形……吧；打算……表示意志、邀请、自言自语式决定
意向形＋と思っています我打算……表达心里已有的计划或想法
辞书形/ない形＋つもりです打算……；不打算……个人意图比较明确
辞书形/名词の＋予定です计划……；预定……偏客观日程、安排
まだ～ていません还没有……表示到现在为止尚未完成

1. 意向形：……吧 / 打算……

动词意向形

意向形可以表示“我来……吧”“一起……吧”“打算……”。它比「ましょう」更随意，也常用于表达自己的想法。

一类动词变化

把最后的 う段 改成 お段 + う。

辞书形意向形中文
行く行こう去吧 / 打算去
書く書こう写吧 / 打算写
読む読もう读吧 / 打算读
話す話そう说吧 / 打算说
買う買おう买吧 / 打算买

二类动词变化

去掉「る」，加 よう。

辞书形意向形中文
食べる食べよう吃吧 / 打算吃
見る見よう看吧 / 打算看
起きる起きよう起床吧 / 打算起床
寝る寝よう睡吧 / 打算睡

三类动词变化

辞书形意向形中文
するしよう做吧 / 打算做
来る来よう来吧 / 打算来
ちょっと休もう。
休息一下吧。
いっしょに行こう。
一起去吧。
今日は早く寝よう。
今天早点睡吧。
意向形单独使用时，语气比较随意，常用于朋友、家人之间，或自己心里决定时。

2. 意向形＋と思っています：我打算……

意向形 + と思っています

这个句型表示自己心里已经有某个计划或想法。中文可以理解为“我打算……”“我想要……”。

将来自分の会社を作ろうと思っています。
将来我打算开自己的公司。
日本で働こうと思っています。
我打算在日本工作。
来年、車を買おうと思っています。
我打算明年买车。
「と思っています」比「と思います」更像“这个想法已经持续了一段时间”，不是刚刚临时想到。

3. ～つもりです：打算……

动词辞书形 / ない形 + つもりです

「つもりです」表示比较明确的个人打算。

接法例子中文
辞书形＋つもりです買うつもりです打算买
ない形＋つもりです買わないつもりです打算不买
来月、車を買うつもりです。
我打算下个月买车。
夏休みに国へ帰るつもりです。
暑假打算回国。
今年は旅行しないつもりです。
今年打算不旅行。
「つもりです」强调个人意图。别人问“你打算怎么做？”时很常用。

4. ～予定です：计划…… / 预定……

动词辞书形 / 名词の + 予定です

「予定です」表示计划、日程、安排。它比「つもりです」更客观，常用于时间表、会议、行程。

接法例子中文
辞书形＋予定です出張する予定です计划出差
名词の＋予定です会議の予定です计划有会议
来月、出張する予定です。
计划下个月出差。
会議は3時からの予定です。
会议计划从3点开始。
飛行機は9時に到着する予定です。
飞机预定9点到达。
简单区别：つもりです = 我个人打算；予定です = 日程计划、客观安排。

5. まだ～ていません：还没有……

まだ + 动词て形 + いません

表示某件事到现在还没有完成。中文就是“还没有……”。

宿題はまだしていません。
作业还没做。
昼ご飯はまだ食べていません。
午饭还没吃。
旅行の準備はまだ終わっていません。
旅行的准备还没有结束。
回答「もう～ましたか」时，如果还没做，常回答「いいえ、まだ～ていません」。

6. つもりです vs 予定です vs と思っています

表达中文语感
～ようと思っています我打算……心里有这个想法，可能较长期
～つもりです打算……个人意图比较明确
～予定です计划……；预定……客观日程或安排
日本で働こうと思っています。
我打算在日本工作。强调心里的想法。
来年、日本で働くつもりです。
我打算明年在日本工作。强调个人打算。
来月から日本で働く予定です。
计划下个月开始在日本工作。强调安排已经定了。
