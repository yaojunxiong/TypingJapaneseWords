1. VたりVたりします：列举动作

动词た形去た/だ + たり + 动词た形去た/だ + たり + します

「たり～たりします」用来举出几个代表性动作，表示“做做A、做做B等”。不是完整列举，而是举例。

休みの 日、散歩したり 買い物に 行ったりします。
休息日，有时散步，有时去买东西。
日曜日は テレビを 見たり、本を 読んだりします。
星期天看看电视、读读书等。
旅行で 写真を 撮ったり、お土産を 買ったりしました。
旅行时拍了照片、买了土特产等。
「たり」虽然来自た形，但句子的时态看最后的「します/しました」。

2. たり 的变化方法

ます形た形たり形例句
行きます行った行ったり行ったり来たりします
買います買った買ったり買ったりします
読みます読んだ読んだり読んだり書いたりします
食べます食べた食べたり食べたり飲んだりします
しますしたしたり掃除したりします
动词的「たり」就是た形后面加「り」：見た→見たり、読んだ→読んだり。

3. 形容词たり：有时……有时……

形容词也可以用「たり」表示状态不固定、时而如此时而那样。

类型变化例子
一类形容词い → かったり暑い → 暑かったり
二类形容词だ → だったり静かだ → 静かだったり
名词だ → だったり雨だ → 雨だったり
このごろ 天気は 暑かったり 寒かったりです。
最近天气时而热，时而冷。
この 店は 静かだったり にぎやかだったりです。
这家店有时安静，有时热闹。
休みは 土曜日だったり 日曜日だったりです。
休息日有时是星期六，有时是星期日。
一类形容词：高い→高かったり；二类形容词和名词：便利だったり、学生だったり。

4. かどうか：是否……

小句简体 + かどうか + わかりません/教えてください

把“是否……”放进大句里时，用「かどうか」。前面通常用简体。

わたしは 今年の 夏、北京へ 行くかどうか わかりません。
我不知道今年夏天是否去北京。
明日 雨が 降るかどうか わかりません。
不知道明天是否下雨。
この 店が 安いかどうか 調べます。
查一下这家店便不便宜。
「かどうか」适用于是/否问题：去不去、有没有、贵不贵、能不能。

5. 疑问词小句＋か：谁/哪里/什么时候……

疑问词小句 + か + 动词

如果小句里有「何、だれ、どこ、いつ、どう」等疑问词，就不用「かどうか」，而用「疑问词小句＋か」。

かぎが どこに あるか 教えてください。
请告诉我钥匙在哪里。
会議が いつ 始まるか わかりません。
不知道会议什么时候开始。
だれが 来るか 知っていますか。
你知道谁会来吗？
何を 買うか まだ 決めていません。
还没有决定买什么。
有疑问词时：どこにあるか。没有疑问词、问是否时：あるかどうか。

6. 小句中的助词与语序

「～か」「～かどうか」前面仍然保持普通日语语序，助词也不能省略错。

駅が どこに あるか わかりません。
不知道车站在哪里。
森さんが 何を 食べたいか 聞きます。
问森先生想吃什么。
この 電車が 新宿へ 行くかどうか 駅員に 聞きます。
问站员这辆电车是否去新宿。
中文会说“在哪里有钥匙”，日语仍说「かぎがどこにあるか」。

7. たり 和 と 的区别

表达感觉例句
AとB完整列举A和Bパンと卵を食べます。
AたりBたり举例，有时A有时B，还有其他可能パンを食べたり卵を食べたりします。
AてB动作顺序朝起きて、顔を洗います。
「たり」不是简单的“和”，它有“不完全列举、代表性例子”的感觉。
