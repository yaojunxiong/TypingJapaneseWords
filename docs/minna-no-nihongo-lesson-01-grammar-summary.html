1. N1 は N2 です：……是……

名词1 + は + 名词2 + です

这是日语最基本的名词判断句。用于介绍姓名、国籍、职业、身份等。

「は」写作 は，但在助词中读作 wa。它用来提示主题：关于N1，后面说明它是什么。
わたしは マイク・ミラーです。
我是迈克・米勒。
サントスさんは 学生です。
桑托斯先生是学生。
ワンさんは 会社員です。
王先生是公司职员。
结构作用例子
わたし主题我
は提示主题关于……
学生说明身份学生
です礼貌判断是

2. N1 は N2 じゃありません：……不是……

名词1 + は + 名词2 + じゃありません

「じゃありません」是「です」的否定形式，表示“不是……”。

サントスさんは 学生じゃありません。
桑托斯先生不是学生。
わたしは 先生じゃありません。
我不是老师。
ワンさんは 日本人じゃありません。
王先生不是日本人。
更正式的说法是「ではありません」。日常初级会话里「じゃありません」很常用。
肯定否定
学生です。学生じゃありません。
会社員です。会社員じゃありません。
日本人です。日本人じゃありません。

3. N1 は N2 ですか：……是……吗？

名词1 + は + 名词2 + ですか

日语疑问句常在句末加「か」。读的时候语调通常上扬。

ミラーさんは 会社員ですか。
米勒先生是公司职员吗？
カリナさんは 学生ですか。
卡莉娜小姐是学生吗？
ワンさんは 中国人ですか。
王先生是中国人吗？

回答方式

回答中文例句
はい、そうです。是，是的。はい、そうです。
いいえ、違います。不，不是。いいえ、違います。
いいえ、N2じゃありません。不，不是N2。いいえ、学生じゃありません。
「そうです」= 是那样；「違います」= 不是 / 不对。第1课会话中非常常用。

4. N1 も N2 です：……也是……

名词1 + も + 名词2 + です

「も」表示“也”。当前面已经说过一个人或事物，再说另一个也相同时，就用「も」。

ミラーさんは 会社員です。グプタさんも 会社員です。
米勒先生是公司职员。古普塔先生也是公司职员。
カリナさんは 学生です。わたしも 学生です。
卡莉娜小姐是学生。我也是学生。
佐藤さんは 日本人です。山田さんも 日本人です。
佐藤小姐是日本人。山田先生也是日本人。
有「も」时，通常不用「は」。例如：わたしも学生です。不要说「わたしはも学生です」。

5. ～さん：称呼别人

姓名 + さん

「さん」接在人名后，表示礼貌称呼。中文可理解为“先生、女士、同学”等，具体要看对象。

ミラーさん
米勒先生 / 米勒小姐
佐藤さん
佐藤先生 / 佐藤女士
ワンさん
王先生 / 王女士
不能称呼自己为「わたしさん」。介绍自己时只说「わたしはミラーです」。
