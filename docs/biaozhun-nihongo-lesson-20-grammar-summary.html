1. 动词基本形：词典里的形式

第20课开始大量使用动词基本形。它也叫“辞书形”，是词典中出现的动词形式。

类型ます形基本形例子
一类动词書きます書く写
一类动词飲みます飲む喝
一类动词買います買う买
二类动词食べます食べる吃
二类动词見ます見る看
三类动词来ます来る（くる）来
三类动词しますする做
基本形在后面很多语法里都会出现，比如「食べることができます」「寝る前に」。

2. Vことができます：会做 / 能做

动词基本形 + こと + が + できます

表示能力、可能性时，用「～ことができます」。前面的动词要用基本形。

スミスさんは ピアノを 弾くことが できます。
史密斯先生会弹钢琴。
わたしは 日本語を 話すことが できます。
我会说日语。
ここで 写真を 撮ることが できます。
这里可以拍照。
この 図書館では 本を 借りることが できます。
在这个图书馆可以借书。
「こと」把前面的动词短句名词化，相当于“做……这件事”。

3. Vことができません：不会 / 不能

动词基本形 + こと + が + できません

表示不会做、不能做时，把「できます」变成「できません」。

わたしは 車を 運転することが できません。
我不会开车。
ここで タバコを 吸うことが できません。
这里不能吸烟。
今日は 忙しいですから、行くことが できません。
今天很忙，所以不能去。
「できません」既可以表示能力不足，也可以表示规则上不允许或条件上不能。

4. Nができます：会…… / 能…… / 完成……

名词 + が + できます

如果对象是名词，可以直接用「Nができます」。

森さんは 英語が できます。
森先生会英语。
李さんは 料理が できます。
小李会做饭。
宿題が できました。
作业完成了。
「できます」意思比较宽：会、能、完成、建成等，具体看上下文。

5. V前に：做……之前

动词基本形 + 前に

表示“做某动作之前”时，用动词基本形接「前に」。

寝る 前に、日記を 書きます。
睡觉之前写日记。
食事を する 前に、手を 洗います。
吃饭前洗手。
日本へ 行く 前に、日本語を 勉強しました。
去日本之前学了日语。
即使后面是过去时，前面的动词也用基本形：行く前に勉強しました。

6. Nの前に：在……之前 / 在……前面

名词 + の + 前に

名词后面接「前に」时，中间要加「の」。它可以表示时间上的“之前”，也可以表示空间上的“前面”。

会議の 前に、資料を コピーします。
会议之前复印资料。
食事の 前に、薬を 飲みます。
饭前吃药。
駅の 前に 銀行が あります。
车站前面有银行。
动词前不用の：寝る前に。名词前要加の：会議の前に。

7. 疑问词 + か：某个…… / 是否……

何か / だれか / どこか / いつか

疑问词后接「か」，表示不确定的某人、某物、某地、某时。

何か 食べませんか。
吃点什么吗？
部屋に だれか いますか。
房间里有人吗？
どこかへ 行きたいです。
想去某个地方。
いつか 日本へ 行きたいです。
将来某一天想去日本。
区别：何か = 某个东西；何も＋否定 = 什么也不；何でも = 什么都。

8. よね：确认并期待对方同意

句子 + よね

「よね」有“是这样吧，对吧”的感觉。说话人认为自己知道，但想确认对方也认同。

李さんは ピアノを 弾くことが できますよね。
小李会弹钢琴吧？
明日の 会議は 9時からですよね。
明天的会议是9点开始吧？
「ね」偏寻求共鸣；「よね」带有“我觉得是这样，你确认一下”的语气。
