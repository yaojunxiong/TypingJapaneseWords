第2课核心语法

これ・それ・あれこの・その・あのこれはNですN1のN2そうです・違います

语法中文意思重点
これは 名词です这是……用来指东西，これ本身就是“这个”
それは 名词です那是……指离听话人近、离说话人远的东西
あれは 名词です那是……指离双方都远的东西
この/その/あの 名词这个/那个……后面必须接名词，不能单独用
N1 の N2N1的N2表示所属、内容、种类、产地等关系

1. これ・それ・あれ：这个、那个

これ / それ / あれ + は + 名词 + です

「これ・それ・あれ」是指示代词，可以单独指东西。中文都可翻译成“这个/那个”，但位置关系不同。

日语中文位置感觉
これ这个离说话人近
それ那个离听话人近，或刚提到的东西
あれ那个离双方都远
これは 辞書です。
这是词典。
それは ボールペンです。
那是圆珠笔。
あれは 車です。
那是车。
「これ」本身已经是“这个东西”，后面不能直接再接名词。不能说「これ本」。要说「この本」。

2. これは何ですか：这是什么？

これは + 何 + ですか

「何」读作「なん」时，常用于「何ですか」「何の～」等表达。

これは 何ですか。
这是什么？
それは 何ですか。
那是什么？
あれは 何ですか。
那是什么？

回答方式

これは 鍵です。
这是钥匙。
それは 時計です。
那是钟表。
あれは かばんです。
那是包。
第2课重点是“指物问答”：これは何ですか。——それはNです。

3. この・その・あの：这个……、那个……

この / その / あの + 名词

「この・その・あの」不能单独使用，后面必须接名词。

日语中文例子
この这个……この本 = 这本书
その那个……その傘 = 那把伞
あの那个……あの人 = 那个人
この本は わたしのです。
这本书是我的。
そのかばんは 田中さんのです。
那个包是田中先生的。
あの人は 山田さんです。
那个人是山田先生。
区别：これ = 这个东西，可单独用；この = 这个……，后面必须接名词。

4. これ vs この 的区别

表达能不能单独用例句中文
これ可以これは本です。这是书。
この不可以この本はわたしのです。这本书是我的。
それ可以それは辞書です。那是词典。
その不可以その辞書は先生のです。那本词典是老师的。
记忆：こ・そ・あ + れ = “这个/那个东西”；こ・そ・あ + の + 名词 = “这个/那个名词”。

5. N1 の N2：……的……

名词1 + の + 名词2

「の」连接两个名词，表示所属、内容、种类、产地等关系。第2课主要用于“谁的东西”“什么语言的书”等。

表示所属：谁的东西

これは わたしの本です。
这是我的书。
それは ミラーさんのかばんです。
那是米勒先生的包。
この傘は 佐藤さんのです。
这把伞是佐藤小姐的。

表示内容或种类

これは 日本語の本です。
这是日语书。
それは コンピューターの本です。
那是电脑方面的书。

表示公司或机构

これは IMCの社員証です。
这是IMC的员工证。
「N1のN2」里的N2如果前文已经知道，可以省略：これはわたしの本です → これはわたしのです。

6. これはだれのですか：这是谁的？

これは + だれ + の + ですか

询问东西属于谁时，用「だれの」。

これは だれのですか。
这是谁的？
それは わたしのです。
那是我的。
この傘は だれのですか。
这把伞是谁的？
山田さんのです。
是山田先生的。
「だれの本ですか」= 谁的书？「だれのですか」= 谁的？后面的名词已经知道时可以省略。

7. はい、そうです / いいえ、違います

第2课继续使用「そうです」「違います」来回答判断句。

これは ミラーさんのかばんですか。
这是米勒先生的包吗？
はい、そうです。
是，是的。
これは 佐藤さんの傘ですか。
这是佐藤小姐的伞吗？
いいえ、違います。山田さんのです。
不，不是。是山田先生的。
「違います」读作「ちがいます」，意思是“不对、不是”。
