1. て形表示原因、理由

动词て形 / 形容词て形 + 后句

「て形」可以表示原因、理由。后句多是道歉、感谢、困扰、感情、自然结果等，语气比较自然。

遅く なって、すみません。
来晚了，对不起。
頭が 痛くて、会社を 休みました。
因为头疼，所以没去上班。
説明が 丁寧で、よく 分かりました。
因为说明很仔细，所以很好理解。
友達に 会えて、うれしいです。
能见到朋友，我很高兴。
原因「て」后面一般不接强烈命令、请求、意志表达。表达主观意志时常用「から」「ので」。

2. て形原因的接续

类型变化例句
动词て形遅れて、すみません。
一类形容词い → くて忙しくて、行けません。
二类形容词で静かで、よく眠れました。
名词で病気で、学校を休みました。
名词和二类形容词的原因形式都是「で」：雨で、病気で、便利で、静かで。

3. Nに使います：用于……

名词 + に + 使います / 役立ちます / 必要です

助词「に」可以表示用途、目的、适用对象。

この 写真は パスポートの 申請に 使います。
这张照片用于申请护照。
この はさみは 紙を 切るのに 使います。
这把剪刀用于剪纸。
この 辞書は 日本語の 勉強に 役立ちます。
这本词典对日语学习有帮助。
旅行に パスポートが 必要です。
旅行需要护照。
当用途是动词小句时，常用「Vるのに」：写真を撮るのに使います。

4. Vてばかりいます：总是……，光是……

动词て形 + ばかりいます

表示反复做同一件事，带有“总是这样、别的不做”的语气。很多时候含有轻微不满或批评。

張さんは 毎日 お酒を 飲んでばかりいます。
小张每天光喝酒。
弟は ゲームを してばかりいます。
弟弟老是在玩游戏。
休みの 日は 寝てばかりいます。
休息日总是在睡觉。
テレビを 見てばかりいないで、少し 勉強しなさい。
不要老是看电视，稍微学习一下。
「ばかり」表示限定，“净是、光是”。「てばかりいます」强调反复动作。

5. のが見えます：看得见……

小句简体 + の + が + 見えます

把一个小句名词化后，作为“看得见”的对象。这里的「見えます」不是主动去看，而是“进入视野、看得见”。

空港の 入り口に 警官が 立っているのが 見えます。
能看见机场入口处有警察站着。
窓から 富士山が 見えます。
从窗户能看见富士山。
子供たちが 公園で 遊んでいるのが 見えます。
能看见孩子们在公园玩。
「見る」是主动看；「見える」是看得见、映入眼帘。

6. のが聞こえます：听得见……

小句简体 + の + が + 聞こえます

表示声音自然传入耳中，能听见某事发生。

隣の 部屋で 子供が 歌っているのが 聞こえます。
能听见隔壁房间里孩子在唱歌。
外で 車の 音が 聞こえます。
听得见外面汽车的声音。
だれかが 階段を 上ってくるのが 聞こえました。
听见有人上楼来了。
「聞く」是主动听；「聞こえる」是听得见、声音传来。

7. 見えます・聞こえます vs 見ます・聞きます

表达意思例句
見ます主动看テレビを見ます。
見えます看得见山が見えます。
聞きます主动听、询问音楽を聞きます。
聞こえます听得见音が聞こえます。
主动动作常用「を」：テレビを見る、音楽を聞く；自然感知常用「が」：山が見える、音が聞こえる。

8. 小句＋の 的名词化复习

第26课学过「の」可以把动词小句变成名词。本课继续用在感知表达里。

形式例句中文
Vるのは日本語を勉強するのは楽しいです。学习日语很开心
Vるのが音楽を聞くのが好きです。喜欢听音乐
Vるのを李さんが来るのを見ました。看见小李来了
Vているのが子供が遊んでいるのが見えます。看得见孩子在玩
核心思路：小句＋の = “……这件事/这个场景”。
