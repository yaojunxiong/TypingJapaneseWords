1. まるでNのようです：简直像……一样

まるで + 名词 + の + ようです

表示比喻或相似。常和「まるで」一起使用，语气是“简直像……一样”。

これは 柔らかくて、まるで 本物の 毛皮のようです。
这个很柔软，简直像真的毛皮一样。
この ケーキは まるで 花のようです。
这个蛋糕简直像花一样。
彼女の 日本語は まるで 日本人のようです。
她的日语简直像日本人一样。
「まるで」常和「ようです」「みたいです」搭配，加强“像”的感觉。

2. NのようなN：像……一样的……

名词 + の + ような + 名词

「ような」用来修饰名词，表示“像……一样的……”。

夢のような 話ですね。
真是像梦一样的话啊。
この 町には 昔のような 建物が 残っています。
这座城市还保留着像从前一样的建筑。
彼は 子供のような 笑顔を しています。
他有像孩子一样的笑容。
修饰名词用「ような」：本物のような毛皮、夢のような話。

3. NのようにV/形容词：像……一样地……

名词 + の + ように + 动词/形容词

「ように」用来修饰动作或状态，表示方式、样子。

鳥のように 空を 飛びたいです。
想像鸟一样在天空飞。
先生のように 上手に 話したいです。
想像老师一样说得好。
この 布は 絹のように 柔らかいです。
这块布像丝绸一样柔软。
修饰动作/形容词用「ように」：鳥のように飛ぶ、絹のように柔らかい。

4. いかにもNらしい：真有……特点

いかにも + 名词 + らしい + 名词

「らしい」表示典型特征，“很有……样子”。「いかにも」加强语气，表示“一看就很像、确实很有……特点”。

この 着物は いかにも 日本らしい 柄ですね。
这件和服的花纹真有日本风格啊。
今日は 春らしい 暖かい 天気です。
今天是很有春天气息的暖和天气。
彼は 学生らしい まじめな 人です。
他是很有学生样子的认真人。
「日本らしい」是“具有日本典型特征”；不是“好像是日本”。

5. らしい vs ようです

表达重点例句
Nのようです像……一样，比喻或推测本物の毛皮のようです。
Nらしい具有N的典型特征日本らしい柄です。
春のようです像春天一样今日は春のようです。
春らしい很有春天的感觉春らしい天気です。
「よう」强调相似；「らしい」强调典型性、应有特征。

6. までに：在……之前

时间 + までに

表示截止期限，意思是“在……之前完成某事”。后面常接完成、提交、回去、到达等一次性动作。

明日の 9時までに この 書類を 完成させなければなりません。
必须在明天9点之前完成这份文件。
金曜日までに レポートを 出してください。
请在星期五之前提交报告。
会議が 始まるまでに、資料を コピーしておきます。
会议开始之前，把资料复印好。
「までに」强调“截止点之前完成”。

7. まで vs までに

表达意思后接动作例句
まで一直到……持续动作5時まで働きます。
までに在……之前一次性完成动作5時までに帰ります。
夜まで一直到晚上続ける、待つ、働く夜まで勉強します。
夜までに晚上之前出す、完成する、帰る夜までに宿題を出します。
简单记：持续用「まで」；截止完成用「までに」。

8. 間：……期间一直……

名词の間 / Vている間 + 持续动作

表示在整个期间内，后面的动作或状态持续存在。

夏休みの 間、ずっと アルバイトを していました。
暑假期间一直在打工。
電車に 乗っている間、日本語の 単語を 覚えています。
坐电车期间一直背日语单词。
母が 料理している間、わたしは テーブルを 片づけました。
妈妈做饭期间，我收拾了桌子。
「間」后面常是持续性动作或状态。

9. 間に：……期间内发生某事

名词の間に / Vている間に + 一次性变化或动作

表示在某个期间内发生了一次动作或变化。

わたしが 留学している間に、家の 周りも ずいぶん 変わりました。
我留学期间，家周围也变化很大。
子供が 寝ている間に、掃除しました。
孩子睡觉期间，我打扫了卫生。
休みの 間に、一度 京都へ 行きたいです。
休假期间想去一次京都。
「間に」后面常是一次性动作或变化：行く、終わる、変わる、完成する。

10. 間 vs 間に

表达重点例句
夏休みの間整个暑假期间持续夏休みの間、働いていました。
夏休みの間に暑假期间内做一次/发生一次夏休みの間に、京都へ行きました。
寝ている間睡着的整个期间寝ている間、雨が降っていました。
寝ている間に睡着期间发生某事寝ている間に、雨がやみました。
持续用「間」；期间内发生某事用「間に」。

13. 中国学习者容易错的地方

错误正确说明
本物ようです。本物のようです。名词接よう要加の
本物のように毛皮です。本物のような毛皮です。修饰名词用ような
日本のらしい柄です。日本らしい柄です。らしい前名词不加の
9時まで完成してください。9時までに完成してください。截止完成用までに
5時までに待ちます。5時まで待ちます。持续等待用まで
留学している間、家の周りが変わりました。留学している間に、家の周りが変わりました。期间内发生变化用間に
