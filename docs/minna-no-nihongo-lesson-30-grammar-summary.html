1. 他動詞＋てあります：已经……好了

他动词て形 + あります

「～てあります」表示：有人为了某个目的，已经把某件事做好了，而且结果状态现在还保留着。

中文理解：不是单纯“东西在那里”，而是“有人已经提前弄好了”。
他动词て形＋あります中文
書きます書いてあります写好了
貼ります貼ってあります贴好了
置きます置いてあります放好了
並べます並べてあります摆好了
開けます開けてあります打开好了
閉めます閉めてあります关好了
カレンダーに予定が書いてあります。
日历上写好了安排。
壁にポスターが貼ってあります。
墙上贴着海报 / 海报已经贴好了。
机の上に資料が置いてあります。
桌子上放好了资料。
会議室にいすが並べてあります。
会议室里椅子已经摆好了。

2. 为什么用「が」？

「～てあります」句子里，前面的东西通常用「が」。因为重点是“这个东西现在处于被安排好的状态”。

普通动作人为结果状态
予定を書きます。
写安排。		予定が書いてあります。
安排已经写好了。
ポスターを貼ります。
贴海报。		ポスターが貼ってあります。
海报已经贴好了。
資料を置きます。
放资料。		資料が置いてあります。
资料已经放好了。
「を」强调动作本身；「が＋てあります」强调结果状态。

3. ～ておきます：事先……；先……

动词て形 + おきます

「～ておきます」表示为了之后方便，提前做某事。中文可以理解成“先……、提前……、事先……”。

旅行の前に、ホテルを予約しておきます。
旅行前先订好酒店。
会議の前に、資料をコピーしておきます。
会议前先把资料复印好。
友達が来る前に、部屋を掃除しておきます。
朋友来之前，先把房间打扫好。
試験の前に、もう一度文法を復習しておきます。
考试前，先再复习一遍语法。
口语里「～ておきます」常变成「～ときます」。例如：予約しておきます → 予約しときます。

4. そのままにしておきます：保持原样

そのままにしておきます

表示“不改变现在的状态，先让它保持这样”。

この資料はそのままにしておいてください。
这份资料请保持原样。
窓は開けたままにしておきます。
窗户就保持打开的状态。
電気はつけたままにしておいてください。
灯请就这样开着。
「～たまま」表示某个动作之后的状态一直保留。比如「座ったまま」= 坐着不动，「開けたまま」= 打开后保持开着。

5. 第29课 vs 第30课：最容易混的区别

第29课是 自动词＋ています，重点是“自然看到的状态”。第30课是 他动词＋てあります，重点是“有人为了某目的做好的状态”。

第29课：自动词＋ています第30课：他动词＋てあります
窓が開いています。
窗户开着。		窓が開けてあります。
窗户被打开好了。
ドアが閉まっています。
门关着。		ドアが閉めてあります。
门被关好了。
電気がついています。
灯亮着。		電気がつけてあります。
灯被打开好了。
車が止まっています。
车停着。		車が止めてあります。
车被停好了。
简单记：自动词ている = 状态在那里；他动词てある = 有人安排好了。

6. 「てあります」和「ておきます」的区别

表达中文重点
～てあります已经……好了看结果：现在已经是准备好的状态
～ておきます事先……；先……看动作：为了将来，现在先做
資料がコピーしてあります。
资料已经复印好了。重点是“已经好了”。
資料をコピーしておきます。
我先把资料复印好。重点是“我现在先做”。
ホテルが予約してあります。
酒店已经订好了。
ホテルを予約しておきます。
我先把酒店订好。
