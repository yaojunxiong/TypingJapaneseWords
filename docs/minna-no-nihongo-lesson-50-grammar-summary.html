1. 謙譲語：把自己放低的说法

第50课学习的是 謙譲語。谦让语用来把自己或自己一方的动作说得低一点，从而表达对对方的尊敬。

第49课尊敬语：抬高对方。第50课谦让语：降低自己。两者方向不同。
普通说法谦让语中文
私が行きます。私が参ります。我去。
私が聞きます。私が伺います。我问 / 我拜访。
私が言います。私が申します。我说 / 我叫……

2. お＋ます形＋します：我为您……

お + 动词ます形去ます + します

这个句型表示自己为对方做某事。因为动作涉及对方，所以把自己的动作说低，显得礼貌。

荷物をお持ちします。
我来帮您拿行李。
駅までお送りします。
我送您到车站。
後でお電話します。
稍后我给您打电话。
チケットをお取りします。
我帮您取票 / 订票。
这个句型不能用于和对方无关的私人动作。比如“我吃饭”不能说「お食べします」。

3. ご＋汉语词＋します：我为您……

ご + 汉语词サ变名词 + します

汉语词、サ变动词常用「ご～します」。常见于服务、商务、学校说明。

普通说法谦让语中文
説明しますご説明します我为您说明
案内しますご案内します我为您带路 / 介绍
連絡しますご連絡します我联系您
紹介しますご紹介します我为您介绍
確認しますご確認します我确认
会議室へご案内します。
我带您去会议室。
使い方をご説明します。
我为您说明使用方法。
明日、もう一度ご連絡します。
明天我再联系您。
有些表达习惯上更常说「確認いたします」「ご確認いたします」需看场景。初级先掌握「ご説明します」「ご案内します」「ご連絡します」。

5. 伺います 的两个意思

「伺います」很常用，有两个重要意思：问、拜访。

普通说法谦让语例句
聞きます伺いますちょっと伺ってもよろしいですか。
訪問します / 行きます伺います明日、先生のお宅へ伺います。
お名前を伺ってもよろしいですか。
可以请教您的姓名吗？
来週、会社へ伺います。
下周我去贵公司拜访。
在商务场景中，「伺います」非常常用，语气比「聞きます」「行きます」礼貌很多。

6. いたします：します 的谦让语

します → いたします

「いたします」是「します」的谦让语，比「します」更郑重。

確認いたします。
我来确认。
後ほど連絡いたします。
稍后我联系您。
よろしくお願いいたします。
请多关照 / 拜托您了。
「お願いいたします」是非常常见的商务、邮件表达。

7. 丁寧語：ございます / でございます

除了尊敬语、谦让语，还有让句子更郑重的礼貌语。

普通礼貌更郑重中文
ありますございます有
ですでございます是
いいですよろしいです可以 / 好
こちらに資料がございます。
这里有资料。
受付は2階でございます。
前台在2楼。
少々お待ちいただいてもよろしいですか。
能否请您稍等一下？

8. 尊敬语 vs 谦让语

普通动词尊敬语：对方动作谦让语：自己动作

いますいらっしゃいますおります
食べます / 飲みます召し上がりますいただきます
言いますおっしゃいます申します
見ますご覧になります拝見します

判断方法：主语是老师、客人、上司 → 尊敬语。主语是我/我方 → 谦让语。
