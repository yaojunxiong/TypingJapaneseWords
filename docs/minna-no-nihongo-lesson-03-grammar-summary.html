1. ここ・そこ・あそこ：这里、那里、那里

ここ / そこ / あそこ + は + 名词 + です

「ここ・そこ・あそこ」是表示地点的词，可以单独使用。

日语中文位置感觉
ここ这里离说话人近
そこ那里离听话人近，或离说话人稍远
あそこ那里离双方都远
ここは 教室です。
这里是教室。
そこは 受付です。
那里是接待处。
あそこは 食堂です。
那里是食堂。
第2课学的是“东西”：これ・それ・あれ。第3课学的是“地点”：ここ・そこ・あそこ。

2. N は どこですか：N在哪里？

名词 + は + どこ + ですか

「どこ」表示“哪里”。询问人、物、场所在哪里时使用。

トイレは どこですか。
厕所在哪里？
事務所は どこですか。
办公室在哪里？
山田さんは どこですか。
山田先生在哪里？
エレベーターは どこですか。
电梯在哪里？

回答方式

トイレは あそこです。
厕所在那里。
事務所は 2階です。
办公室在2楼。
山田さんは 会議室です。
山田先生在会议室。
日语里可以说「山田さんは会議室です」，直译像“山田先生是会议室”，但实际意思是“山田先生在会议室”。

3. こちら・そちら・あちら：这边、那边；这位、那位

こちら / そちら / あちら

「こちら・そちら・あちら」比「ここ・そこ・あそこ」更礼貌，可以表示方向、地点，也可以礼貌地指人。

普通礼貌中文
こここちら这里 / 这边
そこそちら那里 / 那边
あそこあちら那里 / 那边
どこどちら哪里 / 哪边
受付は こちらです。
接待处在这边。
エレベーターは あちらです。
电梯在那边。
こちらは ミラーさんです。
这位是米勒先生。
介绍人时，「こちらは～さんです」比「あの人は～さんです」更礼貌自然。

4. N は どちらですか：N在哪里？/ 哪边？

名词 + は + どちら + ですか

「どちら」是「どこ」的礼貌说法，也可以问方向、公司、国家等。

受付は どちらですか。
接待处在哪里？
エレベーターは どちらですか。
电梯在哪里？
お国は どちらですか。
您是哪个国家的？
会社は どちらですか。
您是哪家公司？
「お国はどちらですか」是礼貌地问对方国家。回答可以说「中国です」「日本です」「アメリカです」。

5. N は どこの N ですか：哪里的……？

名词 + は + どこ + の + 名词 + ですか

用来询问东西的产地、品牌、所属国家或公司。

これは どこの車ですか。
这是哪里的车？
日本の車です。
是日本车。
これは どこのワインですか。
这是哪里的葡萄酒？
フランスのワインです。
是法国葡萄酒。
第2课学过「N1のN2」。第3课的「どこのN」就是“哪里的N”。

6. N は いくらですか：多少钱？

名词 + は + いくら + ですか

「いくら」表示“多少钱”。购物、点餐、看价格时很常用。

このかばんは いくらですか。
这个包多少钱？
7,300円です。
7300日元。
このワインは いくらですか。
这瓶葡萄酒多少钱？
3,200円です。
3200日元。
日元单位是「円（えん）」。例如：100円、1,000円、10,000円。

7. こ・そ・あ・ど 系统整理

第2课和第3课的指示词可以一起记。

类别近说话人近听话人双方都远疑问
东西これそれあれどれ
修饰名词このNそのNあのNどのN
地点ここそこあそこどこ
礼貌地点/方向/人こちらそちらあちらどちら
こ = 离我近；そ = 离你近；あ = 离我们都远；ど = 疑问。
