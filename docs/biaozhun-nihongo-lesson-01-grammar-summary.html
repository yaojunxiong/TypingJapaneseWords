1. NはNです：……是……

名词1 + は + 名词2 + です

这是日语最基础的判断句。助词「は」提示主题，相当于中文“至于……”。句末「です」表示礼貌判断，中文常翻译为“是”。

李さんは 中国人です。
小李是中国人。
森さんは 日本人です。
森先生是日本人。
わたしは 学生です。
我是学生。
「は」写作 は，但作助词时读作「わ」。例如「李さんは」读作「りさん わ」。

2. NはNではありません：……不是……

名词1 + は + 名词2 + ではありません

「ではありません」是「です」的礼貌否定形式，意思是“不是……”。口语中也常说「じゃありません」。

森さんは 学生ではありません。
森先生不是学生。
わたしは 会社員ではありません。
我不是公司职员。
李さんは 日本人ではありません。
小李不是日本人。
正式书面或教材中常用「ではありません」；日常口语中「じゃありません」更常见。

3. NはNですか：……是……吗？

名词1 + は + 名词2 + です + か

日语疑问句常在句末加「か」。语序不变，不像中文需要把“吗”放在句末即可。

林さんは 日本人ですか。
林先生是日本人吗？
李さんは 学生ですか。
小李是学生吗？
あなたは 中国人ですか。
你是中国人吗？
句末有「か」时，通常不用问号也可以。但学习时写问号便于理解。

4. はい / いいえ 的回答

回答「～ですか」时，可以用「はい」或「いいえ」。

问题回答中文
李さんは中国人ですか。はい、中国人です。是的，是中国人。
森さんは学生ですか。いいえ、学生ではありません。不，不是学生。
林さんは日本人ですか。はい、そうです。是的，是那样。
李さんは日本人ですか。いいえ、違います。不，不是。
「そうです」= 是那样；「違います」= 不是，不对。回答时不需要重复完整句子也可以。

5. NのN：所属、属性、说明

名词1 + の + 名词2

「の」连接两个名词，表示所属、属性、身份说明等。中文常翻译为“……的……”。

李さんは JC企画の 社員です。
小李是JC企划的职员。
森さんは 旅行社の 社員です。
森先生是旅行社的职员。
わたしは 北京大学の 学生です。
我是北京大学的学生。
「の」前面的名词用来修饰后面的名词。核心名词在最后：JC企画の社員 = 职员。
