第11课核心句型

Nが好きですNが嫌いですNが上手ですNが下手ですNがわかりますNやNなどから/だから

句型中文意思重点
Nは Nが 好きですN喜欢……喜欢的对象用が
Nは Nが 嫌いですN讨厌……讨厌的对象用が
Nは Nが 上手です/下手ですN擅长/不擅长……能力评价对象用が
Nは Nが わかりますN懂……理解的对象用が
NやNなど……啦……等等不完全列举
句子から因为……放在理由句后面
だから所以……放在结果句前面

1. Nが好きです：喜欢……

人 + は + 对象 + が + 好きです

「好き」是二类形容词。日语中“喜欢的对象”通常用「が」提示，不用「を」。

小野さんは 歌が 好きです。
小野女士喜欢唱歌/歌曲。
わたしは 音楽が 好きです。
我喜欢音乐。
李さんは 日本料理が 好きです。
小李喜欢日本菜。
中文说“喜欢音乐”，日语常说「音楽が好きです」。不要说「音楽を好きです」。

2. Nが嫌いです：讨厌……

人 + は + 对象 + が + 嫌いです

「嫌い」也是二类形容词，讨厌的对象同样用「が」。

森さんは 魚が 嫌いです。
森先生讨厌鱼。
わたしは 暑い 天気が 嫌いです。
我讨厌炎热的天气。
小野さんは スポーツが 嫌いではありません。
小野女士并不讨厌运动。
「嫌い」虽然以い结尾，但不是一类形容词。否定是「嫌いではありません」。

3. Nが上手です / 下手です：擅长 / 不擅长

人 + は + 项目 + が + 上手です/下手です

表达某人擅长或不擅长某事时，对象用「が」。

小野さんは 歌が 上手です。
小野女士唱歌很好。
森さんは テニスが 下手です。
森先生不擅长网球。
李さんは 日本語が 上手です。
小李日语很好。
夸别人可以用「上手です」。但说自己「わたしは日本語が上手です」会显得自夸，自己更常说「まだまだです」。

4. Nがわかります：懂……

人 + は + 内容 + が + わかります

「わかります」表示“明白、懂、理解”。理解的对象用「が」。

わたしは 日本語が わかります。
我懂日语。
李さんは 英語が わかります。
小李懂英语。
この 問題は わかりません。
这个问题我不懂。
「わかります」不是“知道某个事实”的全部用法，本课先掌握“懂语言/明白问题”。

5. は 与 が 的感觉

这一课的句型经常是「AはBが～です」。

部分作用例子
Aは主题：说的是谁小野さんは
Bが对象：喜欢/擅长/懂什么歌が
～です/ます状态或能力好きです、上手です、わかります
小野さんは 歌が 好きです。
说的是小野女士，她喜欢的是歌。
李さんは 日本語が わかります。
说的是小李，他懂的是日语。

6. NやNなど：……啦……等等

名词 + や + 名词 + など

「や」表示不完全列举，意思是“……啦……等等”。常和「など」搭配。

吉田さんは 時々 中国や 韓国へ 行きます。
吉田先生有时去中国、韩国等地方。
わたしは サッカーや 野球が 好きです。
我喜欢足球、棒球等。
机の上に 本や 辞書などが あります。
桌子上有书、词典等等。
「と」表示列举全部；「や」表示只举几个例子，还有其他没说。

7. 频率副词：よく・時々・あまり・全然

描述动作发生频率时，可以用这些副词。

副词中文后接例句
よく经常肯定よく音楽を聞きます
時々有时肯定時々映画を見ます
たまに偶尔肯定たまにテニスをします
あまり不太否定あまりテレビを見ません
全然完全不否定全然わかりません
「あまり」「全然」后面通常要用否定形式：あまり行きません、全然わかりません。

8. から：因为……

理由句 + から

「から」放在句子后面，表示原因、理由。中文是“因为……”。

日本語が 好きですから、毎日 勉強します。
因为喜欢日语，所以每天学习。
この 店は おいしいですから、よく 来ます。
因为这家店好吃，所以经常来。
今日は 忙しいですから、テレビを 見ません。
因为今天忙，所以不看电视。
「から」接在理由句后面。礼貌句也可以直接接：好きですから、忙しいですから。

9. だから：所以……

理由。だから、结果。

「だから」放在结果句前面，连接前后两句话，中文是“所以……”。

日本語が 好きです。だから、毎日 勉強します。
我喜欢日语。所以每天学习。
今日は 忙しいです。だから、早く 帰ります。
今天很忙。所以早点回去。
「から」放在原因句后；「だから」放在结果句前。
