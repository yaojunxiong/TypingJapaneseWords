第13课核心句型

数量词Nが数量ありますNを数量Vます时间量Vます期间に次数どのぐらい

句型中文意思重点
場所に Nが 数量 あります/います某地有几个/几本/几个人……数量词放在动词前
Nを 数量 动词ます做几个/喝几杯/买几本……数量说明动作对象的数量
时间量 动词ます做……多久1時間、2週間、3か月
期间に 次数 动词ます每……做几次1週間に2回
どのぐらい かかりますか大概要花多久？询问时间长度
数量ぐらい/くらい大约……表示概数

1. 場所にNが数量あります/います：某地有多少……

地点 + に + 名词 + が + 数量词 + あります/います

表示“某地有多少东西/多少人”时，数量词通常放在动词前面。

机の上に 本が 三冊 あります。
桌子上有三本书。
教室に 学生が 20人 います。
教室里有20名学生。
冷蔵庫に りんごが 5つ あります。
冰箱里有5个苹果。
数量词不是放在名词前，而常放在动词前：本が三冊あります。

2. Nを数量Vます：做/买/吃多少……

名词 + を + 数量词 + 动词ます

当动作对象有数量时，数量词也放在动词前面。

李さんは 毎日 コーヒーを 2杯 飲みます。
小李每天喝两杯咖啡。
本を 3冊 買いました。
买了三本书。
切手を 5枚 ください。
请给我5张邮票。
りんごを 4つ 食べました。
吃了4个苹果。
中文说“三本书买了”，日语自然顺序是「本を三冊買いました」。

3. 常用数量词：つ・人・冊・枚・台・杯

量词用于例子
～つ一般小物品，1～10个りんごを3つ
～人人数学生が5人
～冊书、本子、杂志本を2冊
～枚薄片状物切手を5枚、写真を3枚
～台机器、车辆車が2台、パソコンが1台
～杯杯装饮料コーヒーを2杯
日语量词很多，本课先记最常用的几个。不同物品要选不同量词。

「～つ」的读法比较特殊，建议整组背下来。

5. 时间量 + 动词：做多久

时间长度 + 动词ます

表示动作持续多久时，时间量直接放在动词前面，不加「に」。

李さんは 毎日 7時間 働きます。
小李每天工作7小时。
昨日 2時間 勉強しました。
昨天学习了2小时。
毎日 30分 ジョギングします。
每天慢跑30分钟。
具体时间点用に：7時に起きます。时间长度不用に：7時間働きます。

6. 期间に次数：每……几次

期间 + に + 次数 + 动词ます

表示频率时，用「1週間に2回」「1か月に1回」这样的结构。

わたしは 1週間に 2回 テニスを します。
我一周打两次网球。
李さんは 1か月に 1回 映画を 見ます。
小李一个月看一次电影。
森さんは 1年に 3回 中国へ 行きます。
森先生一年去三次中国。
「に」在这里表示频率基准：在一个期间内几次。

7. どのぐらい/どれぐらい：多久、多少程度

どのぐらい + かかりますか

询问时间长度、距离、数量大约多少时，可以用「どのぐらい」或「どれぐらい」。

家から 会社まで どのぐらい かかりますか。
从家到公司要花多久？
電車で 1時間ぐらい かかります。
坐电车大概要1小时。
日本語を どのぐらい 勉強しましたか。
你学了多久日语？
3か月ぐらい 勉強しました。
学了大约3个月。
「ぐらい/くらい」表示大约。两种都常见，意思基本相同。

8. かかります：花费时间/金钱

时间/钱 + かかります

「かかります」可以表示花费时间或金钱。

東京から 大阪まで 3時間 かかります。
从东京到大阪要花3小时。
この 修理は 1万円 かかります。
这个修理要花1万日元。
駅まで 10分ぐらい かかります。
到车站大概要10分钟。
花费时间、金钱时，不用「使います」直接套中文，常用「かかります」。
