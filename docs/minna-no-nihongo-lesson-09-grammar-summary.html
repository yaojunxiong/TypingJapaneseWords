第9课核心语法

Nが好きですNが嫌いですNが上手ですNがわかりますNがあります～から

语法中文意思重点
名词が好きです喜欢……喜欢的对象用が
名词が嫌いです讨厌……；不喜欢……嫌い是な形容词
名词が上手です / 下手です擅长…… / 不擅长……能力评价对象用が
名词がわかります懂……；明白……理解的对象用が
名词があります有……这里表示拥有时间、约定、事情等
句子から、句子因为……所以……から表示理由

1. N が好きです：喜欢……

名词 + が + 好きです

「好き」表示“喜欢”，是な形容词。喜欢的对象用助词「が」。

わたしは 音楽が 好きです。
我喜欢音乐。
ミラーさんは 日本料理が 好きです。
米勒先生喜欢日本料理。
子どもは アニメが 好きです。
孩子喜欢动画片。
中文会说“喜欢音乐”，但日语不是「音楽を好きです」，而是「音楽が好きです」。

2. N が嫌いです：讨厌…… / 不喜欢……

名词 + が + 嫌いです

「嫌い」表示“不喜欢、讨厌”。它看起来以「い」结尾，但属于な形容词。

わたしは 魚が 嫌いです。
我不喜欢鱼。
弟は 野菜が 嫌いです。
弟弟讨厌蔬菜。
田中さんは カラオケが あまり好きじゃありません。
田中不太喜欢卡拉OK。
日语会话中直接说「嫌いです」有时听起来比较强。更柔和可以说「あまり好きじゃありません」。

3. どんなNが好きですか：喜欢什么样的……？

どんな + 名词 + が + 好きですか

「どんな」表示“什么样的”。用来询问类别、风格、类型。

どんな音楽が 好きですか。
你喜欢什么样的音乐？
ジャズが 好きです。
我喜欢爵士乐。
どんな映画が 好きですか。
你喜欢什么样的电影？
アクション映画が 好きです。
我喜欢动作电影。
「何の映画」偏“什么电影/哪部电影”；「どんな映画」偏“什么类型、什么风格的电影”。

4. N が上手です / 下手です：擅长 / 不擅长

名词 + が + 上手です / 下手です

「上手」表示擅长、做得好。「下手」表示不擅长、做得不好。评价的对象用「が」。

マリアさんは 日本語が 上手です。
玛丽亚日语很好。
山田さんは 歌が 上手です。
山田唱歌很好。
わたしは 料理が 下手です。
我不擅长做饭。
夸别人可以用「上手ですね」。说自己时直接说「上手です」会显得自夸，通常说「少しできます」「まだまだです」。

5. N がわかります：懂……；明白……

名词 + が + わかります

「わかります」表示“懂、明白、知道意思”。理解的对象用「が」。

わたしは 日本語が 少し わかります。
我懂一点日语。
英語が わかりますか。
你懂英语吗？
はい、少し わかります。
是的，懂一点。
いいえ、全然 わかりません。
不，完全不懂。
「わかります」不是主动学习，而是“理解”。不要说「日本語をわかります」。

6. 程度副词：よく・だいたい・少し・全然

这些副词常和「わかります」一起用，表示理解程度。

副词中文例句
よく很；很好地日本語がよくわかります。
だいたい大致；大概だいたいわかります。
少し一点少しわかります。
あまり不太あまりわかりません。
全然完全不全然わかりません。
「あまり」「全然」后面通常接否定：あまりわかりません、全然わかりません。

7. N があります：有……

名词 + が + あります

第9课里的「あります」常表示“有时间、有约、有事情、拥有某物”等。

時間が あります。
有时间。
約束が あります。
有约。
用事が あります。
有事。
お金が ありません。
没有钱。
「あります」用于无生命物、事情、时间等。人和动物的存在以后会学习「います」。

8. どうしてですか / ～から：为什么？因为……

句子 + から

「どうしてですか」表示“为什么？”「から」表示理由，放在原因句后面。

どうして 早く帰りますか。
为什么早点回去？
用事が ありますから。
因为有事。
どうして 日本語を 勉強しますか。
为什么学习日语？
日本で 働きますから。
因为要在日本工作。
今日は 寒いですから、出かけません。
因为今天冷，所以不出门。
日语的理由常放在前面，也可以只说理由句：忙しいですから。= 因为忙。

9. から 的完整句型

理由句 + から、结果句

「から」连接原因和结果，相当于中文“因为……所以……”。

理由结果完整句
時間がありません新聞を読みません時間がありませんから、新聞を読みません。
日本語が好きです毎日勉強します日本語が好きですから、毎日勉強します。
明日試験があります今晩勉強します明日試験がありますから、今晩勉強します。
中文常说“因为A，所以B”。日语里「から」直接接在理由句后：Aから、B。

第9课一句话记忆

第9课就是学“喜欢什么、会不会、懂不懂、有没有、为什么”。

音楽が好きです喜欢音乐
魚が嫌いです不喜欢鱼
日本語がわかります懂日语
料理が上手です擅长做饭
時間があります有时间
