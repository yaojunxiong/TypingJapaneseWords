1. い形容词过去肯定：～かったです

い形容词去い + かったです

い形容词表示过去状态时，把最后的「い」变成「かったです」。

现在过去中文
暑いです暑かったです热 → 过去很热
寒いです寒かったです冷 → 过去很冷
おもしろいですおもしろかったです有意思 → 过去很有意思
忙しいです忙しかったです忙 → 过去很忙
いいですよかったです好 → 过去很好
昨日は 暑かったです。
昨天很热。
映画は おもしろかったです。
电影很有意思。
旅行は とても楽しかったです。
旅行非常开心。
特别注意：「いいです」的过去式是「よかったです」，不是「いかったです」。

2. い形容词过去否定：～くなかったです

い形容词去い + くなかったです

表示“过去不……”。也可以说「～くありませんでした」，但初级会话常用「～くなかったです」。

现在否定过去否定中文
暑くないです暑くなかったです过去不热
寒くないです寒くなかったです过去不冷
おもしろくないですおもしろくなかったです过去没意思
忙しくないです忙しくなかったです过去不忙
よくないですよくなかったです过去不好
昨日は あまり寒くなかったです。
昨天不太冷。
試験は 難しくなかったです。
考试不难。
そのレストランは あまりよくなかったです。
那家餐厅不太好。

3. な形容词过去：～でした / ～じゃありませんでした

な形容词 + でした / じゃありませんでした

な形容词的过去式和名词句很像。肯定过去用「でした」，否定过去用「じゃありませんでした」。

现在肯定过去肯定过去否定
静かです静かでした静かじゃありませんでした
にぎやかですにぎやかでしたにぎやかじゃありませんでした
便利です便利でした便利じゃありませんでした
きれいですきれいでしたきれいじゃありませんでした
奈良は 静かでした。
奈良以前很安静 / 去奈良时觉得很安静。
ホテルは あまり便利じゃありませんでした。
酒店不太方便。
パーティーは にぎやかでした。
聚会很热闹。
不要说「静かかったです」。な形容词过去用「でした」。

4. 名词过去：Nでした / Nじゃありませんでした

名词 + でした / じゃありませんでした

名词句也可以表示过去“是…… / 不是……”。

现在肯定过去肯定过去否定
雨です雨でした雨じゃありませんでした
休みです休みでした休みじゃありませんでした
日曜日です日曜日でした日曜日じゃありませんでした
昨日は 雨でした。
昨天是雨天。
昨日は 休みじゃありませんでした。
昨天不是休息日。
先週の月曜日は 祝日でした。
上周一是节假日。

5. どうでしたか：过去怎么样？

名词 + は + どうでしたか

想问过去的体验、感想时，用「どうでしたか」。

旅行は どうでしたか。
旅行怎么样？
とても楽しかったです。
非常开心。
試験は どうでしたか。
考试怎么样？
あまり難しくなかったです。
不太难。
第8课「どうですか」问现在或一般评价；第12课「どうでしたか」问过去体验。

6. N1 は N2 より～です：N1比N2更……

名词1 + は + 名词2 + より + 形容词です

「より」表示比较的基准，相当于中文“比……”。

東京は 大阪より 大きいです。
东京比大阪大。
新幹線は 飛行機より 安いです。
新干线比飞机便宜。
日本料理は 中華料理より 好きです。
比起中国菜，我更喜欢日本菜。
比较句中，より后面是被比较的对象。AはBより～ = A比B更～。

7. N1 と N2 と どちらが～ですか：哪个更……？

N1 と N2 と どちらが + 形容词ですか

在两个事物中选择一个时，用「どちらが」。口语也常说「どっちが」。

日本語と 英語と どちらが 難しいですか。
日语和英语哪个更难？
日本語のほうが 難しいです。
日语更难。
コーヒーと 紅茶と どちらが 好きですか。
咖啡和红茶，你更喜欢哪个？
コーヒーのほうが 好きです。
更喜欢咖啡。
回答时常用「Nのほうが～です」，表示“N这一方更……”。

8. N1 より N2 のほうが～です：比起N1，N2更……

N1 + より + N2 + のほうが + 形容词です

这个句型把“更……的一方”明确说出来。中文可以翻译为“比起N1，N2更……”。

大阪より 東京のほうが 大きいです。
比起大阪，东京更大。
バスより 電車のほうが 速いです。
比起公交车，电车更快。
夏より 冬のほうが 好きです。
比起夏天，我更喜欢冬天。
AはBより～ 和 BよりAのほうが～ 意思接近，只是强调方式不同。

9. ～で N が一番～です：在……中，N最……

范围 + で + 名词 + が + 一番 + 形容词です

「一番」表示“最……”。前面常用「～で」说明范围。

スポーツで サッカーが 一番好きです。
在运动中，我最喜欢足球。
日本料理で 寿司が 一番おいしいです。
在日本料理中，寿司最好吃。
一年で 8月が 一番暑いです。
一年中8月最热。
家族で 父が 一番背が高いです。
家里爸爸最高。
范围可以是类别、地点、时间、人群：スポーツで、日本で、一年で、クラスで。
