第10课核心语法

ありますいます場所にNがあります場所にNがいますNは場所にあります位置词

语法中文意思重点
名词があります有……；存在……用于物品、植物、事情等无意志存在
名词がいます有……；在……用于人、动物等有生命存在
場所に N があります某地有N先说地点，再说存在什么
場所に N がいます某地有人/动物存在对象是人或动物
N は 場所にあります/いますN在某地先把N作为主题，再说明位置

1. あります：有 / 在，无生命物

名词 + が + あります

「あります」表示“有、存在”。主要用于桌子、书、车、树、时间、事情等没有自己意志的东西。

机が あります。
有桌子。
電話が あります。
有电话。
公園に 木が あります。
公园里有树。
部屋に テレビが あります。
房间里有电视。
第9课「時間があります」是“有时间”。第10课重点学习“某地有某物 / 某物在某地”。

2. います：有 / 在，人和动物

名词 + が + います

「います」也表示“有、存在”，但用于人、动物等有生命、能自己移动的对象。

男の人が います。
有一个男人。
女の人が います。
有一个女人。
公園に 子どもが います。
公园里有孩子。
庭に 犬が います。
院子里有狗。
人、猫、狗、小鸟等用「います」。桌子、书、车、树、花用「あります」。

3. 場所にNがあります：某地有某物

地点 + に + 物 + が + あります

表示“在某个地方有某物”。地点后面用助词「に」。

部屋に 机が あります。
房间里有桌子。
机の上に 本が あります。
桌子上有书。
駅の前に 銀行が あります。
车站前面有银行。
学校の近くに 公園が あります。
学校附近有公园。
第6课「レストランで食べます」的で表示动作地点；第10课「部屋に机があります」的に表示存在地点。

4. 場所にNがいます：某地有人/动物

地点 + に + 人/动物 + が + います

如果存在的是人或动物，要用「います」。

教室に 学生が います。
教室里有学生。
受付に 女の人が います。
接待处有一位女士。
木の下に 猫が います。
树下有猫。
公園に 子どもが たくさんいます。
公园里有很多孩子。
句型和あります一样，只是存在对象不同：物用あります，人/动物用います。

5. Nは場所にあります：N在某地

物 + は + 地点 + に + あります

如果已经知道要问的东西是什么，想知道它在哪里，就把这个东西放在句首，用「は」提示主题。

トイレは どこに ありますか。
厕所在哪里？
トイレは あそこに あります。
厕所在那里。
本は 机の上に あります。
书在桌子上。
銀行は 駅の前に あります。
银行在车站前面。
「場所にNがあります」= 某地有什么；「Nは場所にあります」= 某物在哪里。

6. Nは場所にいます：人/动物在某地

人/动物 + は + 地点 + に + います

如果主题是人或动物，用「います」说明位置。

山田さんは 事務所に います。
山田先生在办公室。
先生は 教室に います。
老师在教室。
犬は 庭に います。
狗在院子里。
ミラーさんは どこに いますか。
米勒先生在哪里？
问“人在不在某地”时用「いますか」。例如：田中さんはいますか。= 田中先生在吗？

7. 位置词：上・下・前・後ろ・中・外・隣

名词 + の + 位置词

日语的位置表达常用「名词の上」「名词の下」这样的形式。

日语假名中文例子
上うえ上面机の上
下した下面机の下
前まえ前面駅の前
後ろうしろ后面学校の後ろ
右みぎ右边銀行の右
左ひだり左边銀行の左
中なか里面かばんの中
外そと外面うちの外
隣となり旁边，邻近郵便局の隣
近くちかく附近学校の近く
中文说“桌子上”，日语要说「机の上」。中间的「の」不能省。

9. や：列举几个例子

N1 や N2

「や」表示不完全列举，相当于“……啦……啦等”。它暗示还有其他东西没有全部说出来。

箱の中に 手紙や 写真が あります。
盒子里有信、照片等。
部屋に 机や いすが あります。
房间里有桌子、椅子等。
公園に 子どもや 犬が います。
公园里有孩子、狗等。
「と」表示完全列举：A和B。 「や」表示举例列举：A、B之类。

10. あります vs います 总整理

对象用法例句
物品あります机があります。
建筑あります駅があります。
植物あります木があります。
事情/时间あります用事があります。
人います学生がいます。
动物います猫がいます。
植物一般用「あります」，因为它不会像人和动物那样自主移动。
