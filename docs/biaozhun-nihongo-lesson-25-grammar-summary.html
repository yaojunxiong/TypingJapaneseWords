1. 小句（动词简体）＋名词：……的名词

动词简体小句 + 名词

第25课的核心是“名词修饰”。中文常说“明天会议上用的资料”，日语把修饰内容放在名词前面。

これは 明日 会議で 使う 資料です。
这是明天会议上要用的资料。
あれは 森さんが 今夜 泊まる ホテルです。
那是森先生今晚要住的酒店。
あれは 倒産した 会社です。
那是一家倒闭了的公司。
修饰名词时，动词要用简体：使う資料、泊まるホテル、倒産した会社。

2. 修饰句里的主语常用「が」

在修饰名词的小句中，如果需要出现主语，通常用「が」，不用「は」。

森さんが 今夜 泊まる ホテル
森先生今晚要住的酒店
小野さんが 作った 料理
小野女士做的菜
わたしが 昨日 買った 本
我昨天买的书
「は」通常标记大句主题；修饰句内部的小主语多用「が」。

3. 小句＋名词 は 名词/形容词です

小句 + 名词 + は + 说明部分です

被修饰的名词可以作为整个句子的主题。

わたしが 明日 乗る 飛行機は 中国航空です。
我明天要乘坐的飞机是中国航空的。
小野さんが 作る 料理は おいしいです。
小野女士做的菜很好吃。
森さんが 買った 本は これです。
森先生买的书是这本。
先找核心名词：飛行機、料理、本。前面的长句都是修饰它的。

4. 小句＋名词 を/に/から 动词

小句 + 名词 + 助词 + 动词

被修饰的名词不仅能作主语，也可以作宾语、对象、来源等。

中国で 買った CDを 友達に 貸しました。
把在中国买的CD借给了朋友。
中国へ 転勤した 友達に 手紙を 書きました。
给调到中国工作的朋友写了信。
わたしが 知らない 人から 手紙が 来ました。
从我不认识的人那里来了信。
小句＋名词是一个整体，后面再根据句子需要接「を、に、から、は」等助词。

5. 动词简体修饰名词的四种常见形式

形式例子中文
基本形＋名词明日使う資料明天要用的资料
ない形＋名词わたしが知らない人我不认识的人
た形＋名词昨日買った本昨天买的书
なかった形＋名词昨日来なかった人昨天没来的人
修饰名词时不能用ます形：×使います資料 → ○使う資料。

6. 一类形容词＋名词：直接修饰

一类形容词 + 名词

一类形容词修饰名词时，直接放在名词前面。

入り口が 広い あの 建物が わたしの 会社です。
入口很宽的那栋建筑是我的公司。
背が 高い 人は だれですか。
个子高的人是谁？
値段が 安い 店を 探しています。
正在找价格便宜的店。
一类形容词直接修饰名词：広い建物、高い人、安い店。

7. 二类形容词＋な＋名词

二类形容词 + な + 名词

二类形容词修饰名词时，中间要加「な」。

操作が 簡単な パソコンが 欲しいです。
我想要操作简单的电脑。
交通が 便利な 所に 住みたいです。
想住在交通方便的地方。
静かな 部屋で 勉強します。
在安静的房间学习。
きれいな部屋、便利な所、簡単なパソコン。不要漏掉「な」。

8. 名词＋の＋名词

名词 + の + 名词

名词修饰名词时，用「の」。

数学が 専門の 先生は 今日 休みです。
数学专业的老师今天休息。
日本語の 先生に 質問しました。
问了日语老师。
会社の 人と 食事しました。
和公司的人一起吃饭了。
名词修饰名词用「の」，二类形容词修饰名词用「な」。这两个最容易混。

9. 「ところ」：地方、位置、场面

「ところ」常表示“地方、位置、附近、场面”。第25课里会遇到「このあたり」「近くのところ」等位置表达。

表达中文
このところ这段时间；这个地方
あのところ那个地方
このあたり这一带，附近
駅の近く车站附近
交通が便利なところ交通方便的地方
「ところ」很常被前面的形容词小句或动词小句修饰。
