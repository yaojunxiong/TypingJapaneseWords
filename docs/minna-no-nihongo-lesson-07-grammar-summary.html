第7课核心语法

道具で动词言語で动词人にあげます人にもらいますもう～ました

语法中文意思重点
名词で 动词用……做……で表示工具、手段、语言
人に 名词を あげます给某人某物主语把东西给别人，收的人用に
人に/から 名词を もらいます从某人那里得到某物主语收到东西，给的人用に或から
もう 动词ました已经……了表示动作已经完成
まだです还没有回答“もう～ましたか”时常用

1. 道具で动词：用……做……

工具/手段 + で + 动词

助词「で」可以表示工具、手段、方法。中文常翻译成“用……”。

はさみで 紙を 切ります。
用剪刀剪纸。
ボールペンで 名前を 書きます。
用圆珠笔写名字。
パソコンで レポートを 書きます。
用电脑写报告。
カメラで 写真を 撮ります。
用相机拍照片。
第5课「電車で行きます」里的で表示交通手段；第6课「レストランで食べます」里的で表示动作地点；第7课「はさみで切ります」里的で表示工具。

2. 何で～ますか：用什么……？

何 + で + 动词ますか

询问工具、手段时，用「何で」。

何で 名前を 書きますか。
用什么写名字？
ボールペンで 書きます。
用圆珠笔写。
何で 写真を 撮りますか。
用什么拍照片？
スマホで 撮ります。
用手机拍。
「何で」根据上下文可表示“坐什么”“用什么”“为什么”。第7课这里主要是“用什么工具”。

3. 言語で动词：用某种语言……

语言 + で + 动词

「で」也可以表示使用的语言。

日本語で 手紙を 書きます。
用日语写信。
英語で 話します。
用英语说。
中国語で 説明します。
用中文说明。
これは 日本語で 何ですか。
这个用日语怎么说？
「これは日本語で何ですか」是很实用的句子，看到不会说的东西时可以直接问。

4. 人に名词をあげます：给某人某物

人 + に + 物 + を + あげます

「あげます」表示“给”。主语把东西给别人，收到东西的人用「に」。

わたしは 友達に 花を あげます。
我给朋友花。
山田さんは ミラーさんに チョコレートを あげました。
山田给了米勒巧克力。
母に プレゼントを あげます。
给妈妈礼物。
「あげます」的方向是“从我方/主语 → 别人”。初级阶段先不要用「あげます」说别人给我。

5. 人に/から名词をもらいます：从某人得到某物

人 + に/から + 物 + を + もらいます

「もらいます」表示“得到、收到”。主语是收到东西的人。给东西的人可以用「に」或「から」。

わたしは 友達に 花を もらいました。
我从朋友那里收到了花。
ミラーさんは 山田さんに チョコレートを もらいました。
米勒从山田那里收到了巧克力。
会社から 資料を もらいました。
从公司拿到了资料。
给的人如果是组织、公司、学校等，常用「から」：会社から、学校から、銀行から。

6. あげます vs もらいます

句子方向中文
わたしは友達に本をあげました。我 → 朋友我给了朋友书。
わたしは友達に本をもらいました。朋友 → 我我从朋友那里得到了书。
山田さんはミラーさんに花をあげました。山田 → 米勒山田给了米勒花。
ミラーさんは山田さんに花をもらいました。山田 → 米勒米勒从山田那里得到了花。
看主语是谁：主语给出去，用「あげます」；主语收到，用「もらいます」。

7. もう～ました：已经……了

もう + 动词ました

「もう」表示“已经”。和过去形「ました」一起表示动作已经完成。

もう 昼ご飯を 食べました。
已经吃过午饭了。
もう 宿題を しました。
已经做完作业了。
もう レポートを 書きました。
已经写完报告了。
「もう」常用于确认对方是否已经完成某事。

8. もう～ましたか / まだです

もう + 动词ましたか

询问“已经……了吗？”时用「もう～ましたか」。还没做时，可以简短回答「いいえ、まだです」。

もう 昼ご飯を 食べましたか。
已经吃午饭了吗？
はい、もう 食べました。
是的，已经吃了。
もう 宿題を しましたか。
已经做作业了吗？
いいえ、まだです。
不，还没有。
もう 荷物を 送りましたか。
已经寄行李了吗？
いいえ、まだ 送っていません。
不，还没有寄。
第7课常用简短回答「まだです」。更完整的否定是「まだ～ていません」，后面课程会详细学习。
