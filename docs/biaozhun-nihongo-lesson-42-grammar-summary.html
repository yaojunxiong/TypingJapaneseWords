1. Vたまま：保持……的状态

动词た形 + まま

表示前一个动作完成后，形成的状态一直保持着，没有改变，就进行了后面的动作或出现了后面的情况。

テレビを つけたまま、出かけてしまいました。
电视开着就出门了。
窓を 開けたまま、寝てしまいました。
窗户开着就睡着了。
電気を つけたまま、朝まで 寝ました。
灯开着一直睡到早上。
「まま」重点是“状态没有改变”。常带有“忘了关、忘了改”的感觉。

2. Nのまま：以……的状态

名词 + の + まま

名词接「まま」时，中间要加「の」。表示保持某种状态、身份、样子。

靴の まま 部屋に 入らないでください。
请不要穿着鞋进房间。
この 野菜は 生の まま 食べられます。
这种蔬菜可以生吃。
昔の ままの 町並みが 残っています。
保留着从前样子的街景。
名词＋のまま：そのまま、生のまま、昔のまま、靴のまま。

3. まま vs ながら

表达重点例句
Vたまま保持动作后的状态電気をつけたまま寝ました。
Vながら两个动作同时进行音楽を聞きながら勉強します。
Nのまま保持名词状态靴のまま入りました。
「つけたまま」是灯已经打开，状态继续；「聞きながら」是听和学习同时进行。

4. Vるのに：用于……；做……时

动词基本形 + のに + 使います / 必要です / 便利です

表示用途、目的或评价对象。中文常译为“用于……、做……时……”。

この はさみは 紙を 切るのに 使います。
这把剪刀用于剪纸。
この 辞書は 日本語を 勉強するのに 便利です。
这本词典对学习日语很方便。
パスポートを 申請するのに 写真が 必要です。
申请护照需要照片。
这里的「のに」不是“明明……却……”，而是“用于……、为了……时”。

5. 小句＋はずです：应该……，按理说……

小句简体 + はずです

根据已知事实、常识、安排做出判断，表示“按理说应该……”。

李さんは もうすぐ 来るはずです。
小李应该马上会来。
今日は 日曜日ですから、銀行は 休みの はずです。
今天是星期天，所以银行应该休息。
この 道を まっすぐ 行けば、駅に 着くはずです。
沿这条路一直走，应该会到车站。
「はずです」不是单纯猜测，而是“根据理由推断理应如此”。

6. はずです 的接续

前接形式例句
动词简体＋はずです来るはずです
一类形容词直接＋はずですおいしいはずです
二类形容词な＋はずです便利なはずです
名词の＋はずです休みのはずです
否定ない＋はずです来ないはずです
过去た＋はずです着いたはずです
二类形容词用「なはず」；名词用「のはず」。这是最容易错的地方。

7. はずがありません：不可能……

小句简体 + はずがありません

表示根据情况判断“不可能……、不应该……”。语气比普通否定更强。

そんな はずは ありません。
不可能是那样。
李さんが 約束を 忘れるはずが ありません。
小李不可能忘记约定。
この 店が 休みの はずが ありません。
这家店不可能休息。
「はずがありません」是“没有这种道理/不可能”，不是简单的“不”。

8. はずです vs でしょう vs かもしれません

表达确定程度例句
はずです有根据，按理应该もう着いたはずです。
でしょう大概吧もう着いたでしょう。
かもしれません也许，可能性不确定もう着いたかもしれません。
はずがありません强烈否定可能性忘れるはずがありません。
有明确理由时用「はずです」更自然；只是猜测用「でしょう」「かもしれません」。
