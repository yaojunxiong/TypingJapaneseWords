第28课核心句型

NをくれますNをあげますNをもらいますVてあげますVてもらいますVてくれます

句型中文意思重点
Aは わたしに Nを くれますA给我/我方某物东西流向“我方”
Aは Bに Nを あげますA给B某物东西从我方或第三者给出去
Aは Bに/から Nを もらいますA从B那里得到某物站在接受者角度
Vてあげます为别人做……我方主动帮别人
Vてもらいます请/得到别人为我做……我方受益
Vてくれます别人为我做……别人主动帮我方

1. くれます：别人给我/我方

给的人 + は + わたし/我方 + に + 物 + を + くれます

「くれます」表示别人把东西给“我”或“我方的人”。重点是东西朝说话人这边来。

馬さんは わたしに 地図を くれました。
小马给了我地图。
先生は 妹に 本を くれました。
老师给了我妹妹一本书。
友達は わたしに 写真を くれました。
朋友给了我照片。
如果接受者是“我”，日语里「わたしに」常可省略：馬さんは地図をくれました。

2. あげます：我/别人给别人

给的人 + は + 收的人 + に + 物 + を + あげます

「あげます」表示把东西给出去。说话人通常站在给出者一侧。

わたしは 小野さんに お土産を あげました。
我给了小野女士土特产。
李さんは 森さんに 花を あげました。
小李给了森先生花。
兄は 弟に 自転車を あげました。
哥哥给了弟弟自行车。
给上级或不熟的人时，「あげます」有时显得“我施恩给你”，实际会话要注意礼貌表达。

3. もらいます：从别人那里得到

接受者 + は + 给的人 + に/から + 物 + を + もらいます

「もらいます」站在接受者角度，表示“得到、收到”。

わたしは 森さんに チケットを もらいました。
我从森先生那里得到了票。
妹は 先生から 辞書を もらいました。
妹妹从老师那里得到了词典。
李さんは 友達に プレゼントを もらいました。
小李从朋友那里收到了礼物。
人作来源时「に/から」都可以；组织、公司作来源时常用「から」。

4. あげます・もらいます・くれます 的方向感

表达视角例句
あげます从我方/某人给出去私は李さんに本をあげました。
もらいます我方/某人得到私は李さんに本をもらいました。
くれます别人给我方李さんは私に本をくれました。
判断诀窍：东西朝“我这边”来，用「くれます」；强调“我得到”，用「もらいます」；强调“给出去”，用「あげます」。

5. Vてあげます：为别人做……

人 + に + 动词て形 + あげます

表示为别人做某事，带有“帮别人、为别人做”的语气。

わたしは おじいさんに 道を 教えてあげました。
我给老爷爷指了路。
妹に 日本語を 教えてあげます。
我教妹妹日语。
友達の 荷物を 持ってあげました。
我帮朋友拿了行李。
对上级直接说「～てあげます」可能显得自己高高在上，实际会话要慎用。

6. Vてもらいます：请别人为我做……

我方 + は + 人 + に + 动词て形 + もらいます

表示自己得到别人帮助，或者请别人为自己做某事。

わたしは 係の 人に 切符を 交換してもらいました。
我请工作人员给我换了票。
友達に 写真を 撮ってもらいました。
我请朋友给我拍了照片。
先生に 作文を 直してもらいました。
我请老师帮我修改作文。
「てもらいます」强调“我得到了帮助”。主语常是受益者。

7. Vてくれます：别人为我做……

别人 + は + 我方 + に + 动词て形 + くれます

表示别人主动为我或我方做某事，带有感谢、受益的感觉。

友達が わたしに 地図を 書いてくれました。
朋友给我画了地图。
森さんは わたしの 荷物を 持ってくれました。
森先生帮我拿了行李。
母は わたしに お弁当を 作ってくれました。
妈妈给我做了便当。
如果受益者是“我”，「わたしに」常可省略：友達が地図を書いてくれました。

8. てあげます・てもらいます・てくれます 对比

表达中文感觉视角
教えてあげました我帮别人教/告诉我方付出
教えてもらいました我请别人教/告诉我我方受益，别人帮助
教えてくれました别人教/告诉了我别人主动帮我方
私は 李さんに 日本語を 教えてあげました。
我教小李日语。
私は 李さんに 日本語を 教えてもらいました。
我请小李教我日语。
李さんは 私に 日本語を 教えてくれました。
小李教了我日语。

9. それに：而且，再加上

句子。+ それに + 句子。

「それに」用于追加理由、信息或优点，中文常译为“而且、再说”。

この レストランは 安いです。それに、とても おいしいです。
这家餐厅很便宜，而且很好吃。
この 部屋は 広いです。それに、駅から 近いです。
这个房间很宽敞，而且离车站近。
「それで」表示因果；「それに」表示追加。

10. 先：目的地、对方、前方

「先」在本课里常表示“目的地、去处、对方、前方”。

表达中文
行き先目的地，去处
旅行先旅行目的地
送り先寄送地址，对方
連絡先联系方式，联系地址
この先前方，接下来
「先」不只表示时间上的“先”，还常表示“前方、目标地点、对象”。

第28课一句话记忆

第28课就是学“谁给谁东西”和“谁为谁做事”。关键看东西或好处是往外走，还是往我这边来。

馬さんは私に地図をくれました小马给了我地图
私は小野さんにお土産をあげました我给小野女士土特产
私は森さんにチケットをもらいました我从森先生那里得到了票
道を教えてあげました给别人指路
切符を交換してもらいました请别人帮我换票
地図を書いてくれました别人给我画了地图
