第21课核心语法

～と思います～と言います～でしょう？普通形接续意见・引用

语法中文意思重点
普通形 + と思います我想……；我认为……表达自己的判断、意见、推测
普通形 + と思いません我不认为……否定“认为”这个动作
普通形 + と言います说……引用别人说的话
普通形 + と言いました说了……转述过去别人说的话
普通形 + でしょう？……吧？确认对方也知道或同意的事情

1. 普通形 + と思います：我想…… / 我认为……

普通形 + と + 思います

第21课把第20课学的普通形拿来表达意见、判断和推测。中文可以翻译为“我想……”“我觉得……”“我认为……”。

明日 雨が 降ると思います。
我想明天会下雨。
日本語は おもしろいと思います。
我觉得日语很有意思。
この映画は あまりおもしろくないと思います。
我觉得这部电影不太有意思。
田中さんは もう帰ったと思います。
我想田中先生已经回去了。
「と思います」前面用普通形，不用ます形、です形。

2. ～と思います 前面的普通形整理

「と思います」前面的句子要改成普通形。

类型礼貌形普通形 + と思います
动词肯定行きます行くと思います
动词否定行きません行かないと思います
动词过去行きました行ったと思います
い形容词高いです高いと思います
な形容词便利です便利だと思います
名词休みです休みだと思います
な形容词和名词的现在肯定普通形要加「だ」：便利だと思います、学生だと思います。

3. ～と思いません：我不认为……

普通形 + とは + 思いません / 普通形 + と思いません

表示“我不认为……”。初级阶段可以先掌握「～と思いません」。会话里也常听到强调对比的「～とは思いません」。

明日 雨が 降ると思いません。
我不认为明天会下雨。
この問題は 簡単だと思いません。
我不觉得这个问题简单。
あの人は 悪い人だとは思いません。
我不认为那个人是坏人。
「高くないと思います」= 我认为不贵；「高いと思いません」= 我不认为贵。意思接近，但焦点不同。

4. ～についてどう思いますか：关于……你怎么看？

名词 + について + どう思いますか

询问对某个话题的看法时，用「～についてどう思いますか」。

日本の生活について どう思いますか。
你觉得日本的生活怎么样？
便利ですが、物価が高いと思います。
我觉得很方便，但是物价高。
このニュースについて どう思いますか。
关于这条新闻，你怎么看？
とても大切な問題だと思います。
我认为这是非常重要的问题。
「について」表示“关于……”。后面常接「話します」「調べます」「どう思いますか」。

5. 普通形 + と言います：说……

普通形 + と + 言います

「と言います」用于引用别人说的话，表示“说……”。

田中さんは 明日 休むと言いました。
田中先生说他明天休息。
先生は 試験は 簡単だと言いました。
老师说考试很简单。
母は 早く帰ってくださいと言いました。
妈妈说请早点回家。
友達は 日本へ行きたいと言っています。
朋友说想去日本。
引用内容后面用「と」。如果是直接引用，也可以用引号：田中さんは「明日休みます」と言いました。

6. 直接引用 vs 间接引用

类型例句中文
直接引用田中さんは「明日休みます」と言いました。田中说：“明天休息。”
间接引用田中さんは明日休むと言いました。田中说他明天休息。
直接引用先生は「宿題をしてください」と言いました。老师说：“请做作业。”
间接引用先生は宿題をすると言いました。老师说要做作业。/ 说会做作业。
直接引用可以保留原话的礼貌形；间接引用通常把内容改成普通形。

7. でしょう？：……吧？

普通形 + でしょう？

「でしょう？」用于确认对方也知道、也同意的事情。中文可以翻译为“……吧？”

明日 パーティーへ 行くでしょう？
明天你去聚会吧？
この映画は おもしろいでしょう？
这部电影很有意思吧？
田中さんは 先生でしょう？
田中先生是老师吧？
ここは 静かでしょう？
这里很安静吧？
「でしょう？」不是单纯提问，而是带有“我觉得是这样，你也这样认为吧？”的确认感。

8. でしょう？前面的接续

「でしょう？」前面基本接普通形，但な形容词和名词现在肯定时，不加「だ」。

类型普通形＋でしょう？
动词行く行くでしょう？
动词否定行かない行かないでしょう？
い形容词高い高いでしょう？
な形容词静かだ静かでしょう？
名词学生だ学生でしょう？
「と思います」前：静かだと思います；「でしょう？」前：静かでしょう？ 名词、な形容词的「だ」会去掉。

9. 同意・不同意的回答

对「でしょう？」可以表示同意或不同意。

日本語は おもしろいでしょう？
日语很有意思吧？
ええ、おもしろいです。
嗯，很有意思。
この店は 高いでしょう？
这家店很贵吧？
いいえ、あまり高くないです。
不，不太贵。
明日 暇でしょう？
明天有空吧？
すみません、ちょっと忙しいです。
不好意思，有点忙。
