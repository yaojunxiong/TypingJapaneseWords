1. 自动词：事情自己发生

名词 + が + 自动词

自动词表示“某物自己发生变化、某状态出现”，不强调是谁做的动作。

電車が 急に 止まりました。
电车突然停了。
ドアが 開きました。
门开了。
電気が 消えました。
灯灭了。
財布が 落ちました。
钱包掉了。
自动词常用「が」标记发生变化的主体：電車が止まる、ドアが開く、電気が消える。

2. 他动词：有人去做某动作

人 + が/は + 名词 + を + 他动词

他动词强调有人对某物做动作，动作对象用「を」。

李さんが ドアを 開けました。
小李打开了门。
森さんは 電気を 消しました。
森先生关了灯。
わたしは 財布を 落としました。
我把钱包弄掉了。
他动词常用「を」标记动作对象：ドアを開ける、電気を消す、財布を落とす。

4. 自动词て形＋います：结果状态

自动词て形 + います

表示动作发生后留下来的状态，中文常译为“……着”。

窓が 開いています。
窗户开着。
電気が ついています。
灯亮着。
ドアが 閉まっています。
门关着。
椅子が 壊れています。
椅子坏着。/ 椅子坏了。
第15课的「ています」可表示正在做；这里表示“变化后的状态还保持着”。

5. 他动词てあります：人为动作后的状态

名词 + が + 他动词て形 + あります

表示某人事先做了某动作，结果状态留在那里。虽然动词是他动词，但对象常用「が」。

壁に ポスターが 貼ってあります。
墙上贴着海报。
机の 上に メモが 置いてあります。
桌子上放着便条。
窓が 開けてあります。
窗户被打开着。/ 窗户事先开好了。
「開いています」只说窗户开着；「開けてあります」暗示有人为了某目的把窗户打开了。

6. Vてしまいます：做完，完成

动词て形 + しまいます

表示把某动作全部做完，强调完成。

宿題を 全部 やってしまいました。
作业全部做完了。
この 本を 読んでしまいました。
这本书读完了。
会議の 前に 資料を コピーしてしまいます。
会议前把资料复印完。
强调“做完”时，「てしまいます」比普通过去「しました」更有完成感。

7. Vてしまいました：遗憾、后悔、糟糕

「てしまいました」也常表示“不小心做了、糟糕，做掉了”，带遗憾或后悔。

財布を 落としてしまいました。
不小心把钱包弄丢了。
大切な 書類を 忘れてしまいました。
糟糕，把重要文件忘了。
約束の 時間に 遅れてしまいました。
不小心迟到了约定时间。
同一个形式有两种感觉：完成 = 做完了；遗憾 = 不小心做了。要看上下文。

8. 形容词そうです：看起来……

一类形容词去い + そうです / 二类形容词 + そうです

根据外观、样子判断“看起来……”。这不是第32课的“听说そうです”。

この ケーキは おいしそうです。
这个蛋糕看起来很好吃。
李さんは 忙しそうです。
小李看起来很忙。
この 仕事は 大変そうです。
这份工作看起来很辛苦。
一类形容词：おいしい→おいしそう；二类形容词：大変→大変そう。

9. 动词そうです：好像要……

动词ます形去ます + そうです

表示根据眼前情况判断某动作快要发生。

雨が 降りそうです。
好像要下雨了。
この 箱は 落ちそうです。
这个箱子好像要掉下来了。
電車が 止まりそうです。
电车好像要停了。
动词样态「そうです」前接ます形词干：降ります→降りそう、落ちます→落ちそう。

10. そうです：传闻 vs 样态

用法接续例句中文
传闻简体小句＋そうです明日は雨が降るそうです。听说明天下雨
样态动词ます形词干＋そうです雨が降りそうです。好像要下雨
样态一类形容词词干＋そうですおいしそうです。看起来好吃
样态二类形容词＋そうです大変そうです。看起来辛苦
「降るそうです」= 听说会下雨；「降りそうです」= 看起来快下雨了。

ドアを開けました打开了门
