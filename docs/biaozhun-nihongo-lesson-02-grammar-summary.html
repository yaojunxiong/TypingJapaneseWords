第2课核心句型

これはNですそれはNですかあれはだれのNですかこのN/そのN/あのN何・だれ・どなた

句型中文意思重点
これ/それ/あれ は Nです这/那/那 是……指示事物，单独使用
これは Nですか这是……吗？句末か表示疑问
これは 何ですか这是什么？何读「なん」
この/その/あの N は～です这个/那个/那个N是……后面必须接名词
N は だれの N ですかN是谁的……？だれの表示“谁的”

1. これ・それ・あれ：这个 / 那个 / 那个

これ / それ / あれ + は + 名词 + です

「これ」「それ」「あれ」是指示代词，可以单独指代物品。

词中文距离感觉
これ这个离说话人近
それ那个离听话人近，或前面提到的东西
あれ那个离说话人和听话人都远
これは 本です。
这是书。
それは かばんです。
那是包。
あれは テレビです。
那是电视。
「これ・それ・あれ」本身就等于“这个东西/那个东西”，后面不直接接名词。

2. これは何ですか：这是什么？

これ / それ / あれ + は + 何 + ですか

询问物品是什么时，用「何ですか」。这里的「何」读作「なん」。

これは 何ですか。
这是什么？
それは 辞書です。
那是词典。
あれは 何ですか。
那是什么？
あれは 新聞です。
那是报纸。
「何」有时读「なに」，有时读「なん」。在「何ですか」里常读「なんですか」。

3. それはNですか：那是……吗？

指示词 + は + 名词 + ですか

和第1课一样，句末加「か」就可以变成疑问句。

それは テレビですか。
那是电视吗？
いいえ、テレビではありません。パソコンです。
不，不是电视。是电脑。
これは 日本語の 本ですか。
这是日语书吗？
はい、そうです。
是的，是这样。

4. この・その・あの：这个…… / 那个……

この / その / あの + 名词

「この」「その」「あの」不能单独使用，后面必须接名词。

词中文例子
この这个……この本：这本书
その那个……そのかばん：那个包
あの那个……あの人：那个人
この カメラは スミスさんのです。
这台相机是史密斯先生的。
その ノートは だれのですか。
那个笔记本是谁的？
あの 人は 田中さんです。
那个人是田中先生。
区别：これ = 这个东西；この本 = 这本书。不能说「このは本です」。

5. だれ / どなた：谁 / 哪位

だれ 表示“谁”；どなた 是更礼貌的“哪位”。

あの 人は だれですか。
那个人是谁？
あの 人は 森さんです。
那个人是森先生。
あの 方は どなたですか。
那位是谁？
あの 方は 小野さんです。
那位是小野女士。
「方（かた）」比「人（ひと）」更礼貌；「どなた」比「だれ」更礼貌。

6. だれのNですか：是谁的……？

名词 + は + だれ + の + 名词 + ですか

「だれの」表示“谁的”。如果后面的名词从上下文能知道，可以省略。

これは だれの かばんですか。
这是谁的包？
それは 李さんの かばんです。
那是小李的包。
この 傘は だれのですか。
这把伞是谁的？
わたしのです。
是我的。
「わたしのです」后面省略了已知名词，比如「かばん」「傘」。

7. NのN：内容、所属、属性

第2课继续使用「の」。它可以表示“谁的”，也可以表示内容、种类、所属。

表达中文说明
わたしの本我的书所属
日本語の本日语书内容/种类
会社の電話公司的电话所属/关联
森さんのかばん森先生的包所有者
日语中两个名词连在一起时，经常需要用「の」连接。

9. 中国学习者容易错的地方

错误正确说明
これは本のです。これは本です。判断句不用の
このは本です。これは本です。/ この本です。この后面必须接名词
これ本はだれのですか。この本はだれのですか。修饰名词用この
あの人はだれのですか。あの人はだれですか。问人是谁用だれ
これはだれ本ですか。これはだれの本ですか。“谁的”要用だれの
わたしのかばんですか。回答：はい、わたしです。はい、わたしのです。回答“是谁的包”要说“我的”
