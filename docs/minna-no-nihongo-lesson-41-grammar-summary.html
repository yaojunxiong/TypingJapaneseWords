第41课核心语法

いただきますくださいますやります～ていただきます～てくださいます

语法中文意思重点
いただきます我得到；我收下「もらいます」的谦让语，说自己从长辈/上级那里得到
くださいます对方给我「くれます」的尊敬语，抬高给东西的人
やります给晚辈/动物/植物比「あげます」更向下，多用于孩子、宠物、植物
～ていただきます请别人为我做；承蒙别人做「～てもらいます」的谦让语
～てくださいます别人为我做「～てくれます」的尊敬语

1. いただきます：我得到 / 我收下

私は 人に/から 名词を いただきます

「いただきます」是「もらいます」的谦让语。说“我从别人那里得到东西”时，把自己放低，显得更礼貌。

中文理解：我收到了…… / 承蒙……给我……。对象通常是老师、上司、客人、长辈等。
私は先生に本をいただきました。
我从老师那里得到了书。
社長からお土産をいただきました。
我从社长那里收到了特产礼物。
お客様に名刺をいただきました。
我从客人那里收到了名片。
普通说法更礼貌中文
先生に本をもらいました。先生に本をいただきました。从老师那里得到了书。
社長にお土産をもらいました。社長にお土産をいただきました。从社长那里收到了礼物。

2. くださいます：对方给我

人が 私に 名词を くださいます

「くださいます」是「くれます」的尊敬语。重点是“别人给我或我方东西”，同时抬高对方。

先生が私に本をくださいました。
老师给了我书。
社長が私にお土産をくださいました。
社长给了我特产礼物。
お客様が妹に花をくださいました。
客人给了我妹妹花。
「くださいました」是过去式。说长辈、上级、客人给我东西时，比「くれました」更礼貌。
普通说法更礼貌中文
先生が本をくれました。先生が本をくださいました。老师给了我书。
社長がお土産をくれました。社長がお土産をくださいました。社长给了我礼物。

3. やります：给晚辈、动物、植物

私は 下位对象に 名词を やります

「やります」表示给晚辈、动物、植物东西。它比「あげます」更“向下”，所以对成年人随便使用会很失礼。

私は弟にお菓子をやりました。
我给了弟弟点心。
犬にえさをやります。
给狗喂食。
花に水をやります。
给花浇水。
对朋友、同事、客人不要随便说「やります」。一般用「あげます」或更礼貌的表达。

4. ～ていただきます：请别人为我做 / 承蒙别人做

私は 人に 动词て形 + いただきます

这是「～てもらいます」的谦让语。表示“我请别人为我做某事”或“承蒙别人为我做某事”。

先生に作文を見ていただきました。
我请老师看了作文 / 承蒙老师帮我看了作文。
部長に駅まで送っていただきました。
部长送我到了车站。
お客様に説明していただきました。
承蒙客人进行了说明。
这个表达重点在“我受益”，同时把自己放低，所以很适合对老师、上司、客户使用。
普通礼貌
先生に教えてもらいました。先生に教えていただきました。
部長に送ってもらいました。部長に送っていただきました。

5. ～てくださいます：别人为我做

人が 私に 动词て形 + くださいます

这是「～てくれます」的尊敬语。表示长辈、上司、客人等为我或我方做某事。

先生が日本語を教えてくださいました。
老师教了我日语。
部長が駅まで送ってくださいました。
部长送我到了车站。
お客様が写真を撮ってくださいました。
客人帮我拍了照片。
「～てくださいました」强调“对方主动为我做了”，并抬高对方。

6. ～ていただきます vs ～てくださいます

表达中文视角
先生に教えていただきました。我请老师教了我 / 承蒙老师教我。我得到帮助，自己放低
先生が教えてくださいました。老师教了我。老师为我做，抬高老师
先生に作文を直していただきました。
我请老师帮我改了作文。
先生が作文を直してくださいました。
老师帮我改了作文。
两个都很礼貌。区别在主语和视角：いただきます = 我承蒙别人做；くださいます = 对方为我做。

7. あげます・もらいます・くれます 的礼貌升级

普通表达第41课表达用途
もらいますいただきます我从上级/长辈那里得到
くれますくださいます上级/长辈给我
あげますやります给晚辈、动物、植物
～てもらいます～ていただきます请上级/长辈为我做
～てくれます～てくださいます上级/长辈为我做
