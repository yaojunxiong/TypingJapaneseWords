第29课核心语法

自動詞＋ています结果状态～てしまいました完成遗憾

语法中文意思重点
自動詞＋ています……着；……了描述动作发生后留下的状态
～てしまいました……完了；糟糕……了表示动作完成，或表达后悔、遗憾、意外
自动词 vs 他动词自己变化 vs 人为动作第29课重点看“状态”，第30课会学“人为做好”

1. 自動詞＋ています：结果状态

自动词て形 + います

这里的「～ています」不是“正在……”，而是表示某个动作发生以后，结果状态还保留着。

中文理解：不是强调“谁做了动作”，而是强调“现在看到的状态”。
自动词て形＋います中文
開きます開いています开着
閉まります閉まっています关着
つきますついています亮着；开着
消えます消えています灭着；关着
壊れます壊れています坏了
止まります止まっています停着
窓が開いています。
窗户开着。
ドアが閉まっています。
门关着。
電気がついています。
灯亮着。
エレベーターが壊れています。
电梯坏了。

2. 自动词：重点是“状态自己变成这样”

第29课里经常出现自动词。自动词不强调谁做的，而是描述东西的状态。

自动词中文例句
開きます开窓が開いています。
閉まります关ドアが閉まっています。
つきます亮；开電気がついています。
消えます灭；关電気が消えています。
壊れます坏時計が壊れています。
落ちます掉落財布が落ちています。
止まります停車が止まっています。
中文里我们常说“门开着”“灯亮着”。日语里这种状态常用「自动词て形＋います」。

3. ～てしまいました：做完了

动词て形 + しまいました

「～てしまいました」可以表示动作完全结束。这个时候不一定有负面意思，只是强调“已经做完”。

宿題をしてしまいました。
作业做完了。
本を全部読んでしまいました。
书全部读完了。
お金を全部使ってしまいました。
钱全部花完了。
如果上下文没有遗憾感，它可以只是“全部完成”的意思。

4. ～てしまいました：糟糕……了 / 不小心……了

「～てしまいました」也常表示后悔、遗憾、意外、不小心做了某事。

財布をなくしてしまいました。
钱包弄丢了。
パスポートを忘れてしまいました。
把护照忘了。
コップを割ってしまいました。
把杯子打碎了。
電車に傘を忘れてしまいました。
把伞忘在电车上了。
这个用法里，中文常带“糟糕、不小心、结果……了”的感觉。

5. ～てしまいます / ～てしまいました / ～ちゃいました

表达中文语感
～てしまいます会……完；会不小心……现在/未来
～てしまいました已经……完了；糟糕……了过去/完成
～ちゃいました……掉了；糟糕……了口语缩略
食べてしまいました。
吃完了 / 不小心吃掉了。
食べちゃいました。
吃掉了。口语。
口语中「～てしまいました」常变成「～ちゃいました」；「～でしまいました」常变成「～じゃいました」。例如：飲んでしまいました → 飲んじゃいました。

6. 第29课和第30课的关键区别

第29课学的是 自动词＋ています，第30课会学 他动词＋てあります。两者很容易混。

表达中文重点
窓が開いています。窗户开着。只描述状态，不管是谁开的
窓が開けてあります。窗户被打开好了。有人为了某目的打开了窗户
電気がついています。灯亮着。看到灯处于亮的状态
電気がつけてあります。灯被打开好了。有人提前把灯开好了
第29课：东西现在是什么状态。第30课：有人事先把东西弄成这个状态。
