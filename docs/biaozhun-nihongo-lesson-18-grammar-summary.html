1. 一类形容词くなります：变得……

一类形容词去い + く + なります

表示事物自然变化或状态发生变化时，用「～くなります」。

携帯電話は とても 小さくなりました。
手机变得非常小了。
だんだん 暖かくなります。
渐渐变暖和。
日本語が 少し 難しくなりました。
日语变得有点难了。
部屋が 明るくなりました。
房间变亮了。
变化方法：小さい → 小さくなります；暑い → 暑くなります；いい → よくなります。

2. 二类形容词になります：变得……

二类形容词 + に + なります

二类形容词表示变化时，不用「く」，而是加「に」。

部屋が きれいに なりました。
房间变干净了。
町が にぎやかに なりました。
城市变热闹了。
交通が 便利に なりました。
交通变方便了。
きれい是二类形容词，正确是「きれいになりました」，不是「きれいくなりました」。

3. 名词になります：成为……

名词 + に + なります

身份、职业、季节、年龄等发生变化时，用「名词になります」。

息子は 医者に なりました。
儿子成为了医生。
もう 春に なりました。
已经到春天了。
来年、20歳に なります。
明年满20岁。
「になります」强调结果变化：从不是医生变成医生，从不是春天变成春天。

4. 一类形容词くします：把……弄得……

对象 + を + 一类形容词去い + く + します

「なります」偏自然变化；「します」表示人为地让某物变成某种状态。

テレビの 音を 大きくします。
把电视声音调大。
部屋を 明るくします。
把房间弄亮。
髪を 短くしました。
把头发剪短了。
对象用「を」：音を大きくします、部屋を明るくします。

5. 二类形容词にします：把……弄成……

对象 + を + 二类形容词 + に + します

二类形容词表示人为改变时，加「にします」。

部屋を きれいに してください。
请把房间打扫干净。
資料を 簡単に しました。
把资料弄简单了。
この 町を 安全に します。
让这个城市变得安全。
请求别人“把……弄成……”时，常用「～にしてください」。

6. 名词にします：决定为…… / 做成……

名词 + に + します

「Nにします」可以表示选择、决定，也可以表示把某物做成某种结果。

コーヒーに します。
我选咖啡。/ 我要咖啡。
昼ご飯は カレーに します。
午饭决定吃咖喱。
会議は 明日に します。
会议定在明天。
点餐时「～にします」很常用，比「～をください」多了“我决定选这个”的感觉。

7. なります vs します

表达核心意思例句
小さくなります自己变小/结果变小携帯電話が小さくなりました。
小さくします人为把它变小文字を小さくします。
きれいになります变干净/漂亮部屋がきれいになりました。
きれいにします把它弄干净部屋をきれいにします。
一句话记：自己变化用「なります」，人为改变用「します」。

第18课一句话记忆

第18课就是学“变了”和“把它变成”：自然变化用なります，人为改变用します。

携帯電話は小さくなりました手机变小了
部屋がきれいになりました房间变干净了
息子は医者になりました儿子成为医生了
音を大きくします把声音调大
部屋をきれいにしてください请把房间弄干净
昼ご飯はカレーにします午饭决定吃咖喱
