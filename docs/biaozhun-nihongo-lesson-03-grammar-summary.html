1. ここ・そこ・あそこ：这里、那里、那里

ここ / そこ / あそこ + は + 名词 + です

「ここ」「そこ」「あそこ」是地点指示词，用来指“这里、那里、那边”。

词中文距离感觉
ここ这里离说话人近
そこ那里离听话人近，或前面提到的地方
あそこ那里/那边离双方都远
ここは デパートです。
这里是百货商店。
そこは 図書館です。
那里是图书馆。
あそこは 入口です。
那边是入口。
第2课的「これ・それ・あれ」指物；第3课的「ここ・そこ・あそこ」指地点。

2. Nはどこですか：……在哪里？

名词 + は + どこ + ですか

「どこ」表示“哪里”。询问地点时，用「どこですか」。

トイレは どこですか。
洗手间在哪里？
あちらです。
在那边。
受付は どこですか。
接待处在哪里？
ここです。
在这里。
问地点时，日语常用「Nはどこですか」。中文“厕所在哪里”不要直译成「トイレどこ」。

3. こちら・そちら・あちら：这边、那边、那边

こちら / そちら / あちら

「こちら」「そちら」「あちら」比「ここ」「そこ」「あそこ」更礼貌，也可以表示方向、地点或人物。

普通礼貌中文
こここちら这里/这边
そこそちら那里/那边
あそこあちら那里/那边
どこどちら哪里/哪边
受付は こちらです。
接待处在这边。
エレベーターは あちらです。
电梯在那边。
お国は どちらですか。
您的国家是哪里？
「どちら」不仅能问地点，也能礼貌地问“哪一位、哪个方向、哪个国家”。

4. NはNですか、Nですか：是A还是B？

名词 + は + A + ですか、B + ですか

想让对方在两个答案中选择一个时，可以用两个「ですか」。

ここは 郵便局ですか、銀行ですか。
这里是邮局还是银行？
銀行です。
是银行。
田中さんは 会社員ですか、学生ですか。
田中先生是公司职员还是学生？
会社員です。
是公司职员。
回答二选一问题时，一般直接回答其中一个选项，不用「はい」或「いいえ」。

5. NもNです：……也是……

名词 + も + 名词 + です

「も」表示“也”。当后面的判断和前面相同，可以用「も」代替「は」。

ここは デパートです。あそこも デパートです。
这里是百货商店。那边也是百货商店。
李さんは 中国人です。王さんも 中国人です。
小李是中国人。小王也是中国人。
「も」强调“也”。不要和主题助词「は」同时乱用成「もは」。

6. NはどこのNですか：是哪里的……？

名词 + は + どこ + の + 名词 + ですか

询问产地、所属公司、所属国家时，可以用「どこの」。

この カメラは どこの カメラですか。
这台相机是哪儿的相机？
日本の カメラです。
是日本的相机。
この 会社は どこの 会社ですか。
这家公司是哪国/哪里的公司？
「どこ」问地点；「どこのN」问“哪里的N”。

7. いくらですか：多少钱？

名词 + は + いくら + ですか

询问价格时，用「いくらですか」。

この かばんは いくらですか。
这个包多少钱？
5,800円です。
5800日元。
あの 時計は いくらですか。
那块表多少钱？
18,000円です。
18000日元。
日元读作「円（えん）」。例如 800円 = はっぴゃくえん。
