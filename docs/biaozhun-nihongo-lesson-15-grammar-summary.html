第15课核心句型

Vています正在做VてもいいですVてはいけません場所にV目的地に入ります

句型中文意思重点
今 Vています现在正在做……表示动作正在进行
Vてもいいです可以做……表示许可
Vてもいいですか可以做……吗？请求许可
Vてはいけません不可以做……表示禁止
場所に 座ります/入ります坐到/进入某处动作到达点用に
ここで Vてもいいですか可以在这里做……吗？动作场所用で

1. Vています：正在做……

动词て形 + います

表示某个动作现在正在进行时，用「～ています」。常和「今」一起出现。

小野さんは 今 新聞を 読んでいます。
小野女士现在正在读报纸。
李さんは 今 テレビを 見ています。
小李现在正在看电视。
森さんは 電話を しています。
森先生正在打电话。
子供たちは 公園で 遊んでいます。
孩子们正在公园玩。
「読んでいます」来自「読みます → 読んで + います」。先变て形，再加います。

2. Vています 的否定与过去

形式例句中文
肯定読んでいます正在读
否定読んでいません没有在读
过去肯定読んでいました当时正在读
过去否定読んでいませんでした当时没有在读
今、勉強していません。
现在没有在学习。
昨日の夜、テレビを 見ていました。
昨天晚上正在看电视。

3. Vてもいいです：可以做……

动词て形 + も + いいです

表示允许做某事，中文是“可以……”。

ここで 写真を 撮っても いいです。
可以在这里拍照。
この 本を 読んでも いいです。
可以读这本书。
少し 休んでも いいです。
可以稍微休息一下。
「てもいいです」表示许可，不是“也好”的直译。重点是“可以做”。

4. Vてもいいですか：可以……吗？

动词て形 + も + いいですか

请求许可时，用「～てもいいですか」。回答可用「はい、いいです」或「すみません、ちょっと……」。

この 椅子に 座っても いいですか。
可以坐这把椅子吗？
はい、いいです。
可以。
ここで タバコを 吸っても いいですか。
可以在这里吸烟吗？
すみません、ここは ちょっと……。
不好意思，这里有点不方便……
日语中拒绝许可时常说得委婉，不一定直接说“不行”。

5. Vてはいけません：不可以做……

动词て形 + は + いけません

表示禁止，语气较强，中文是“不可以……、禁止……”。

ここで 写真を 撮ってはいけません。
不可以在这里拍照。
図書館で 大きい 声で 話してはいけません。
不可以在图书馆大声说话。
この 部屋に 入ってはいけません。
不可以进入这个房间。
「てはいけません」比「だめです」更像规则、规定。日常标识中常见。

6. てもいいです vs てはいけません

表达意思例句
Vてもいいです可以做ここで休んでもいいです。
Vてもいいですか可以做吗ここに座ってもいいですか。
Vてはいけません不可以做ここでタバコを吸ってはいけません。
学习时可以成对记：许可 = てもいい；禁止 = てはいけません。

7. 場所に座ります / 入ります：动作到达点用に

地点/位置 + に + 座ります・入ります・乗ります

表示动作最终到达的位置或进入的地方时，用「に」。

椅子に 座ります。
坐到椅子上。
部屋に 入ります。
进入房间。
電車に 乗ります。
上电车。
动作发生地用「で」：部屋で勉強します。动作到达点用「に」：部屋に入ります。

8. 场所で动作：在哪里做某事

地点 + で + 动词

第15课也会继续用第7课的「で」表示动作发生场所。

ここで 写真を 撮っても いいですか。
可以在这里拍照吗？
食堂で 昼ご飯を 食べています。
正在食堂吃午饭。
会議室で 会議を しています。
正在会议室开会。
「で」强调动作在哪里进行；「に」强调存在或到达点。

11. 中国学习者容易错的地方

错误正确说明
