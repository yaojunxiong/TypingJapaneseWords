1. 动词意志形：我要…… / ……吧

动词意志形

意志形可以表示说话人自己的决心，也可以用于亲近关系中的邀请、提议。

もう 11時だから、寝よう。
已经11点了，睡吧。/ 我要睡了。
少し 休もう。
稍微休息一下吧。
今日は 早く 帰ろう。
今天早点回去吧。/ 今天我要早点回去。
意志形比「ましょう」更随意，常用于自言自语、朋友之间。正式邀请仍可用「ましょう」。

2. 意志形变化规则

类型基本形意志形规则
一类动词書く書こうう段变お段＋う
一类动词急ぐ急ごうぐ→ごう
一类动词読む読もうむ→もう
一类动词買う買おうう→おう
二类动词食べる食べよう去る＋よう
二类动词見る見よう去る＋よう
三类动词来る来よう（こよう）特殊
三类动词するしよう特殊
「行く」的意志形是「行こう」，不是「行よう」。

3. Vようと思います：我想…… / 打算……

动词意志形 + と + 思います

表达自己的想法、打算时，用「～ようと思います」。常表示此刻决定或现在的想法。

明日 病院へ 行こうと 思います。
我想明天去医院。
週末、友達と 映画を 見ようと 思います。
我打算周末和朋友看电影。
日本語の 勉強を 続けようと 思います。
我想继续学习日语。
「と思います」前面用意志形，不用ます形：×行きますと思います → ○行こうと思います。

4. Vようと思っています：一直打算……

动词意志形 + と + 思っています

「思っています」表示这个打算已经持续了一段时间，比「思います」更像已有计划。

将来、日本で 働こうと 思っています。
我一直打算将来在日本工作。
来年、車を 買おうと 思っています。
我打算明年买车。
いつか 富士山に 登ろうと 思っています。
我一直想有一天去爬富士山。
简单区别：今決めた感じ＝思います；前からの計画＝思っています。

5. Vる/Vないつもりです：打算做/不做

动词基本形 + つもりです / 动词ない形 + つもりです

表示较明确的个人计划或意向。

来月、旅行するつもりです。
我打算下个月去旅行。
今日は お酒を 飲まないつもりです。
今天我打算不喝酒。
卒業した後で、日本の会社に 入るつもりです。
毕业后打算进日本公司。
「つもりです」主观意向较强，常用于“我打算……”。

6. Vる/Nの予定です：预定…… / 计划……

动词基本形 + 予定です / 名词 + の + 予定です

「予定です」表示日程、计划、安排，比「つもりです」更客观。

来週 出張する予定です。
计划下周出差。
会議は 3時からの 予定です。
会议预定3点开始。
飛行機は 6時に 到着する予定です。
飞机预定6点到达。
名词接「予定」时要用「の」：会議の予定、3時からの予定。

7. つもりです vs 予定です

表达感觉例句
つもりです个人打算、主观意向来年留学するつもりです。
予定です日程安排、客观计划来年留学する予定です。
ようと思います我想做，语气较柔和来年留学しようと思います。
ようと思っています一直有这个想法来年留学しようと思っています。
越正式、越像日程安排，用「予定です」越自然；越表达个人意愿，用「つもりです」「ようと思います」。

8. まだVていません：还没有……

まだ + 动词て形 + いません

表示到现在为止某动作还没有完成。

宿題は まだ 終わっていません。
作业还没有完成。
旅行の 予定は まだ 決まっていません。
旅行计划还没有定。
李さんは まだ 来ていません。
小李还没有来。
和计划表达一起用时很常见：まだ決まっていません、まだ予約していません。

12. 中国学习者容易错的地方

错误正确说明
もう11時だから寝ますよう。もう11時だから寝よう。意志形不是ます＋よう
明日病院へ行くと思います。想说“我打算去”明日病院へ行こうと思います。打算做用意志形＋と思います
来年車を買うと思っています。来年車を買おうと思っています。已有打算用意志形＋と思っています
旅行するつもります。旅行するつもりです。つもり是名词，后面接です
会議は3時から予定です。会議は3時からの予定です。名词/时间短语接予定用の
今日はお酒を飲まない予定です。想说“我打算不喝酒”今日はお酒を飲まないつもりです。个人“不打算”常用つもり
