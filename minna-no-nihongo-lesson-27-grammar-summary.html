第27课核心语法

语法中文意思重点
可能形能……；会……；可以……表示能力或可能性
～が見えます看得见……自然进入视野，不是主动看
～が聞こえます听得见……自然听到，不是主动听
～ができます……建成了 / 做好了 / 产生了表示完成、建成、出现
～しか～ません只……；仅仅……后面一定用否定形

1. 可能形：表示“能……”

一类动词

う段 → え段 + ます

原形可能形中文
書きます書けます能写
読みます読めます能读
行きます行けます能去
話します話せます能说
買います買えます能买

二类动词

去掉ます + られます

原形可能形中文
食べます食べられます能吃
見ます見られます能看
起きます起きられます能起床
借ります借りられます能借

三类动词

原形可能形中文
しますできます能做
来ます来られます能来
普通动词常用「を」，变成可能形后，很多时候用「が」。例如：日本語を話します → 日本語が話せます。
私は日本語が少し話せます。
我会说一点日语。
このATMは夜も使えます。
这个ATM晚上也能使用。

2. ～が見えます：看得见……

名词 + が見えます

「見えます」表示东西自然进入眼睛，是“看得见”，不是主动去看。

日语中文感觉
見ます看主动去看
見えます看得见自然看到
窓から海が見えます。
从窗户看得见海。
ここから富士山が見えます。
从这里看得见富士山。

3. ～が聞こえます：听得见……

名词 + が聞こえます

「聞こえます」表示声音自然传到耳朵里，不是主动听。

日语中文感觉
聞きます听；问主动听
聞こえます听得见声音自然传来
鳥の声が聞こえます。
听得见鸟叫声。
電話の声がよく聞こえません。
电话里的声音听不太清楚。

4. ～ができます：建成 / 做好 / 出现

第27课里的「できます」不只是“能做”，也可以表示“建成、做好、完成、产生、交到朋友”。

日语中文
駅ができます车站建成
スーパーができます超市建成
友達ができます交到朋友
用事ができます有事了
料理ができます饭做好了
駅の前に大きいスーパーができました。
车站前建了一家大超市。
日本で友達ができました。
我在日本交到了朋友。

5. ～しか～ません：只……

名词 / 数量词 + しか + 否定形

「しか」后面一定要接否定。
表达中文后面形式
だけ只肯定、否定都可以
しか只后面必须否定
私は日本語が少ししか話せません。
我只会说一点日语。
財布に1000円しかありません。
钱包里只有1000日元。

一句话记忆

第27课就是学“能不能”：
話せます = 能说；読めます = 能读；見えます = 看得见；聞こえます = 听得见；できます = 能做 / 建成 / 完成；しか～ません = 只……
