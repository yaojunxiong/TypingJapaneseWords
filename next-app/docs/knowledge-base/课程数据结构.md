# 课程数据结构

## 文件位置

```
src/data/minna/lessons/
├── lesson-01.json
├── lesson-02.json
...
└── lesson-50.json
```

文件命名：`lesson-{两位数字}.json`。

## JSON Schema

每个文件遵循 schema `minna.lesson.v1`：

```jsonc
{
  "schema": "minna.lesson.v1",
  "course": "minna",
  "lessonNo": 1,
  "lessonId": "minna_lesson_01",
  "title": { "zh": "第1课", "en": "Lesson 1", "ja": "第1課" },
  "subtitle": { "zh": "名词句・自我介绍", "en": "Noun sentences / self-introduction" },
  "focus": { "zh": "学习...", "en": "Learn..." },
  "sections": [
    {
      "type": "vocab",
      "title": { "zh": "核心词汇", "en": "Core Vocabulary" },
      "items": [
        {
          "id": "l01_v01",
          "jp": "わたし",
          "kana": "わたし",
          "zh": "我",
          "en": "I / me",
          "tags": ["person"],
          "examples": [
            { "jp": "...", "zh": "...", "en": "..." }
          ],
          "practice": [
            {
              "id": "l01_v01_p01",
              "skill": "vocab",
              "question": { "zh": "...", "en": "..." },
              "options": [
                { "text": { "zh": "我", "en": "I / me" }, "correct": true },
                { "text": { "zh": "你", "en": "you" } }
              ],
              "explanation": { "zh": "...", "en": "..." }
            }
          ]
        }
      ]
    }
  ]
}
```

## Section 类型

| type | 显示名称 |
|------|----------|
| `vocab` | 词汇 |
| `grammar` | 语法 |
| `examples` | 例句 |
| `quiz` | 测验 |
| `review` | 复习 |

## Item 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 唯一 ID |
| `jp` | string | 日语 |
| `kana` | string | 假名读音 |
| `zh` | string | 中文释义 |
| `en` | string | 英文释义 |
| `pattern` | string | (语法) 句型 |
| `title` | LangText | 标题 |
| `explanation` | LangText | 说明/解析 |
| `tags` | string[] | 标签 |
| `examples` | Example[] | 例句 |
| `practice` | Practice[] | 练习题 |

## 练习字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 练习 ID |
| `skill` | string | 技能类型 |
| `question` | LangText | 题干 |
| `options` | Option[] | 选项（含 correct 标记） |
| `explanation` | LangText | 解析 |
| `type` | string | 特殊题型（如 `order`） |
| `answer` | string[] | 排序题答案 |
| `parts` | string[] | 排序题片段 |

## LangText 类型

```typescript
type LangText = {
  zh?: string
  en?: string
  ja?: string
  jp?: string
}
```

## 课程元数据

`src/lib/minna-lessons.ts` 包含 `LESSONS_1_50` 常量，记录 50 课的标题与副标题。

## 校验标准

`scripts/verify-lessons.mjs` 检查：
1. 文件是否存在
2. 是否包含 `vocab`、`grammar`、`examples`、`quiz` 四个 section
3. 是否有 title
4. 是否有 learning items
5. 是否有选择题练习
6. 选择题是否有题干、至少 2 个选项、至少 1 个正确选项
