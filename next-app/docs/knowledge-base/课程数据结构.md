# 课程数据结构

## 文件位置

```
src/data/minna/lessons/
├── lesson-01.json
├── lesson-02.json
...
└── lesson-50.json
```

文件命名：`lesson-{两位数字}.json`。

---

## JSON Schema

### schema v1（当前）

```jsonc
{
  "schema": "minna.lesson.v1",
  "course": "minna",
  "lessonNo": 1,
  "lessonId": "minna_lesson_01",
  "title": { "zh": "第1课", "en": "Lesson 1", "ja": "第1課" },
  "subtitle": { "zh": "名词句・自我介绍", "en": "Noun sentences / self-introduction" },
  "focus": { "zh": "学习...", "en": "Learn..." },
  "sections": [
    { "type": "vocab", "items": [...] },
    { "type": "grammar", "items": [...] },
    { "type": "examples", "items": [...] },
    { "type": "quiz", "items": [...] }
  ]
}
```

### schema v2（会话主线，目标）

```jsonc
{
  "schema": "minna.lesson.v2",
  "course": "minna",
  "lessonNo": 1,
  "lessonId": "minna_lesson_01",
  "title": { "zh": "第1课", "en": "Lesson 1" },
  "subtitle": { "zh": "名词句・自我介绍", "en": "Noun sentences / self-introduction" },
  "focus": { "zh": "学习...", "en": "Learn..." },
  "conversationGoal": {
    "zh": "能用日语进行简单的自我介绍（姓名、国籍、职业）",
    "en": "Be able to introduce yourself in Japanese (name, nationality, occupation)"
  },
  "sections": [
    // ===== 会话主线 section（按学习顺序） =====
    { "type": "conversation",          "sourceType": "official_video_subtitle" },
    { "type": "conversation_vocab",    "sourceType": "ai_generated" },
    { "type": "conversation_grammar",  "sourceType": "ai_generated" },
    { "type": "conversation_examples", "sourceType": "ai_generated" },
    { "type": "conversation_quiz",     "sourceType": "ai_generated" },
    { "type": "conversation_review",   "sourceType": "ai_generated" },
    // ===== 补充参考 section（保留但非主线） =====
    { "type": "vocab" },
    { "type": "grammar" },
    { "type": "examples" },
    { "type": "quiz" }
  ]
}
```

详见 `会话主线课程重构方案.md`。

## Section 类型

### 当前 v1

| type | 显示名称 | 说明 |
|------|----------|------|
| `vocab` | 词汇 | 核心词汇（教材词汇表） |
| `grammar` | 语法 | 核心语法（教材语法列表） |
| `examples` | 例句 | 核心例句（教材例句） |
| `quiz` | 测验 | 综合测试 |
| `review` | 复习 | 错题复习 |

### v2 新增（会话主线）

| type | sourceType | 显示名称 | 说明 |
|------|------------|----------|------|
| `conversation` | official_video_subtitle | 会话原文 | 官方视频字幕原文 |
| `conversation_vocab` | ai_generated | 会话词汇 | 从会话原文提取的词汇 |
| `conversation_grammar` | ai_generated | 会话语法 | 从会话原文提取的语法点 |
| `conversation_examples` | ai_generated | 会话例句 | 基于原句的替换练习 |
| `conversation_quiz` | ai_generated | 会话测试 | 服务于背会话的测试题 |
| `conversation_review` | ai_generated | 背诵挑战 | 整课背诵挑战 |

---

## sourceType 标记

| sourceType | 含义 | 适用 section |
|------------|------|-------------|
| `official_video_subtitle` | 来自官方视频字幕原文，不可修改 | conversation |
| `official_textbook` | 来自教材原文，不可修改 | conversation |
| `ai_generated` | AI 辅助生成，需人工审核 | conversation_vocab/grammar/examples/quiz/review |
| `temporary_test` | 临时测试数据，待替换 | conversation（过渡期） |

---

## Item 字段

### conversation item

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 唯一标识 `lXX-conv-YYY` |
| `speaker` | string | 否 | 说话人 |
| `jp` | string | 是 | 日语原文 |
| `kana` | string | 否 | 假名注音 |
| `zh` | string | 是 | 中文翻译 |
| `keyword` | string | 否 | 关键词 |
| `videoStart` | string | 否 | 视频开始时间（m:ss.s） |
| `videoEnd` | string | 否 | 视频结束时间（m:ss.s） |
| `sourceType` | string | 是 | `official_video_subtitle` |
| `needsReview` | boolean | 否 | 是否需要人工审核 |
| `reviewNote` | string | 否 | 审核备注 |

### conversation_vocab / conversation_grammar / conversation_examples / conversation_quiz item

复用现有 `vocab`/`grammar`/`examples`/`quiz` item 的字段结构，但 `sourceType` 标记为 `ai_generated`。

## 校验标准

`scripts/verify-lessons.mjs` 检查：
1. 文件是否存在
2. 是否包含 `vocab`、`grammar`、`examples`、`quiz` 四个 section（v1）
3. 是否包含 `conversation` section（v2 新增）
4. 是否有 title
5. 是否有 learning items
6. 是否有选择题练习
7. 选择题是否有题干、至少 2 个选项、至少 1 个正确选项
