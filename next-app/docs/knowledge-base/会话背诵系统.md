# 会话背诵系统

## 项目背景

当前项目为「Minna Next」—— 基于 Next.js App Router + Supabase SSR Auth 的日语学习应用，课程数据来自《みんなの日本語》50 课 JSON 文件。现有练习模块包括词汇（vocab）、语法（grammar）、例句（examples）、测验（quiz）、错题复习（review），均通过 `stage` 参数路由到 `/lessons/[lessonNo]/practice` 页面。

---

## 新设计方向：会话主线

### 核心原则

每一课以"会话背诵"为主线。词汇、语法、例句、测试都围绕该课会话内容重新编排。用户学习一课的最终目标不是单独记词汇或语法，而是能背下并说出该课会话。

### 会话 vs 传统模式的定位

| 维度 | 传统模式（当前） | 会话主线（目标） |
|------|-----------------|-----------------|
| 学习顺序 | vocab → grammar → examples → quiz | 会话目标 → 会话原文 → 会话词汇 → 会话语法 → 例句 → 测试 → 背诵 |
| 词汇来源 | 教材词汇表 | 从会话原文提取 |
| 语法来源 | 教材语法列表 | 从会话原文提取 |
| 例句来源 | 教材例句 | 基于会话原句做替换 |
| 测试题型 | 独立选择题 | 服务于背会话（听句选义、中文转日语、关键词补全、语序排列、角色接话、整课背诵） |
| 最终目标 | 掌握词汇和语法 | 背下并说出该课会话 |

### 数据设计

在 `lesson-XX.json` 的 schema v2 中，以 conversation 为主线：

```jsonc
{
  "schema": "minna.lesson.v2",
  "conversationGoal": { "zh": "能用日语进行简单的自我介绍", "en": "..." },
  "sections": [
    // 主线 section（按学习顺序排列）
    { "type": "conversation",         "sourceType": "official_video_subtitle" },
    { "type": "conversation_vocab",   "sourceType": "ai_generated" },
    { "type": "conversation_grammar", "sourceType": "ai_generated" },
    { "type": "conversation_examples","sourceType": "ai_generated" },
    { "type": "conversation_quiz",    "sourceType": "ai_generated" },
    { "type": "conversation_review",  "sourceType": "ai_generated" },
    // 补充参考 section（保留但不作为主线）
    { "type": "vocab" },
    { "type": "grammar" },
    { "type": "examples" },
    { "type": "quiz" }
  ]
}
```

详见 `会话主线课程重构方案.md`。

## 数据来源规则

| 规则 | 说明 |
|------|------|
| 原文来源 | conversation 原文（`jp` 字段）必须来自视频字幕或人工确认的教材原文 |
| AI 辅助范围 | AI 只能做拆句、翻译、`kana` 注音、`keyword` 提取、时间轴对齐等辅助加工 |
| 禁止行为 | AI 不得自编会话内容冒充 `official_video_subtitle` |
| 扩展标记 | AI 生成的词汇/语法/例句/测试必须标记 `sourceType: "ai_generated"` |

## 练习模式设计（会话主线）

### 模式 1：会话视频 + 同步字幕

读取 `section.videoUrl`，嵌入视频播放器。字幕同步高亮当前句子。

### 模式 2：会话句子拆解

逐句展示：
- 说话人 + 日语原文 + 假名 + 中文
- 每句标注语法点
- 每句标注关键词

### 模式 3：中文提示背诵

| 步骤 | 界面 |
|------|------|
| 1 | 显示中文句子，隐藏日语 |
| 2 | 用户默背或朗读日语 |
| 3 | 点击「显示答案」揭示日语原文 + 假名 |
| 4 | 用户评估「我会了」或「不熟」 |

### 模式 4：角色扮演

分角色显示台词，用户扮演其中一个角色，系统显示对方台词。

### 模式 5：整课背诵挑战

逐句提示（从中文到日语），完整背出全部会话后标记课程完成。

## 熟悉度存储

使用 localStorage `minna.conversation.familiarity.v1`：

```typescript
type FamiliarityRecord = {
  [itemId: string]: {
    status: 'known' | 'unfamiliar'
    count: number
    lastSeen: string
  }
}
```

标记「不熟」的句子同时写入 `minna.mistakes.v1` 错题本。
