# 会话背诵系统

## 项目背景

当前项目为「Minna Next」—— 基于 Next.js App Router + Supabase SSR Auth 的日语学习应用，课程数据来自《みんなの日本語》50 课 JSON 文件。现有练习模块包括词汇（vocab）、语法（grammar）、例句（examples）、测验（quiz）、错题复习（review），均通过 `stage` 参数路由到 `/lessons/[lessonNo]/practice` 页面，由 `lesson-practice-client.tsx` 驱动。

**会话背诵（conversation）** 是第 6 个练习模式，使用已有的课程 JSON 数据、本地存储、云端同步和管理员后台基础设施。

---

## 数据结构方案

### 课程 JSON 扩展

在 `src/data/minna/lessons/lesson-XX.json` 的 `sections` 数组中新增 type `conversation`，与现有 `vocab`/`grammar`/`examples`/`quiz` 平级：

```jsonc
{
  "type": "conversation",
  "id": "l01_conversation",
  "title": {
    "zh": "会话背诵",
    "en": "Conversation Practice"
  },
  "items": [
    {
      "id": "l01_conv_01",
      "jp": "はじめまして、わたしは田中です。",
      "kana": "はじめまして、わたしはたなかです。",
      "zh": "初次见面，我是田中。",
      "en": "Nice to meet you, I'm Tanaka.",
      "speaker": "田中",
      "order": 1
    },
    {
      "id": "l01_conv_02",
      "jp": "こちらこそ、よろしくお願いします。",
      "kana": "こちらこそ、よろしくおねがいします。",
      "zh": "彼此彼此，请多关照。",
      "en": "Likewise, nice to meet you.",
      "speaker": "山田",
      "order": 2
    }
  ],
  "videoUrl": "https://example.com/lesson01-conv.mp4",
  "dialogTitle": {
    "zh": "自我介绍",
    "en": "Self Introduction"
  }
}
```

### 新增 Item 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 唯一标识 `lXX_conv_YY` |
| `jp` | string | 是 | 日语原文 |
| `kana` | string | 否 | 假名注音（填充 `jp` 中的汉字读音） |
| `zh` | string | 是 | 中文翻译 |
| `en` | string | 否 | 英文翻译 |
| `speaker` | string | 否 | 说话人角色名 |
| `order` | number | 是 | 对话顺序（从 1 递增） |

### section 级别字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | 是 | 固定 `"conversation"` |
| `id` | string | 是 | section 唯一 ID |
| `title` | LangText | 是 | section 标题 |
| `dialogTitle` | LangText | 否 | 本段对话的标题 |
| `videoUrl` | string | 否 | 对话示范视频链接 |
| `items` | ConversationItem[] | 是 | 逐句列表 |

### 数据校验

在 `scripts/verify-lessons.mjs` 和后台 audit 中新增 `conversation` 校验：

```javascript
const REQUIRED = ['vocab', 'grammar', 'examples', 'quiz', 'conversation']
```

校验规则：
- 至少 2 个 items
- 每个 item 必须有 `jp`、`zh`、`kana`
- `order` 必须从 1 开始连续递增
- `id` 必须唯一

## 练习模式设计

### 模式 1：会话视频

读取 `section.videoUrl`，如果存在则提供视频播放界面。视频下方显示完整对话文本列表。

交互流程：
1. 用户观看示范视频
2. 逐句显示文本，高亮当前正在说的句子
3. 播放完毕后进入逐句背诵模式

### 模式 2：中文提示背诵

| 步骤 | 界面 |
|------|------|
| 1 | 显示中文句子，隐藏日语 |
| 2 | 用户默背或朗读日语 |
| 3 | 点击「显示答案」或按空格键揭示日语原文 + 假名 |
| 4 | 用户评估「我会了」或「不熟」 |

### 模式 3：逐句跟读

显示日语原文 + 假名，播放 TTS 语音（复用 `speechSynthesis`，`lesson-practice-client.tsx` 已有实现），用户跟读后手动进入下一句。

## 我会了 / 不熟逻辑

### 存储设计

使用 localStorage `minna.conversation.familiarity.v1`，格式：

```typescript
type FamiliarityRecord = {
  [itemId: string]: {
    status: 'known' | 'unfamiliar'
    count: number      // 学习次数
    lastSeen: string   // ISO date
  }
}
```

### 业务流程

1. 用户完成一句背诵后选择「我会了」→ 标记 `known`
2. 用户选择「不熟」→ 标记 `unfamiliar`，该句进入复习队列
3. 同一课中所有 `unfamiliar` 句子会在当前 session 内循环出现，直到用户标记 `known`
4. 跨课复习（通过复习中心进入）时展示所有 `unfamiliar` 句子

### 与错题本联动

`minna.mistakes.v1` 中新增 `type: 'conversation'` 条目：

```typescript
{
  lessonNo: number
  stage: 'conversation'
  jp: string
  kana: string
  meaning: string
  sourceId: string
  at: string
  type: 'conversation'  // 新增
}
```

在 `/mistakes` 页面中（`mistakes-client.tsx`）自动显示会话型错题，支持过滤 `stage === 'conversation'`。

## 收藏与 TTS 复用

### 收藏按钮

每个会话句子旁显示 `<FavoriteToggleButton>`（已实现在 `favorite-toggle-button.tsx`），收藏后写入 `minna.vocab.favorites.v1`，在 `/favorites` 页面显示。

### TTS 语音

复用 `lesson-practice-client.tsx` 中的 `speakHint()` 函数（`src/components/lesson-practice-client.tsx:201-209`）：

```typescript
function speakHint() {
  if (!voiceOn || !current?.hint || !('speechSynthesis' in window)) return
  window.speechSynthesis.cancel()
  const ut = new SpeechSynthesisUtterance(current.hint)
  ut.lang = 'ja-JP'
  ut.rate = 0.9
  window.speechSynthesis.speak(ut)
}
```

会话背诵客户端直接调用此函数，使用 item 的 `kana` 或 `jp` 作为 `hint`。
