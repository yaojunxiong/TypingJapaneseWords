# 管理员后台

> **当前状态**：多数后台能力为只读恢复模式，不提供编辑/发布/删除。后台不影响前台 50 课学习主线、打卡、确认动作或 0/4 算法。

## 入口

- 后台首页：`/admin`
- 访客浏览记录：`/admin/activity`
- 用户管理：`/admin/users`
- 系统检测：`/admin/system`
- 论坛审核：`/admin/forum`
- 审批记录：`/admin/membership-requests`
- 知识库报告：`/admin/knowledge-base`
- 课程详情：`/admin/lessons/{lessonNo}`
- CSV 导出：`/admin/export.csv`

## 访问控制

1. 使用 Supabase Auth 获取当前用户
2. 查询 `user_roles` 表，要求 `role === 'admin'`
3. 硬编码管理员：`yaojunxiong@gmail.com` 强制为 admin

## 功能

### 一键 Audit

扫描 1-50 课的 JSON 数据，逐课报告：

| 指标 | 说明 |
|------|------|
| Sections | 课程节数 |
| V/G/E/Q | 各 section 的 item 数 |
| Items | 总学习条目 |
| Examples | 例句总数 |
| Practice | 选择题总数 |
| Issues | 问题清单 |

### 数据检索

- 支持跨 50 课搜索词汇、例句、练习题
- 按 section 类型和课号过滤
- 结果按课号或匹配类型排序
- 支持分页

### CSV 导出

- 基于当前检索条件导出 CSV
- 包含：课号、section、itemId、匹配位置、日语、假名、释义、摘要

### 课程详情阅读

- 逐 course 查看所有 sections 和 items
- 显示词汇、例句、练习题
- 支持收起/展开、section 类型过滤
- 导航到上一课/下一课

### 访客浏览记录（只读）

- 路由：`/admin/activity`
- 数据源：`visitor_activity_events`
- 读取最近 300 条页面访问事件
- 支持只读搜索：email、path、page_type、user_agent
- 支持筛选：全部/已登录/匿名、最近 1 小时/24 小时/7 天/全部、page_type、课号
- 支持排序：时间、用户、Path、类型、课号
- 顶部统计当前筛选结果、已登录访问、匿名访问、涉及用户数
- 显示时间、邮箱/匿名、path、page_type、lesson_no、referrer、user_agent 摘要
- 不提供删除、修改或导出按钮
- 不记录密码、token、cookie、完整 query、输入内容或完整 IP

### 用户管理（只读）

- 路由：`/admin/users`
- 只读查看用户角色、邮箱和创建/更新时间
- 不提供角色修改、删除或禁用按钮

### 系统检测（只读）

- 路由：`/admin/system`
- 展示环境、域名、后台模式、可用路由和检测清单
- 不执行 shell 命令，不写数据库

### 论坛审核（只读）

- 路由：`/admin/forum`
- 只读查看论坛帖子和审核状态
- 不开放审核通过、隐藏、删除、置顶或封禁操作

### 审批记录（只读）

- 路由：`/admin/membership-requests`
- 只读查看会员等级申请审批记录和流程图预览
- 不开放通过或驳回操作

### 知识库报告

- 路由：`/admin/knowledge-base`
- 浏览 `docs/knowledge-base` 中的项目报告和专题文档

## 限制

- 不可编辑 JSON
- 不可发布课程
- 不可修改用户角色
- 不可删除访客记录
- 不可执行审批通过/驳回
- 不可执行论坛审核写操作
- 不可查看 Supabase 密钥或 secret
