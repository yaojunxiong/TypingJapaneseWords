# 项目结构总览

```
next-app/
├── .env.local                  # 本地环境变量（gitignored）
├── .env.local.example          # 环境变量模板
├── next.config.ts              # Next.js 配置
├── tsconfig.json               # TypeScript 配置，@/ 指向 src/
├── package.json                # 依赖管理
├── RELEASE_NOTES_v1.md         # v1 发布说明
├── scripts/
│   └── verify-lessons.mjs      # 课程数据校验脚本
├── src/
│   ├── middleware.ts            # Next.js Middleware（调用 Supabase middleware）
│   ├── app/                    # App Router 页面
│   ├── components/             # 客户端交互组件
│   ├── data/
│   │   └── minna/lessons/      # 课程 JSON 数据（50 课）
│   ├── lib/                    # 核心逻辑：i18n、课程元数据、云同步
│   └── utils/supabase/         # Supabase 客户端/服务端/middleware/配置
└── docs/
    └── knowledge-base/         # 本知识库
```

## src/ 目录职责

| 目录 | 职责 |
|------|------|
| `src/app/` | App Router 页面、API Route、Auth 回调 |
| `src/components/` | 客户端组件：课程列表、练习、错题本、收藏、后台、导航、聊天 |
| `src/data/minna/lessons/` | 50 课 JSON 数据文件 |
| `src/lib/` | 不含 React 的纯逻辑：i18n、课程元数据 Singleton、学习同步引擎 |
| `src/utils/supabase/` | Supabase SSR 客户端工厂函数 |
| `src/middleware.ts` | Next.js Middleware（注入 Supabase Auth） |
