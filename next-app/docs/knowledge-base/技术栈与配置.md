## TypeScript 配置要点

- `target`: ES2022
- `strict`: true
- `moduleResolution`: bundler
- `jsx`: preserve
- 路径别名：`@/*` → `./src/*`

## 环境变量

来自 `.env.local.example`：

```
NEXT_PUBLIC_SUPABASE_URL=https://ycjuceortcduakxscfes.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_sK-...
NEXT_PUBLIC_APP_ORIGIN=https://next-app-kohl-one.vercel.app
```

| 变量 | 说明 |
|------|------|
| NEXT_PUBLIC_SUPABASE_URL | Supabase 项目 URL |
| NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY | Supabase anon/public key |
| NEXT_PUBLIC_APP_ORIGIN | 部署域名 |

## Supabase Auth 邮件配置

- Supabase Auth 已启用 custom SMTP。
- SMTP host 使用 `smtp.mail.me.com`。
- Sender email 使用 `noreply@jimmyyao.com` 或系统邮箱。
- Email Magic Link 已可用于 `/login` 登录。
- Magic Link 登录成功后默认回到 `/lessons`。
- Apple 登录入口当前前台隐藏；Google 登录保留。
- 不在知识库中记录 SMTP 密码、App 专用密码、token、secret 或 API key。
