# 第 1 课会话主线闭环控制

> 最后更新：2026-06-11

## 一、数据链

```
视频字幕 JSON（official_video_subtitle）
       │
       ▼
tmp/conversation-preview/lesson-01.conversation.cleaned.json（清洗合并后）
       │
       ▼
src/data/minna/lessons/lesson-01.json
  ├── conversation（↑ 官方字幕原句）
  ├── conversation_vocab（AI 从原句提取）
  ├── conversation_grammar（AI 从原句提取）
  ├── conversation_examples（AI 基于原句生成）
  └── conversation_quiz（AI 基于原句生成）
```

## 二、追溯规则

所有 conversation_vocab / conversation_grammar / conversation_examples / conversation_quiz
都必须能追溯到 conversation 中的某条 `id`。

| 字段 | 来源 |
|------|------|
| `fromConversationId` | 对应 conversation item 的 `id` |
| `sourceSentence` / `originalSentence` | conversation item 的 `jp` 原句 |
| `sourceType` | conversation: `official_video_subtitle` / 其余: `ai_generated_from_official_conversation` |

## 三、审核标记

| 字段 | 说明 |
|------|------|
| `needsReview: true` | 未审核 |
| `reviewStatus: "needs_review"` | 未审核 |
| `needsSpeakerReview: true` | 说话人未确认 |
| `needsKanaReview: true` | 假名注音未确认 |
| `needsKeywordReview: true` | 关键词未确认 |

不允许将未人工审核内容标记为 `reviewed` / `verified`。

## 四、校验流程

每次修改 lesson-01.json 后执行：

```bash
node scripts/verify-conversation-mainline.mjs
```

校验内容：
1. conversation_vocab 每项 fromConversationId 必须存在于 conversation
2. conversation_grammar 每项 fromConversationId 必须存在于 conversation
3. conversation_examples 每组 originalSentence 必须来自 conversation 原句
4. conversation_quiz 每题 sourceSentence 必须来自 conversation 原句
5. 不允许 temporary_test 混入 official_video_subtitle
6. 每项必须有 sourceType / needsReview / reviewStatus
