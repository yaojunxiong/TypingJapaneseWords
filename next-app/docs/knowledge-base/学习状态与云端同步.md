# 学习状态与云端同步

## 核心引擎

`src/lib/learning-cloud-sync.ts`

### 类型

```typescript
type UnifiedLearningState = {
  schema: 'minna.learning.state.v2'
  lastLesson: number
  streak: number
  lastStudyDate: string
  xp: number
  hearts: number
  crowns: Record<string, boolean>
  progress: JsonObj
  studyDays: Record<string, boolean>
  learningStats: LearningStats
  updatedAt: string
}
```

### 同步策略

```
本地 localStorage ────┬───→ 云端 Supabase
                      │
              冲突时最新时间戳为准
```

同步优先级（forceUpload 参数控制）：
1. 如果本地有 dirty 标记（stateDirtyAt / mistakesDirtyAt），优先上传
2. 如果云端更新时间比本地同步时间更新，先从云端拉
3. 正常情况下双向合并（云端 + 本地）

### 同步边界

- `minna_learning_state`：学习状态（XP、皇冠、打卡、收藏列表）
- `minna_learning_mistakes`：错题列表
- `minna_learning_checkins`：每日打卡记录（保留最近 180 天）

### 同步时机

- 首页加载时
- 课程列表加载时
- 学习中心加载时
- 错题本加载时
- Auth 状态变化时
- 打卡操作后
- 收藏变更后（通过 `favorites-client` 单独同步）

## 本地存储 Key 前缀

所有 key 以 `minna.` 开头：

| 前缀 | 用途 |
|------|------|
| `minna.mobile.learning.state.v1` | 学习状态 |
| `minna.stage.progress.v1` | 各 stage 进度 |
| `minna.crowns.v1` | 皇冠记录 |
| `minna.mistakes.v1` | 错题列表 |
| `minna.hearts.v1` | 心数 |
| `minna.xp.v1` | XP 值 |
| `minna_study_days` | 学习日 |
| `minna.learning.stats.v1` | 连续打卡统计 |
| `minna.vocab.favorites.v1` | 收藏词汇 |
| `minna.cloud.*` | 云端同步时间戳 |

## 语言设置

存储在 cookie `minna_lang` 中，值为 `zh` 或 `en`。
