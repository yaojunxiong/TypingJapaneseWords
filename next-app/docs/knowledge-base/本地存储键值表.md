# 本地存储键值表

## 学习状态 key

| Key | 类型 | 说明 |
|-----|------|------|
| `minna.mobile.learning.state.v1` | JSON | 完整学习状态（lastLesson, streak, xp, hearts, crowns, progress, studyDays, learningStats, updatedAt） |
| `minna.stage.progress.v1` | JSON | 各 stage 进度（旧格式，兼容） |
| `minna.crowns.v1` | JSON | 皇冠记录 `Record<string, boolean>`，key 如 `lesson1.vocab` |
| `minna.mistakes.v1` | JSON | 错题数组 `MistakeItem[]` |
| `minna.hearts.v1` | number (string) | 心数 0-5 |
| `minna.xp.v1` | number (string) | 累计 XP |

## 打卡 key

| Key | 类型 | 说明 |
|-----|------|------|
| `minna_study_days` | JSON | `Record<string, boolean>`，key 为日期 ISO 字符串 |
| `minna.learning.stats.v1` | JSON | `{ streak, lastDate, daily: Record<string, number> }` |

## 收藏 key

| Key | 类型 | 说明 |
|-----|------|------|
| `minna.vocab.favorites.v1` | JSON | `FavItem[]` |
| `minna.vocab.favorites.updated_at.v1` | string (ISO) | 最后更新时间 |

## 聊天 key

| Key | 类型 | 说明 |
|-----|------|------|
| `minna.chat.pins.v1` | JSON | 置顶会话 |
| `minna.chat.prefs.v2` | JSON | 聊天偏好 |
| `minna.chat.drafts.v1` | JSON | 草稿 |
| `minna.chat.read.v1` | JSON | 已读状态 |
| `minna.chat.unread.total.v1` | number (string) | 未读总数 |

## 练习 key

| Key | 类型 | 说明 |
|-----|------|------|
| `minna.practice.voice.v1` | string | 语音开关 `"0"` = 关 |
| `minna.practice.sfx.v1` | string | 音效开关 `"0"` = 关 |
| `minna.top.lesson_label.v1` | string | 顶部课程标签 |

## 云同步 key

| Key | 类型 | 说明 |
|-----|------|------|
| `minna.cloud.state.updated_at.v1` | number (string) | 学习状态云端同步时间戳 |
| `minna.cloud.mistakes.updated_at.v1` | number (string) | 错题云端同步时间戳 |
| `minna.cloud.state.dirty_at.v1` | number (string) | 学习状态本地修改时间戳（非空时下次同步上传） |
| `minna.cloud.mistakes.dirty_at.v1` | number (string) | 错题本地修改时间戳（非空时下次同步上传） |
