# 功能模块映射

## 首页

| 层级 | 文件 |
|------|------|
| 页面 | `src/app/page.tsx` |
| 导航 | `src/components/minna-nav.tsx` |
| 进度 | `src/components/home-progress-client.tsx` |

## 课程列表

| 层级 | 文件 |
|------|------|
| 页面 | `src/app/lessons/page.tsx` |
| 客户端 | `src/components/lessons-client.tsx` |
| 元数据 | `src/lib/minna-lessons.ts` |
| 进度存储 | localStorage `minna.crowns.v1` |

课程锁逻辑：
- 读取 `user_roles.role`
- admin/vip/member 角色可绕过锁
- 若课号 > 当前 lastLesson 且 crowns=0，则锁住

## 课程详情

| 层级 | 文件 |
|------|------|
| 页面 | `src/app/lessons/[lessonNo]/page.tsx` |
| 数据 | `src/data/minna/lessons/lesson-XX.json` |
| 导航 | `src/components/minna-nav.tsx` |
| 收藏按钮 | `src/components/favorite-toggle-button.tsx` |

## 课程练习

| 层级 | 文件 |
|------|------|
| 页面 | `src/app/lessons/[lessonNo]/practice/page.tsx` |
| 客户端 | `src/components/lesson-practice-client.tsx` |

练习数据流：
1. Server 读 JSON → 提取对应 section 的 items
2. 提取 practice 和 quiz-like 考题 → 传给客户端
3. 客户端进行选题、判断正误、更新 XP/皇冠/错题

## 单词/语法/例句

词汇、语法、例句均存储在课程 JSON 的对应 section 中，由课程详情页和练习页展示。

## 错题本

| 层级 | 文件 |
|------|------|
| 页面 | `src/app/mistakes/page.tsx` |
| 客户端 | `src/components/mistakes-client.tsx` |
| 存储 | localStorage `minna.mistakes.v1` |
| 云同步 | `src/lib/learning-cloud-sync.ts` → `minna_learning_mistakes` |

错题条目结构：

```typescript
type MistakeItem = {
  lessonNo?: number
  stage?: string
  jp?: string
  kana?: string
  meaning?: string
  question?: string
  answer?: string
  sourceId?: string
  at?: string
}
```

## 复习中心（学习中心）

| 层级 | 文件 |
|------|------|
| 页面 | `src/app/toolbox/page.tsx` |
| 客户端 | `src/components/toolbox-client.tsx` |

复习中心聚合显示：XP、皇冠、错题数、课程数、连续打卡天数、打卡总天数。
提供同步、打卡、跳转到错题本等功能。
