# 50 课视频资料清单

> 此清单登记《みんなの日本語》各课会话视频的来源、拆句状态和加工进度。每条「会话标题」对应 `lesson-XX.json` 中新增的 `conversation` section 的 `dialogTitle` 字段。

## 当前阶段：视频资源链接整合（已完成）

2026-06-11：已通过 `scripts/link-conversation-videos.mjs` 为全部 50 课 JSON 写入 `conversationVideo` 元数据。

### conversationVideo 字段

```jsonc
{
  "conversationVideo": {
    "sourcePageUrl": "https://yaojunxiong.github.io/TypingJapaneseWords/EveryonesJapanese/index.html",
    "lessonNo": 1,
    "videoUrl": "https://.../{filename}.mp4",
    "subtitleUrl": "https://.../{filename}.json",
    "sourceType": "official_video_resource",
    "status": "linked_not_imported"  // 或 "parsed_not_imported"(第1课)
  }
}
```

| status 值 | 含义 | 课程 |
|-----------|------|------|
| `linked_not_imported` | 视频资源已关联，字幕未导入 | 第 2-50 课 |
| `parsed_not_imported` | 字幕已解析预览，未写入 conversation | 第 1 课 |
| `imported` | 字幕已写入 conversation section | — |

### 页面集成

- `/lessons/[lessonNo]`：显示"会话视频"卡片，含播放视频和资源页按钮
- `/lessons/[lessonNo]/practice?stage=conversation`：页面顶部显示视频资源信息

## 视频资源入口

**播放器页面：** https://yaojunxiong.github.io/TypingJapaneseWords/EveryonesJapanese/index.html

该页面为《大家的日本語 第2版》会話视频字幕播放器，覆盖 1-50 课，每课均提供：
- MP4 视频文件
- JSON 字幕文件（含 `start` / `end` / `jp` / `zh` 字段，纯数字时间戳）

### 文件命名规则

```
大家的日本语第2版-会话_P{num}_第{num}課.{mp4|json}
```

示例：
- 第 1 课：`大家的日本语第2版-会话_P1_第1課.mp4` / `.json`
- 第 2 课：`大家的日本语第2版-会话_P2_第2課.mp4` / `.json`

### 文件 URL 模板

```
https://yaojunxiong.github.io/TypingJapaneseWords/EveryonesJapanese/大家的日本语第2版-会话_P{num}_第{num}課.mp4
https://yaojunxiong.github.io/TypingJapaneseWords/EveryonesJapanese/大家的日本语第2版-会话_P{num}_第{num}課.json
```

### 字幕 JSON 格式

```typescript
type SubtitleLine = {
  start: number      // 开始时间（秒）
  end: number        // 结束时间（秒）
  jp: string         // 日语原文
  zh: string         // 中文翻译
}
```

示例（第 1 课第 1 句）：
```json
{"start": 0.0, "end": 27.3, "jp": "おはようございます", "zh": "早上好"}
```

---

字段说明：

| 字段 | 说明 |
|------|------|
| 课数 | 1-50 |
| 课程 JSON | 对应 JSON 文件是否已包含 `conversation` section |
| 会话标题 | 对话主题，对应 `dialogTitle` |
| 视频 URL | 官方会话示范视频 |
| 字幕 JSON URL | 逐句字幕文件（含时间轴） |
| 字幕是否已解析 | 字幕 JSON 是否已下载并拆分为可导入 JSON 的格式 |
| 是否已导入 conversation | 字幕拆句结果是否已写入 `lesson-XX.json` 的 `conversation.items[]` |
| 来源验证 | 当前 conversation 文本是否来自视频字幕或教材原文 |
| 状态 | `未开始` / `已解析` / `已拆句` / `已导入` / `待审核` |
| 备注 | 说明、数据来源、与字幕差异等 |
