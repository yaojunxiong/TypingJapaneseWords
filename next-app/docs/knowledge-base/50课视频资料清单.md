# 50 课视频资料清单

> 此清单登记《みんなの日本語》各课会话视频的来源、拆句状态和加工进度。每条「会话标题」对应 `lesson-XX.json` 中新增的 `conversation` section 的 `dialogTitle` 字段。

字段说明：

| 字段 | 说明 |
|------|------|
| 课数 | 1-50 |
| 课程 JSON | 对应 JSON 文件是否已包含 `conversation` section |
| 会话标题 | 对话主题，对应 `dialogTitle` |
| 视频 URL | 会话示范视频链接（YouTube / 自制 / 第三方） |
| 是否已拆句 | 视频是否已按句子切割为逐句列表（对应 `items[]`） |
| 是否已标时间轴 | 每句是否已标注在视频中的起止时间（用于字幕同步） |
| 状态 | `未开始` / `进行中` / `已完成` / `待审核` |
| 备注 | 额外说明、数据来源、质量标注 |
