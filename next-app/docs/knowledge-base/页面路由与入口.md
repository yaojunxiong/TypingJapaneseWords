## API Route

| 路由 | 文件 | 用途 |
|------|------|------|
| `GET /auth/callback` | `src/app/auth/callback/route.ts` | Supabase OAuth 回调 |
| `GET /lang` | `src/app/lang/route.ts` | 语言切换 |
| `GET /admin/export.csv` | `src/app/admin/export.csv/route.ts` | 后台 CSV 导出 |

## 导航组件

`src/components/minna-nav.tsx`

导航栏分两级：
- **主要**：首页、课程、学习、收藏、消息
- **更多**：系统语言、登录、我的、聊天

`active` prop 决定高亮项。
