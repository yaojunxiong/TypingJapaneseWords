# 会话主线课程重构方案

> 每一课以"会话背诵"为主线，词汇、语法、例句、测试都围绕该课会话内容重新编排。用户学习一课的最终目标不是单独记词汇或语法，而是能背下并说出该课会话。

---

## 一、课程新结构

每课学习顺序改为以下 10 个步骤：

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | 会话目标 | 展示本课要掌握的会话场景与学习目标 |
| 2 | 会话视频/字幕原文 | 播放官方会话视频，同步显示逐句字幕 |
| 3 | 会话关键词汇 | 从会话原文中提取核心词汇 |
| 4 | 会话核心语法 | 从会话原文中提取语法点 |
| 5 | 会话句子拆解 | 逐句展示 jp/kana/zh/speaker，附带语法标注 |
| 6 | 会话替换例句 | 基于原句生成替换练习（换主语/宾语/场景） |
| 7 | 会话专项测试 | 测试题全部服务于背会话 |
| 8 | 中文提示背诵 | 显示中文 → 用户背日语 → 标记熟悉度 |
| 9 | 角色扮演 | 分角色对话练习 |
| 10 | 整课背诵挑战 | 不看提示完整背出全部会话 |

### 学习流程图

```
会话目标
   ↓
会话视频/字幕 ─→ 会话关键词汇 ─→ 会话核心语法
   ↓
会话句子拆解
   ↓
会话替换例句 ─→ 会话专项测试
   ↓
中文提示背诵 ─→ 角色扮演 ─→ 整课背诵挑战
```

## 二、数据设计建议

### schema 升级

将 schema 从 `minna.lesson.v1` 升级为 `minna.lesson.v2`：

```jsonc
{
  "schema": "minna.lesson.v2",
  "course": "minna",
  "lessonNo": 1,
  "lessonId": "minna_lesson_01",
  "title": { "zh": "第1课", "en": "Lesson 1" },
  "subtitle": { "zh": "名词句・自我介绍", "en": "Noun sentences / self-introduction" },
  "focus": { "zh": "学习...", "en": "Learn..." },
  "conversationGoal": {
    "zh": "能用日语进行简单的自我介绍（姓名、国籍、职业）",
    "en": "Be able to introduce yourself in Japanese (name, nationality, occupation)"
  },
  "sections": [
    // conversation — 官方视频字幕原文，必须标记 sourceType
    // conversation_vocab — 从会话中提取的词汇
    // conversation_grammar — 从会话中提取的语法
    // conversation_examples — 基于原句的替换例句
    // conversation_quiz — 服务于背会话的测试
    // conversation_review — 整课背诵挑战
    // 保留原有的 vocab/grammar/examples/quiz 作为补充参考
  ]
}
```

### section 类型变更

| type | 来源 | 说明 |
|------|------|------|
| `conversation` | official_video_subtitle | 官方会话原文，不得自编 |
| `conversation_vocab` | ai_generated + 人工审核 | 从会话中提取的词汇 |
| `conversation_grammar` | ai_generated + 人工审核 | 从会话中提取的语法点 |
| `conversation_examples` | ai_generated | 基于原句的替换练习 |
| `conversation_quiz` | ai_generated | 会话专项测试 |
| `conversation_review` | ai_generated | 整课背诵挑战 |

原有 `vocab`/`grammar`/`examples`/`quiz` 保留为补充参考 section，不再作为主线。

### 字段标记规则

| sourceType | 含义 |
|------------|------|
| `official_video_subtitle` | 来自官方视频字幕原文，不可修改 |
| `official_textbook` | 来自教材原文，不可修改 |
| `ai_generated` | AI 辅助生成，需人工审核 |
| `temporary_test` | 临时测试数据，待替换 |

### 数据依赖关系

```
conversation (原文)
  ├── conversation_vocab (提取自原文)
  ├── conversation_grammar (提取自原文)
  ├── conversation_examples (基于原句改写)
  ├── conversation_quiz (基于原句出题)
  └── conversation_review (基于原句)
```

所有扩展内容如果修改了原文，必须使用不同的 id 并标记 `ai_generated`，不得混入 `official_video_subtitle`。

## 三、内容生成规则

### 绝对规则

1. **conversation 必须来自官方视频字幕或教材原文**
   - 来源为 `https://yaojunxiong.github.io/TypingJapaneseWords/EveryonesJapanese/` 下的字幕 JSON
   - 或来自教材原文（需人工确认）
   - 标记 `sourceType: "official_video_subtitle"` / `"official_textbook"`

2. **AI 不得自编或改写原会话**
   - `conversation` section 的 `jp` 字段必须与字幕/原文逐字一致
   - 不允许 AI 私自修改原文内容

### AI 允许范围

3. **AI 可以从会话中提取词汇、语法、关键词**
   - `conversation_vocab`：从原文中提取名词、动词、形容词等
   - `conversation_grammar`：从原文中识别句型、助词用法
   - `keyword`：标记每句的关键词

4. **AI 可以基于原句生成替换练习和测试**
   - `conversation_examples`：替换主语、宾语、场景，但保持句型结构一致
   - `conversation_quiz`：生成服务于背诵的测试题

### 标记规则

5. **扩展内容必须标记为 `ai_generated`**
   - 所有 AI 生成的内容在 `sourceType` 中标记 `"ai_generated"`
   - 不允许将 AI 内容混入 `"official_video_subtitle"`

## 四、测试体系

测试题必须服务于背会话，而非独立考察词汇语法：

| 题型 | 说明 | 示例 |
|------|------|------|
| 听句选义 | 播放 jp 音频，选择正确中文翻译 | 听到「おはようございます」→ 选「早上好」 |
| 中文转日语 | 显示中文，输入或选择对应日语原文 | 「早上好」→ 选「おはようございます」 |
| 关键词补全 | 显示带空格的会话句子，补关键词 | 「___、マイクミラーです」→ 初めまして |
| 语序排列 | 打乱词块，按正确顺序排列 | 「です / マイクミラー / 初めまして」→ 排序 |
| 角色接话 | 显示 A 的台词，选择 B 的正确回应 | A:「初めまして」→ B:「どうぞよろしく」 |
| 整课背诵挑战 | 逐句提示，完整复述全部会话 | 从第 1 句到第 N 句 |

### 测试数据 vs conversation 关系

```
conversation items[]
  └── 每句可派生：
       ├── 听句选义题 (1 题)
       ├── 中文转日语题 (1 题)
       ├── 关键词补全题 (1 题)
       └── 角色接话题 (与上下文配对)
整课 → 语序排列题 (1 大题) / 整课背诵挑战
```
