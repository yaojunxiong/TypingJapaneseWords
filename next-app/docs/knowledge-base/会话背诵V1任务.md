## P1：第 1 课数据加工

### 1.1 人工审核 cleaned JSON

**输入**：`tmp/conversation-preview/lesson-01.conversation.cleaned.json`

**待确认项**：

| 字段 | 当前状态 | 需要人工做什么 |
|------|----------|---------------|
| speaker | 全部为空 | 看视频确认每句谁说的 |
| kana | 含汉字的句子为空 | 补充注音（或调用日语 API 辅助） |
| keyword | 部分有初步建议 | 确认/修正 |
| 断句 | 8 条 | 是否合理？"佐藤さん"是否该合并？ |
| 中文翻译 | 来自字幕 | 确认是否准确 |

**产出**：`tmp/conversation-preview/lesson-01.conversation.reviewed.json`

### 1.2 替换 lesson-01.json conversation

将审核后的 JSON 写入 `lesson-01.json` 的 conversation section。

**操作**：
1. 删除原有 `temporary_test` conversation section
2. 写入官方字幕数据
3. `sourceType` → `"official_video_subtitle"`
4. 保留 `speaker`/`kana`/`keyword`（已审核）

**验收**：`/admin/lessons/1` 显示官方会话原文，不再是 AI 自编内容。

### 1.3 生成 conversation_vocab

**脚本**：`scripts/generate-conversation-vocab.mjs`（新建）

**逻辑**：
1. 读取 `lesson-01.json` 的 `conversation.items[]`
2. 提取所有名词、动词、形容词、助词
3. 保留原句作为出处
4. 标记 `sourceType: "ai_generated"`

**产出**：`tmp/conversation-preview/lesson-01.conversation_vocab.preview.json`

### 1.4 生成 conversation_grammar

**脚本**：`scripts/generate-conversation-grammar.mjs`（新建）

**逻辑**：
1. 识别原文中的语法点（NはNです、Nから来ました 等）
2. 每个语法点附带源于原文的示例
3. 标记 `sourceType: "ai_generated"`

**产出**：`tmp/conversation-preview/lesson-01.conversation_grammar.preview.json`

### 1.5 生成 conversation_examples

**脚本**：`scripts/generate-conversation-examples.mjs`（新建）

**逻辑**：
1. 基于原句做替换（换主语、换场景）
2. 保持句型结构一致
3. 标记 `sourceType: "ai_generated"`

**产出**：`tmp/conversation-preview/lesson-01.conversation_examples.preview.json`

### 1.6 生成 conversation_quiz

**脚本**：`scripts/generate-conversation-quiz.mjs`（新建）

**题型**：
- 听句选义（每句 1 题）
- 中文转日语（每句 1 题）
- 关键词补全（每句 1 题）
- 语序排列（整课 1 大题）
- 角色接话（按对话顺序）
- 整课背诵挑战（入口）

**产出**：`tmp/conversation-preview/lesson-01.conversation_quiz.preview.json`

## P2：第 1 课页面实现

### 2.1 创建会话主线学习组件

**组件**：`src/components/lesson-main-line-client.tsx`（新建）

**功能**：
1. 会话目标展示（顶部，显示 `conversationGoal`）
